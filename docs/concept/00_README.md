# 도전 성경말씀 — 개념 명세 (새 프로젝트 인수용)

> 이 폴더는 잠실새내교회 유년부 사이트(YunYunBu2025)의 **"도전 성경말씀"** 기능을 떼어,
> **새 저장소에서 멀티테넌트 SaaS로 완전히 새로 개발**하기 위한 **개념 명세**다.
>
> - 여기에는 **개념 · 업무 규칙 · 사용 흐름 · 결정 사항**만 있다.
> - **표 설계(논리 · 물리), 코드, API 상세는 새 프로젝트에서 처음부터** 한다.
> - 지금 시스템의 표 · 코드 이름은 "참고(현행)"로만 적었다. 그대로 옮기지 않는다.
> - 기존 데이터는 **옮기지 않는다**(콘텐츠 · 기록 · 점수 모두 새로 시작).

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-10-21 |
| 근거 | 현행 소스 `DailyMission4Controller`, `DailyMission2Service`, `AwardDashboardService`, `StudentPointGiftService`(가족 부분), DB 함수 `ufn_DM2_GetUserDailyPoints`, `ufn_GetUserClickHistory` 를 직접 읽고 정리 |
| 상위 문서 | 현행 시스템 전체 설명서 `docs/system-manual/` (참고용) |

## 새 프로젝트로 가져가는 법
1. 이 폴더(`docs/challenge-bible/`)를 통째로 새 저장소의 `docs/` 아래로 복사한다.
2. 새 저장소에서 코드방을 열고 [06 문서](06_새프로젝트_시작안내.md) 순서대로 시작한다.
