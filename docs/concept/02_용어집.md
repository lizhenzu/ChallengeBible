# 02. 용어집 (Ubiquitous Language)

> 새 프로젝트의 코드 · 표 · 화면 · 대화에서 **이 이름을 그대로** 쓴다. (영문은 코드 이름 후보)
> "현행" 칸은 지금 시스템에서 같은 개념을 부르던 이름이다 — 참고만 하고 따르지 않는다.

## 테넌시 · 사람

| 용어 | 영문 | 정의 | 현행 |
|---|---|---|---|
| 플랫폼 | Platform | 서비스 전체. 모든 영역을 담는 그릇 | — |
| 영역 | Tenant | 격리 단위. 한 교회의 한 부서(유년부, 초등부 …). 고유 코드(주소 경로에 사용)와 이름, 시간대, 설정을 가진다 | 없음(사이트 전체가 유년부 하나) |
| 영역 코드 | TenantSlug | 주소 경로에 쓰는 짧은 영문 코드. 예: `jsn-kids` | — |
| 계정 | Account | 로그인 주체. 전역(영역과 무관). 아이디 · 비밀번호 · 이름 | `Identity.User` |
| 소속 | Membership | (계정, 영역, 역할) 연결. 상태: 신청 → 승인 → 정지/해제 | `DeptRoleUserAssoc`(부서·역할 코드) |
| 참여자 | Participant | 영역 안에서 미션을 하고 점수를 쌓는 주체(주로 아이). 소속 1건에 대응 | 학생(`T1001`) + 미션을 한 모든 사람 |
| 보호자 | Guardian | 영역 안에서 특정 참여자(자녀)를 조회할 수 있는 계정. 점수 없음 | 없음(가족팀의 엄마·아빠가 일부 대신) |
| 보호 관계 | GuardianLink | (보호자 소속, 참여자) 연결. 영역 관리자가 만든다 | — |
| 영역 관리자 | TenantAdmin | 영역 하나를 운영하는 역할 | Admin/SuperAdmin 역할 + 계정 이름 예외 |
| 플랫폼 관리자 | PlatformAdmin | 모든 영역을 넘나드는 슈퍼유저 | SuperAdmin |
| 그룹 라벨 | GroupLabel | 참여자에 붙이는 선택 문자열(예: "3학년 2반"). 계산에 쓰지 않고 표시 · 필터에만 | `ClassInfo_2026` 학년·반 |
| 대리 접속 | Impersonation | 플랫폼 관리자가 다른 사람 화면으로 보는 기능. 감사 로그 필수 | `ImpersonateUserId` 세션 |

## 콘텐츠

| 용어 | 영문 | 정의 | 현행 |
|---|---|---|---|
| 콘텐츠 | Content | 미션에 쓰는 자료의 통칭 | — |
| 오늘의 말씀 | DailyWord | 날짜 1일에 1건. 성경 본문 범위(책 · 시작 장절 · 끝 장절) + 요약 · 해설 · 질문 · 영상 구간 | `TodayWordToRead` |
| 오늘의 기도 | DailyPrayer | 날짜 1일에 1건. 제목, 시작 · 본문 · 끝 문장, 근거 말씀 | `PrayPhrase` |
| 오늘의 퀴즈 | DailyQuiz | 날짜 1일에 1건. 문제, 보기(객관식 4개) 또는 주관식, 정답, 해설, 배경 설명 | `QuestionData` |
| 이번 주 암송 | WeeklyVerse | 기간(시작일~종료일, 보통 1주)에 1건. 암송 구절 범위 + 공과 정보 | `WeeklyWordToRead` |
| 공용 콘텐츠 | LibraryContent | 플랫폼 관리자가 만든 콘텐츠. 모든 영역의 기본값 | — |
| 영역 덮어쓰기 | TenantOverride | 특정 영역 · 특정 날짜(또는 주)에 공용 대신 쓰는 콘텐츠 | — |
| 노출일 | ExposeDate | 콘텐츠가 "오늘의 것"이 되는 날짜(영역 시간대 기준) | `ExposeDate` |
| 성경 본문 | BibleVerse | 한 절. (번역본, 책, 장, 절, 본문). 플랫폼 공용 참조 데이터 | `eBible`, `eBibleEN`, `eBibleHD` |
| 퀴즈 문제 은행 | QuizBank | 퀴즈를 만들 때 고르는 문제 저장소 | `QuestionBankData` |

## 미션 · 점수

| 용어 | 영문 | 정의 | 현행 |
|---|---|---|---|
| 미션 | Mission | 참여자가 하는 행동의 종류: 말씀(Word), 기도(Prayer), 퀴즈(Quiz), 암송(Recite) | DM2 미션 |
| 미션 항목 | MissionItem | 한 미션 안에서 점수가 따로 나오는 단위. 말씀: 나 · 부모님께 / 기도: 나 · 부모님 · 친구 | ToMe, ToParent, ToFriend |
| 수행 기록 | Activity | (참여자, 미션 대상일, 미션 항목) 의 수행 사실. **하루 · 항목당 최대 1건** | `ClickHistoryFor*` |
| 미션 대상일 | MissionDate | 그 기록이 "어느 날의 미션"인지. 실제로 누른 시각과 다를 수 있다(어제 미션을 오늘 함) | `ClickDate` |
| 인정 기간 | GraceWindow | 지난 날짜 미션을 할 수 있는 기간. 기본 오늘 포함 3일(오늘 · 어제 · 그제) | `IsActionableDate` |
| 퀴즈 시도 | QuizAttempt | 퀴즈 답 제출 1회. 하루 최대 N회(기본 2) | `TryCnt` |
| 점수 원장 | PointLedger | 점수 변동을 한 줄씩 쌓은 기록. 모든 점수 합계의 근거 | 없음(DB 함수가 매번 계산) |
| 하루 점수 | DailyPoint | 한 참여자의 한 날짜 점수 합(말씀 + 기도 + 퀴즈 + 암송) | `ufn_DM2_GetUserDailyPoints` |
| 연간 점수 | SeasonPoint | 시즌(기본: 1월 1일~12월 31일) 누적 점수 | `YearTotalPoint` |
| 완주일 | AllDoneDay | 4가지 미션이 모두 완료된 날(달력 표시) | `CalendarAllDoneMap` |
| 연속 참여일 | Streak | 마지막으로 점수를 얻은 날부터 거꾸로 하루도 빠짐없이 점수가 있는 날 수 | `ConsecutiveDays` |
| 목표 점수 | TargetPoint | 순위 화면의 달성률 기준. 가장 높은 축하 단계 점수 | `AwardBase` 최댓값 |
| 축하 단계 | Milestone | 개인 연간 점수가 도달하면 축하하는 기준 점수(여러 개) | `AwardBase` (3000/5000/8000) |
| 단계 도달 | MilestoneReached | 축하 단계를 처음 넘은 사건. 1번만 발생 | `AwardUserClaim` Eligible |

## 가족팀

| 용어 | 영문 | 정의 | 현행 |
|---|---|---|---|
| 가족팀 | FamilyTeam | 같은 영역 안 참여자 여러 명을 묶은 팀. 팀 점수 = 구성원 점수 합 | `DM2_FamilyTeam` |
| 팀 구성원 | FamilyMember | (가족팀, 참여자, 관계, 순서). 관계: 학생 · 엄마 · 아빠 · 할머니 · 할아버지 · 기타 | `DM2_FamilyMember` |
| 가족 단계 | FamilyMilestone | 팀 합산 점수 기준. 종류: 축하+보상(AWARD) / 박수만(APPLAUSE) | `DM2_FamilyMilestoneConfig` |
| 단계 숨김 | MilestoneDismiss | 관리자가 특정 팀의 특정 단계 카드를 감춤 | `DM2_FamilyMilestoneHidden` |

## 설정

| 용어 | 영문 | 정의 |
|---|---|---|
| 규칙 설정 | RuleSet | 점수 · 인정 기간 · 횟수 등 값의 묶음. 플랫폼 기본값 + 영역별 덮어쓰기 |
| 기능 스위치 | FeatureToggle | 영역별 켜기/끄기: 순위, 가족팀, 대조 번역 등 |
| 시즌 | Season | 점수를 모으는 1년 기간. 기본 1월 1일 시작, 영역이 시작일 변경 가능 |
| 동의 확인 | ConsentVerified | 영역 관리자가 교회가 받은 보호자 동의서를 확인했다는 표시(소속 속성) |
| 진급 | Promotion | 참여자가 다른 영역으로 옮김. 이전 영역 기록은 삭제 |
