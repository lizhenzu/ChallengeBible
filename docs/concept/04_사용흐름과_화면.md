# 04. 사용 흐름과 화면

> 화면 디자인은 새 프로젝트에서 시안부터 다시 만든다. 여기에는 **무엇이 필요한지**만 적는다.
> 주소는 예시다. 모든 영역 화면은 `/{영역코드}/...` 아래에 있다(D8).
> 휴대폰(375px) 우선, PWA 설치 가능.

## 1. 사용자별 흐름

### 1-1. 참여자(아이)
```
가입(계정: 이메일 · 비밀번호 · 이름만) → 영역 주소로 접속 → 소속 신청 →
[영역 관리자 승인 + 교회 동의서 확인 표시] →
미션 홈 → 오늘의 미션 카드 4장 중 하나 →
  말씀: 본문 읽기(선택) → [내가 읽었어요] [부모님께 읽어드렸어요] → +점수 팝업
  기도: 기도문 읽기 → [나] [부모님] [친구] → +점수 팝업
  퀴즈: 문제 → 답 선택 → 정답(+1)/오답(1/2) → 해설
  암송: 이번 주 구절 → [외웠어요] → +1
→ 미션 홈(점수 · 달력 갱신) → (단계 도달 시 축하 팝업)
지난 날짜: 달력에서 어제 · 그제 선택 → 같은 흐름 (그 이전은 보기만)
```

### 1-2. 보호자(부모)
```
가입(계정) → 영역 주소 접속 → 소속 신청(보호자) → [영역 관리자 승인 + 자녀 연결] →
보호자 홈: 연결된 자녀 목록 → 자녀별 오늘 미션 상태 · 이번 주 점수 · 달력 ·
(형제가 다른 영역이면) 상단 영역 전환 → 다른 영역의 자녀 보기
```

### 1-3. 영역 관리자
```
영역 관리 홈 → 
  소속 신청 승인/거절, 역할 지정(참여자/보호자/교사/관리자)
  보호 관계 연결(보호자 ↔ 참여자)
  그룹 라벨 붙이기(선택)
  콘텐츠 달력: 날짜별 공용/덮어쓰기 상태 → 덮어쓰기 작성 · 수정 · 되돌리기
  규칙 설정: 점수 · 인정 기간 · 퀴즈 횟수 · 단계 · 기능 스위치
  가족팀: 팀 만들기, 구성원 추가 · 관계 · 순서, 단계 카드 숨김
  현황: 오늘 참여자 수, 미참여자, 그룹별 참여율, 참여자 상세(달력)
```

### 1-4. 플랫폼 관리자(슈퍼유저)
```
플랫폼 홈 → 
  영역 목록: 만들기(코드 · 이름 · 시간대) · 정지 · 삭제, 영역 관리자 지정
  공용 콘텐츠 라이브러리: 말씀 · 기도 · 퀴즈 · 암송 날짜별 작성, 퀴즈 문제 은행, 월 단위 날짜 생성
  플랫폼 기본 규칙
  영역 진입(대리 접속) — 감사 로그
  감사 로그, 사용량(영역별 참여자 · 활동 수)
```

## 2. 화면 목록

### 2-1. 공통 · 계정
| 화면 | 내용 |
|---|---|
| 랜딩 | 서비스 소개, 로그인 · 가입 |
| 로그인 / 가입 / 비밀번호 찾기 | 계정(전역). 아이용 간단 로그인(PIN 등) 검토 |
| 내 계정 | 이름, 프로필 사진, 비밀번호, 소속 영역 목록 |
| 영역 선택 · 전환 | 소속이 여러 개일 때 |
| 소속 신청 | 영역 코드(주소)로 들어와 신청: 이름, 역할 희망(참여자/보호자) |

### 2-2. 참여자
| 화면 | 현행 대응 | 내용 |
|---|---|---|
| **미션 홈** | `/DailyMission4/Index` | 인사, 시즌 점수, 최근 7일 막대 + 합계, 미션별 숫자, 다음 단계까지 남은 점수, 오늘 한 줄 말씀, **미션 카드 4장**(완료 표시), 날짜 칩(오늘 · 어제 · 그제), 다른 날짜 안내 |
| **말씀** | `Word` | 오늘의 말씀 요약 · 해설 · 질문, [본문 읽기] 이동, 버튼 2개(나 · 부모님께), 완료 상태 |
| **본문 읽기** | `BibleRead` | 범위 본문 절 단위, 번역 전환, 절 읽음 · 전체 읽음 · 책갈피, 책 소개, 영상 구간, 글자 크기 조절 |
| 범위 읽기 | `BibleReadRange` | 구절 범위로 연 본문(점수 버튼 없음), 돌아가기 링크 |
| **기도** | `Pray` | 기도문(제목 · 시작 · 본문 · 끝), 근거 말씀, 버튼 3개(나 · 부모님 · 친구) |
| **퀴즈** | `Quiz` | 문제, 배경 설명, 보기, 시도 횟수(1/2), 내가 고른 답 표시, 정답 · 해설 |
| **암송** | `Recite` | 이번 주 암송 구절(한국어), 공과 제목, [외웠어요], 이번 주 완료 상태 |
| **달력** | `_Calendar` | 42칸, 날짜별 점수, 완주일 표시, 달 이동, 날짜 눌러 이동 |
| 내 점수 | `UserMonthlyPoints` | 월별 하루 점수 표(말씀 · 퀴즈 · 기도 · 암송 · 합계) |
| **참여자 순위** | `ParticipantPersons` | 카드 목록(R-81), 본인 강조, 시즌 선택 [기능 스위치] |
| **가족팀** | `ParticipantTeams` | 팀 카드(점수 · 달성률 · 가계도 · 구성원 점수), 가족 단계 [기능 스위치] |
| 축하 팝업 | `_OkPopup` | +점수, 올해 총점, 단계 도달 축하, 1 · 3 · 7일 숨김 |

### 2-3. 보호자
| 화면 | 내용 |
|---|---|
| 보호자 홈 | 연결된 자녀 카드: 오늘 미션 4개 상태, 이번 주 점수, 연속일 |
| 자녀 상세 | 자녀의 달력 · 월별 점수 (읽기 전용) |

### 2-4. 영역 관리자
| 화면 | 내용 |
|---|---|
| 관리 홈 | 오늘 참여자 수, 최근 7일 추이, 미참여 참여자 |
| 소속 관리 | 신청 목록(승인 · 거절 · **보호자 동의 확인**), 역할 변경(참여자 · 보호자 · 교사 · 관리자, 여러 개 가능), 정지 · 해제, **진급 처리**, 그룹 라벨 |
| 시즌 설정 | 시즌 시작일, 지난 시즌 보기 |
| 보호 관계 | 보호자 ↔ 참여자 연결 · 해제 |
| 콘텐츠 달력 | 월 달력에 종류별(말씀 · 기도 · 퀴즈 · 암송) 출처 표시(공용/덮어쓰기/없음) |
| 콘텐츠 덮어쓰기 편집 | 종류별 입력 폼, 미리보기, 공용으로 되돌리기 |
| 규칙 설정 | 03 문서 11절 값 편집, 변경 이력 |
| 가족팀 관리 | 팀 목록 · 만들기 · 수정, 구성원 추가(관계 · 순서) · 비활성, 단계 카드 숨김 |
| 참여자 상세 | 한 참여자의 달력 · 점수 · 최근 활동 |

### 2-5. 플랫폼 관리자
| 화면 | 내용 |
|---|---|
| 영역 관리 | 목록 · 생성 · 정지 · 삭제(내보내기 후), 영역 관리자 지정 |
| 공용 콘텐츠 | 종류별 날짜 달력 · 편집, 월 단위 일괄 생성, 공개 여부 |
| 퀴즈 문제 은행 | 문제 등록 · 검수 · 날짜 배정 |
| 성경 참조 데이터 | 번역본 · 책 정보 · 본문(초기 적재) |
| 플랫폼 기본 규칙 | 기본값 편집 |
| 감사 로그 | 영역 진입 · 대리 접속 · 설정 변경 기록 |
| 사용량 | 영역별 참여자 수 · 일일 활동 수 |

## 3. 화면 공통 요소
- 상단: 영역 이름(전환), 홈, 글자 크기 조절(아이 · 어르신 배려, 현행 기능).
- 모든 저장 동작 후 결과 팝업(성공 · +점수 / 실패 사유).
- 오래 걸리는 동작은 대기 카드(스피너 + 안내 문구).
- 언어: 화면 · 콘텐츠 한국어. 본문 번역 대조는 기능 스위치. 화면 문구는 리소스로 분리(D19).
- 접근성: 큰 버튼, 높은 대비, 아이 눈높이 문구, 이모지는 최소.

## 4. 외부 연동 지점 (범위 밖 시스템을 위한 출구)
| 이름 | 방향 | 내용 |
|---|---|---|
| 참여자 점수 조회 | 제공(API) | 영역 · 참여자 · 시즌별 점수 합, 미션별 내역 |
| 단계 도달 | 발행(이벤트/웹훅) | `MilestoneReached`, `FamilyMilestoneReached` |
| 활동 기록 | 발행(선택) | `ActivityRecorded` (통합 대시보드 · 출석 시스템용) |
| 그룹 라벨 동기화 | 받기(선택) | 외부 반 관리 시스템이 참여자 그룹 라벨을 채움 |
