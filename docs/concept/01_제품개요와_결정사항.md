# 01. 제품 개요와 결정 사항

## 1. 한 줄 정의
**주일학교 아이들이 매일 말씀 읽기 · 기도 · 퀴즈 · 암송 미션을 하고 점수를 쌓는 서비스.**
같은 프로그램을 여러 부서(유년부, 초등부 …)가 함께 쓰되, 부서끼리는 완전히 격리된다.

## 2. 목표
- 아이가 **매일 짧게(5~10분)** 말씀을 가까이하는 습관을 만든다.
- 부모가 함께 참여하도록 유도한다("부모님께 읽어드리기", "부모님을 위해 기도").
- 점수 · 달력 · 순위 · 가족팀으로 꾸준함을 눈에 보이게 한다.
- 부서 담당자는 콘텐츠를 매일 새로 만들 필요 없이 **공용 콘텐츠**를 쓰고 필요할 때만 바꾼다.
- 한 번 만들어 **여러 부서 · 여러 교회가 쓰는 SaaS** 로 운영한다.

## 3. 범위

### 포함 (In scope)
| 영역 | 내용 |
|---|---|
| 매일 미션 4종 | 말씀 읽기, 기도, 퀴즈(매일) / 암송(매주) |
| 성경 본문 읽기 | 오늘 말씀 범위의 본문 표시, 절 단위 읽음 표시, 책갈피, 대조 번역 |
| 점수 | 하루 점수, 월 · 연 누적, 최근 7일, 연속 참여일 |
| 달력 | 날짜별 점수, 4가지 모두 완료한 날 표시, 지난 날짜 보기 |
| 순위 · 참여자 | 개인 순위, 목표 대비 달성률 (영역별 켜기/끄기) |
| 가족팀 | 같은 영역 안 형제자매 · 가족의 점수 합산, 합산 단계 축하 (영역별 켜기/끄기) |
| 축하 단계 | 개인 연간 점수 단계 도달 축하(팝업) |
| 콘텐츠 관리 | 공용 콘텐츠 라이브러리 + 영역별 날짜 덮어쓰기 |
| 테넌시 관리 | 영역 생성 · 정지, 영역 관리자 지정, 소속 · 보호자 연결, 영역 설정 |

### 제외 (Out of scope) — 별도 시스템으로 두고 필요하면 연동
| 기능 | 이유 / 연동 방식 |
|---|---|
| 출석 체크 | 도전 성경과 무관. 독립 서비스 |
| 반 · 학년 관리 | 무관. 참여자에 선택적 **그룹 라벨**만 붙일 수 있게 함 |
| 선물 · 도토리(금액 환산, 상품 선택, 배송) | 무관. 이 서비스는 **"참여자별 점수"를 외부에 제공(API · 이벤트)** 만 한다 |
| 통합 점수(출석 + 세계관 + 묵상 + 전도 + 미션) | 현행은 미션 화면에서 계산하지만, 새 설계에서는 바깥 "통합 대시보드"의 책임 |
| 세계관 · 묵상 · 전도 점수 | 무관 |
| 기존 데이터 이전 | 하지 않음 |

> 현행 시스템에서 축하 단계 도달 시 "선물 고르기" 화면으로 보낸다. 새 설계에서는 **"단계 도달" 이벤트만 발생**시키고, 선물은 외부 시스템이 받아 처리한다(없으면 축하 메시지만).

## 4. 멀티테넌시 원칙
- **테넌트 = 영역(부서)**. 예: 잠실새내교회 유년부, 잠실새내교회 초등부.
- 모든 업무 데이터(참여자, 기록, 점수, 영역 콘텐츠, 설정, 가족팀)는 **정확히 하나의 영역에 속한다.**
- 영역 A 의 사용자 · 관리자는 영역 B 의 데이터를 **보거나 바꿀 수 없다**(존재조차 알 수 없음).
- **계정(로그인)만 전역**이다. 한 계정이 여러 영역에 소속될 수 있다(부모 사례).
- **플랫폼 관리자(슈퍼유저)** 만 영역을 넘나든다. 넘나든 행위는 감사 로그에 남긴다.
- 확장 여지: 나중에 "교회" 같은 상위 조직 계층(영역 묶음)을 추가할 수 있게 열어 둔다. 1차에는 만들지 않는다.

| D2 | 범위 | 미션 + 점수 + 달력 + 순위 + 가족팀 + 콘텐츠 + 테넌시 관리 | 출석 · 반 · 선물 제외 |

## 6. 역할(Role) 구성

| 역할 | 범위 | 할 수 있는 일 |
|---|---|---|
| **플랫폼 관리자** (Platform Admin, 슈퍼유저) | 전체 | 영역 생성 · 정지 · 삭제, 영역 관리자 지정, 공용 콘텐츠 관리, 플랫폼 기본 규칙, 모든 영역 조회(대리 접속), 감사 로그 |
| **영역 관리자** (Tenant Admin) | 자기 영역 | 소속 승인 · 해제, 보호자 연결, 영역 콘텐츠 덮어쓰기, 영역 규칙 값 변경, 가족팀 관리, 순위 · 가족팀 켜기/끄기, 영역 통계 |
| **교사** (Teacher, 선택) | 자기 영역 | 참여자 기록 조회, 그룹(반 라벨)별 참여 현황, 격려 — 1차에서는 영역 관리자 권한 일부로 대체 가능 |
| **참여자** (Participant) | 자기 영역 | 미션 수행, 내 점수 · 달력, 순위 · 가족팀 보기 |
| **보호자** (Guardian) | 자기 영역 | 연결된 자녀의 기록 · 점수 조회 (점수 없음) |

- 권한은 항상 **(계정, 영역, 역할)** 의 조합이다. 같은 계정이 유년부에선 보호자, 초등부에선 영역 관리자일 수 있다.
- 현행 시스템의 "계정 이름이 Basic/SuperAdmin 이면 관리자" 같은 **이름 기반 예외는 만들지 않는다.**
