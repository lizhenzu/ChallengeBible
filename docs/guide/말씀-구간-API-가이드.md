# 말씀 영상 구간 API 가이드

그날 말씀의 "🎧 듣기"가 재생할 **영상 구간 목록**을 넣는 API 입니다(옛 사이트의 구간 데이터도 이 API 로 밀어 넣습니다). 관리 화면 입력은 없습니다.
키 · 헤더 · 오류 모양은 [콘텐츠 입력 API 정의서](콘텐츠-입력-API-정의서.md)와 같고, 키도 같은 키를 씁니다.

## 호출

```
PUT https://{사이트 주소}/api/platform/words/{yyyy-MM-dd}/clips
Content-Type: application/json
X-Api-Key: {API 키}
```

```json
{
  "clips": [
    { "chapter": 1, "start": "3:20" },
    { "chapter": 2, "youtube": "https://youtu.be/dLv2ndgXrbo", "end": "1:05" }
  ]
}
```

위 예는 1장 기본 영상의 3분 20초부터 끝까지, 이어서 지정한 영상의 처음부터 1분 5초까지 재생하고, 마지막 뒤에는 처음부터 반복합니다.

## 칸

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `clips` | 배열 | 예 | 그날 목록 전체. **보낸 차례대로** 저장 · 재생합니다. 50개까지 |
| `clips[].chapter` | 숫자 | 예 | 장 번호(1 ~ 150). 책은 그날 말씀의 책입니다 |
| `clips[].youtube` | 글자 | | 유튜브 주소나 영상 번호(11자). 비우면 그 장의 기본 듣기 영상 |
| `clips[].start` | 글자 | | 시작 `"분:초"`(예: `"12:34"`). 비우거나 `"0:00"` 이면 처음부터 |
| `clips[].end` | 글자 | | 끝 `"분:초"`. 비우거나 `"0:00"` 이면 끝까지. 시작보다 뒤여야 합니다 |

## 동작

- **통째로 바꿉니다.** 부를 때마다 그날 목록 전체가 보낸 내용으로 바뀝니다.
- **지우려면 빈 목록**(`{ "clips": [] }`)을 보냅니다. `clips` 칸이 빠지면 지우지 않고 `400` 입니다.
- **하나라도 틀리면 아무것도 바뀌지 않습니다.** `errors` 의 칸 이름은 `clips[1].start` 모양입니다.
- 형식만 검사합니다. 장이 그날 말씀 범위 안인지, 차례가 맞는지, 시간이 영상 길이 안인지는 보지 않습니다. 그날 말씀이 아직 없어도 저장됩니다.
- 기본 영상이 없는 장이고 `youtube` 도 비었으면 그 구간은 재생할 때 건너뜁니다.
- 말씀과 달리 초안이 없습니다. 저장하면 바로 적용되며, 그날 말씀이 공개되어 있을 때만 화면에 보입니다.

## 응답

성공 `200`:

```json
{ "date": "2026-11-05", "count": 2 }
```

실패는 정의서의 오류 표와 같습니다. 일부러 다시 불러도 개정이 늘지 않으므로 같은 호출을 반복해도 결과는 같습니다.
