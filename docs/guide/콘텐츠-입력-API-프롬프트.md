# 다른 곳에 줄 프롬프트

아래 줄 사이를 모두 복사해 다른 사이트의 개발자나 AI 에게 줍니다. `{사이트 주소}` 만 실제 주소로 바꿉니다. **API 키는 여기에 쓰지 않습니다.**

---

나는 **도전!!! 성경말씀**(주일학교 아이들의 매일 성경 미션 서비스)에 하루치 말씀과 퀴즈를 넣는 프로그램을 만들려고 한다.
아래 API 명세대로 연동 코드를 작성해 줘. 명세에 없는 주소나 칸은 지어내지 말고, 모르는 것은 나에게 물어봐. 내가 쓰는 언어와 환경을 모르면 코드를 쓰기 전에 먼저 물어봐.

## 지켜야 할 것
- API 키는 환경 변수 `CONTENT_API_KEY` 에서 읽는다. 코드 · Git · 로그 · 채팅에 키를 쓰지 않는다. 나에게 키 값을 묻지 않는다.
- 서버 쪽 코드에서만 부른다. 브라우저 자바스크립트나 앱에서 직접 부르지 않는다.
- 한 번 호출에 하루치 한 건. 여러 날은 날짜마다 차례로 부른다.
- 시험은 앞으로 올 날짜에 `publish: false`(초안)로 한다. 초안은 참여자에게 보이지 않는다. 공개는 내가 시킬 때만 한다.
- 공개한 날을 초안으로 되돌리는 방법은 없다. 이미 공개된 내용을 덮어쓰기 전에 나에게 확인한다.

## 공통
- 주소 앞부분: `https://{사이트 주소}`
- 메서드 `PUT`, 헤더 `Content-Type: application/json`, `X-Api-Key: {키}`, 본문은 UTF-8 JSON
- 주소의 `{date}` 는 콘텐츠가 나올 날, `yyyy-MM-dd`
- 같은 날을 다시 부르면 그날 내용을 바꾼다. 그날 이미 미션을 한 사람의 기록과 점수는 그대로다.
- 공개된 날은 부를 때마다 개정이 하나 늘어나므로, 성공한 호출을 반복하지 않는다.
- 숫자 칸은 숫자로 보낸다. `publish` 는 기본값을 쓰려면 칸을 뺀다(`null` 금지).
- 읽기 · 지우기 API 는 없다.

## 말씀: `PUT /api/platform/words/{date}`
| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `title` | 글자 | 예 | 화면 맨 위 제목. 100자까지 |
| `book` | 숫자 | 예 | 성경 책 번호. 개역개정 순서로 1 창세기 ~ 39 말라기, 40 마태복음 ~ 66 요한계시록 |
| `startChapter`, `startVerse` | 숫자 | 예 | 읽을 범위의 시작 장 · 절 |
| `endChapter`, `endVerse` | 숫자 | 예 | 끝 장 · 절. 한 절이면 시작과 같게. 끝이 시작보다 앞이면 안 된다 |
| `summary` | 글자 | 예 | 아이들이 읽는 오늘 이야기. 20,000자까지. `\n` 은 줄바꿈으로 보이고, 처음에 3줄만 보이므로 첫 3줄에 핵심을 쓴다. HTML · 마크다운 불가 |
| `commentary` | 글자 | | 지도용 해설. 20,000자까지. 지금은 참여자 화면에 나오지 않는다 |
| `publish` | 참 · 거짓 | | 기본 `true` 공개, `false` 초안 |

서버는 장이 그 책의 장 수 안인지는 검사하지만, **절이 그 장에 실제로 있는지는 검사하지 않는다.** 절 번호는 보내기 전에 확인해야 한다.

```json
{ "title": "믿음의 시작", "book": 1, "startChapter": 12, "startVerse": 1, "endChapter": 12, "endVerse": 9, "summary": "아브람은 말씀을 믿고 길을 떠났어요.", "publish": false }
```

## 퀴즈: `PUT /api/platform/quizzes/{date}`
| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `question` | 글자 | 예 | 문제. 1,000자까지. 앞에 `Q.` 를 붙이지 않는다 |
| `background` | 글자 | | 문제 위 이야기. 4,000자까지. `\n` 하나가 문단 하나 |
| `format` | 글자 | | `Choice` 객관식(기본) 또는 `Text` 주관식. 대소문자를 지킨다 |
| `choices` | 글자 배열 | 객관식 | 보기 2 ~ 4개. 하나에 300자까지 |
| `correctNumber` | 숫자 | 객관식 | 정답 보기 번호. **1부터** 센다 |
| `acceptedAnswers` | 글자 배열 | 주관식 | 맞는 답 1개 이상. 하나에 200자까지. 공백 · 문장부호 · 영문 대소문자는 무시하고 비교한다 |
| `explanation` | 글자 | | 해설. 4,000자까지. 맞히거나 기회를 다 쓴 뒤에 보인다 |
| `publish` | 참 · 거짓 | | 기본 `true` 공개, `false` 초안 |

퀴즈는 화면에 "이날 말씀에서 한 문제"로 나오므로 같은 날 말씀 내용으로 만든다.

```json
{ "question": "아브람은 누구의 말씀을 듣고 떠났나요?", "format": "Choice", "choices": ["하나님", "아버지", "왕"], "correctNumber": 1, "explanation": "하나님이 말씀하셨어요(창 12:1).", "publish": false }
```

## 응답
성공 `200`: `{ "date": "2026-11-05", "id": 123, "status": "Published 또는 Draft", "created": true 또는 false }`

실패: `{ "code": "...", "message": "...", "errors": { "칸 이름": "안내" } }`. `errors` 는 `Invalid` 일 때만 있다.

| 상태 | `code` | 뜻 | 처리 |
|---|---|---|---|
| 400 | `BadDate` · `BadJson` · `Invalid` | 날짜 · 본문 · 칸 값이 틀림. 범위 오류는 `errors.range`, 공개된 날을 초안으로 보내면 `errors.status` | 다시 부르지 말고 고친다 |
| 401 | `BadKey` | 키가 없거나 틀림 | 나에게 알린다. 다시 부르지 않는다 |
| 404 | 본문 없음 | 주소가 틀렸거나 서버에 키 설정이 없음 | 나에게 알린다 |
| 503 | `NotReady` | 서버 설정이 빠짐 | 나에게 알린다 |
| 500 · 네트워크 오류 | | 일시적 오류 | 잠시 뒤 몇 번만 다시 부른다 |

실패한 날짜와 `errors` 를 기록해서 나에게 보여 줘.
