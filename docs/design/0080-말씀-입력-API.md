# 0080. 말씀 입력 API

- 상태: **확정**(2026-11-04, 사용자: "오늘의 말씀 입력하는 api 개발해줘")
- 관련: R-120 ~ R-124, R-126, ADR 0079(퀴즈 입력 API)

## 결정
1. 하루치 공용 말씀을 `PUT /api/platform/words/{yyyy-MM-dd}` 로 넣는다. 같은 날을 다시 부르면 그날 말씀을 바꾼다.
2. 키(`X-Api-Key`) · 서버 설정 · 만든 사람 · 새 개정 · 응답 모양은 ADR 0079 와 같다. 키도 같은 것을 쓴다.
3. 관리 화면은 만들지 않는다. 말씀은 기존 플랫폼 공용 콘텐츠 화면에서도 넣을 수 있다.
4. DB 바꿈 없음. 범위는 공용 말씀만 — 기도 · 암송 · 부서 덮어쓰기는 범위 밖.

## 호출
`PUT https://{사이트}/api/platform/words/2026-11-05` · `Content-Type: application/json` · `X-Api-Key: {키}`

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `title` | 글자 | 예 | 제목, 100자까지 |
| `book` | 숫자 | 예 | 성경 책 번호, 1 ~ 66 |
| `startChapter` · `startVerse` | 숫자 | 예 | 시작 장 · 절 |
| `endChapter` · `endVerse` | 숫자 | 예 | 끝 장 · 절 |
| `summary` | 글자 | 예 | 오늘 이야기, 20,000자까지 |
| `commentary` | 글자 | | 해설, 20,000자까지 |
| `publish` | 참 · 거짓 | | 기본 `true`(공개), `false` 면 초안 |

장은 그 책의 장 수 안이어야 하고 끝이 시작보다 앞이면 안 된다(`errors.range`). 절은 1 ~ 176 만 보고, 그 장에 실제로 있는 절인지는 보지 않는다(화면 입력과 같음).

## 응답
ADR 0079 와 같다. `400` 의 `errors` 칸 이름만 위 표를 따른다.
