# 0136 「나의 도전」 화면 신설 — 홈 상단 포인트 링 · 현황 카드 이동

- 날짜: 2026-11-23 · 상태: 결정(사용자 "A로 하고 b의 이번주 를 a에 추가해서 확정")
- 관련: ADR 0133(통합 카드) · 0135(포인트 띠) · 0134(선물 카드) · 0132(가족팀) · 0076(R-190)
- 시안: `docs/design/시안/나의도전-확정-A링히어로-이번주추가.html`

## 결정

1. **홈 상단 포인트 링(B안)** — `도전 성경말씀` 오른쪽 빈자리. 링 안에 포인트(점)와 지금 성장 단계, 아래 한 줄은 다음 단계까지 남은 점수.
   호 길이 = `PointMath.GrowthOf(...).Percent`(그 단계 안에서 자란 정도). 참여자만, 손님은 없다.
2. **누르면 `/{slug}/challenge`** — 새 화면 「나의 도전」.
3. **새 화면 = A안 링 히어로 + B안 「이번 주」** — 큰 링(150) + 단계 눈금 → 이번 주 일~토 막대 → 오늘 미션 → 프로그램 진행 → 참여자 숫자.
4. **홈에서 빼는 것** — 「나의 도전 현황」 카드(오늘 미션 · 진행 · 포인트 띠 · 참여자). 홈은 링 하나로 대신한다.
5. **홈에 그대로 두는 것** — 선물 대상자 카드 · 우리 가족팀(사용자 요청: 새 화면에 넣지 않는다).
6. **값의 출처** — 점수 `HomeView.SeasonPoints`, 단계 `Rules.GrowthStages`(R-190). 코드에 단계 이름 · 경계 점수를 쓰지 않는다.

## 구현

- `Services/ChallengeCardService.cs` — `PointRing(Points, Growth, Href)` · `RingOf(data, slug)` · `WeekBar(Day, Points, AllFour, Height)` · `WeekOf(...)` · `ChallengeCard.Week` 추가, `GrowthView.Percent` 노출.
- `Pages/Shared/_PointRing.cshtml` — 홈 92 · 새 화면 150 두 크기.
- `Pages/Mission/Challenge.cshtml(.cs)` — `@page "/{slug}/challenge"`.
- `Pages/TenantHome.cshtml` — 히어로를 `vb-hero-row` 로 감싸 링을 오른쪽에, 카드 partial 제거.
- `Pages/Index.cshtml` — 부서 하나인 사람도 같은 규칙(카드 제거).
- `landing.css` — `.vb-ring` · `.vb-ch` 계열.
- 테스트: `HomeMainTests` — 홈에 카드 없음 + `/{slug}/challenge` 링크, 새 화면에 미션 · 진행 · 이번 주 · 선물/가족팀 없음.

## 하지 않은 것

- 선물 · 가족팀은 새 화면에 넣지 않는다(각자 화면 유지).
- `/points`(내 점수 달력)는 그대로 둔다.

## 2026-11-24 정리(사용자 확정 시안 `시안/나의도전-정리-*.png`)
- ① 「프로그램 진행」 세 줄을 같은 모양으로(이름 · 오른쪽 상태 · 막대 · 숫자 줄, 시작 전은 빈 막대 + 오른쪽 「시작하기 ›」, 회색 박스 없음)
- ② 「오늘 미션」 네 칸에 프로그램 색(말씀 초록 · 퀴즈 파랑 · 기도 분홍 · 암송 주황): 대기 = 옅은 바탕, 완료 = 진한 색. 칸에 `Key` 를 넣어 `k-word` 등 클래스로 고른다.
- ③ 링은 홈(168)보다 크게 — 휴대폰 190 · 데스크톱 210. ④ 단계 이름은 눈금 칸 가운데. ⑥ 「다음 단계(새싹)까지 400점」.
- **버그 수정**: 「이번 주」 막대가 하나도 안 그려졌다 — 막대 높이를 격자 칸 안의 `height: N%` 로 줘서 0px 로 계산됨(0점인 날도 6% 막대가 안 보였다). 칸을 flex 열로 바꾸고 높이를 `calc((100% - 18px) * var(--h) / 100)` 로 계산(`--h` 는 서버가 주는 0 ~ 100). 테스트 `ScreenStyleGuardTests`.
- **들어가기**(2026-11-24 사용자): 프로그램 진행 세 줄 오른쪽 아래에 **항상** 「들어가기 ›」(「시작하기」 아님). 「시작했는지」 판단이 통독(기록이 있으면)과 필사 · 기도365(1건 이상)가 달라 통독만 버튼이 없던 문제를 판단과 상관없이 버튼을 두어 없앴다. 「시작 전」 글자는 상태 표시로 그대로. 성경미션은 「오늘 미션」 카드 제목 줄 오른쪽 「들어가기 ›」(A안, 시안 나의도전-미션들어가기)로 `/{부서}/word-mission` 이동.
