# 화면 시안

실제처럼 동작하는 반응형 단독 시안(`*-단독시안.html`)이 기준이다. 브라우저로 바로 열 수 있다.
사용자와 한 장씩 다시 확정했다(2026-10-22 ~ 10-23). 예시 날짜는 2027년 1월 5일(화), 예시 사람은 김철수(유년부 · 사랑반)와 가족이다.
사람 이름은 모두 지어낸 예시다.

`도전성경말씀-화면시안.pdf` · `이미지/` · `원본/` 은 그 전의 평면 시안(캔버스)이다. 참고용으로만 둔다.
