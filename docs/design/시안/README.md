# 화면 시안

실제처럼 동작하는 반응형 단독 시안(`*-단독시안.html`)이 기준이다. 브라우저로 바로 열 수 있다.
사용자와 한 장씩 다시 확정했다(2026-10-22 ~ 10-23). 예시 날짜는 2027년 1월 5일(화), 예시 사람은 김철수(유년부 · 사랑반)와 가족이다.
사람 이름은 모두 지어낸 예시다.

`도전성경말씀-화면시안.pdf` · `이미지/` · `원본/` 은 그 전의 평면 시안(캔버스)이다. 참고용으로만 둔다.

## 아직 단독 시안이 없는 1차 화면

구현하면서 위 시안들과 같은 모양으로 만든다(필요하면 먼저 시안을 보여 준다).

- 부서 고르기(`/account/tenants`), 보호자 화면, 가족과 함께할 부서 고르기(0046)
- 부서 관리: 진급 요청, 콘텐츠 달력(보기), 시즌, 이름 · 색, 통독 현황
- 플랫폼: 플랫폼 홈, 공용 콘텐츠, 성경 데이터, 기본 규칙, 계정 찾기
