세 시안의 차이 · 공통 규칙

A · 조용한 한 줄

  • 회색 바탕 · 글자만 — 말씀 카드와 톤이 같음
  • 상세 = 첨부 카드 한 장 그대로
  • 가장 단순 · 가장 적게 말함

B · 아이콘 + 미니 눈금

  • 🎁 타일 + 두 줄 문장 + 오른쪽 3칸 눈금
  • 상세 맨 위에 진행 스트립 하나 추가
  • 「남은 일」이 한 줄에서 바로 보임

C · 상태 칩

  • 인원 + 칩(준비 중 / 받았어요)
  • 상세에 필터 탭 — 명단이 길어져도 안전
  • 칩 색은 받았어요=초록 하나만
  • 자리 — 「오늘의 말씀」 카드 바로 아래, 가족팀 초대 배너 위. 첫 화면(/)과 부서 홈(/{slug}) 둘 다 같은 부품.
  • 한 줄까지만 — 홈에서는 사람 이름·선물 이름을 꺼내지 않는다(길어지면 「오늘의 말씀」이 밀린다). 상세 페이지가 그 몫을 맡는다.
  • 누르면 새 페이지(예: /{slug}/gifts)로 이동 — 뒤로 「홈으로」. 지금 있는 /{slug}/gift-board(전체 명단)는 그대로 두고, 그 안의 「더보기」가 이 상세로 이어진다.
  • 상세 화면 규칙 — 사람마다 한 칸, 이름 · 개인 배지 · 선물 이름 · 3칸 눈금(골랐어요 → 샀어요 → 줬어요) · 오른쪽 상태 알약. 받은 사람은 옅은 초록 바탕 + 초록 「받았어요」.
  • 손님 · 대상자 없음 — 손님에게는 로그인 안내 한 줄, 대상자가 없으면 홈에서 카드를 아예 그리지 않는다.
