시안 A-2 가 바꾼 것

  1. 네 프로그램을 모두 소개합니다. 기존 랜딩에는 미션 · 통독만 있었고, 필사와 365 기도는 빠져 있었어요(ADR 0113 구조와 불일치).
  2. 프로그램마다 실제 동작을 짧게 — 미션은 네 항목과 3,000/5,000/8,000점 축하, 통독은 1,189장 · 번역 3종 · 몇 독째, 필사는 점수 없음 · 완필 선물, 365 기도는 366편 · 하루 한 편 · 학생 제외.
  3. 미리보기 카드를 넣어 글만 읽지 않고 "내 화면에선 이렇게 보이겠구나"를 짐작할 수 있게 했습니다.
  4. 누가 쓰는지 칩(학생 · 학부모 / 부모 · 교사)으로 역할별 기대를 맞췄습니다. 365 기도가 학생에게 안 보인다는 사실도 여기서 전달됩니다.
  5. 첫 화면은 그대로 오늘의 말씀 + 로그인이 주인공이고, 관리자 로그인은 보조 칩으로 유지했습니다(R-364 · R-367).
  6. 부서별 켜기/끄기를 접이식으로 안내해, 프로그램이 4개로 고정이 아니라는 점을 설명합니다.
