시안 B 가 바꾼 것

  1. 부서가 첫 화면의 단위입니다. 로그인 폼보다 "우리 부서"를 먼저 고르게 해서, 부서가 늘어도 화면이 무너지지 않아요.
  2. 관리자 · 대표 학생 로그인을 부서 카드 안으로 흡수했습니다. 맨 아래에 쌓이던 3중 로그인 블록이 사라지고 R-364 · R-367의 "항상 보임"은 유지됩니다.
  3. 부서별 오늘 참여 인원을 보여 줘서 "지금 살아 있는 부서"인지 한눈에 판단할 수 있어요.
  4. 참여 코드 찾기를 검색 옆에 고정했습니다. 40개 부서가 넘어가도 검색 두 글자로 도달합니다.
  5. 부서 목록이 길어지면 카드가 2열로 늘어나고, 마지막에 "목록에 없어요" 출구를 두었습니다.
  6. 말씀·통계·가입은 부서 선택 아래로 내려 주 행동을 방해하지 않습니다.
주의 — 부서 이름·오늘 참여 인원을 로그인 전에 노출하는 범위는 개인정보 검토가 필요합니다(인원 수만, 이름 없음).
