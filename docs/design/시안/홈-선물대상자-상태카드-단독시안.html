세 시안의 차이

A · 단계 요약 + 최근 명단

  • 3숫자(살 것 · 줄 것 · 받았어요)로 규모를 먼저
  • 최근 3명, 이름 · 선물 · 상태 칩
  • 지금 홈의 진행 카드와 같은 리듬

B · 3단계 스텝 막대

  • 막대 하나로 골랐어요 → 샀어요 → 줬어요
  • "몇 명 남았나"를 문장으로 한 번 더
  • 관리자가 처리할 양이 바로 보임

C · 사람별 카드 + 눈금

  • 사람마다 카드 하나, 3칸 눈금
  • 완료는 옅은 초록 바탕으로 한 번에 구분
  • 카드가 커서 3명까지만 — 더보기로
  • 상태 글자 — 골랐어요 / 샀어요 / 받았어요 (체크 표시 없이 바탕색 + 글자색). 받은 선물은 받은 지 30일까지(R-297).
  • 가격은 넣지 않는다 — 아이 · 학부모 화면이라 관리 화면의 원 · 쿠팡 링크는 두지 않는다.
  • 누구에게 — 부서 홈과 첫 화면(`/`) 모두. 승인된 소속 · 임시 부서 아님. 손님에게는 "로그인하면 보여요".
  • 자리 — 나의 도전 현황 카드 바로 아래, 가족팀 카드 위.
