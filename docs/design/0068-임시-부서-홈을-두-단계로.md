# 0068. 임시 부서 홈을 두 단계로 나누고, 미션은 따로 "미션 화면"에서

- 상태: **확정** (2026-10-30, 사용자와 하나씩 정함 · 시안 임시부서-홈-두단계 "확정"). 구현은 사용자가 시작하라고 할 때
- 관련: 0064(가입하면 임시 부서 "처음 오신 분"), 확정 시안 임시부서-홈-모바일(2026-10-29, 이 결정으로 바뀜), R-171 ~ R-174

## 맥락
2026-10-29 확정한 임시 부서 홈 휴대폰 시안은 한 화면에 윗부분(인사 · 시작까지 3단계)과 아랫부분(오늘의 말씀 · 성경말씀 · 성경통독 · 이번 주 기록 · 계정 줄)을 모두 담았다.
처음 온 사람에게는 할 일이 너무 많아 보인다. 사용자는 "지금 할 일 하나"만 보이게 상태별로 나누기로 했다.

## 결정(사용자, 2026-10-30)
1. **1단계 — 아직 부서를 고르지 않음**(처리 안 된 참여 신청이 없음): 홈(`/welcome`)은 **윗부분만** 보인다.
   - 하늘색 머리말 · "○○님, 반가워요!" · 시작까지 3단계(가입 ✓ → **내 부서 찾기 · 지금 할 일** → 관리자 승인 · 다음 단계).
   - 큰 버튼 **[내 부서 찾기]** → 부서 고르기(`/join`).
   - 그 아래 작은 링크 **[먼저 미션 해 보기]** → 미션 화면. 0064 대로 부서를 찾는 동안에도 미션은 할 수 있다(사용자 답 "막지 않는다").
2. **2단계 — 부서를 골라 신청했고 승인 기다림**: 홈은 **진행 상태**만 보인다.
   - 시작까지 3단계(가입 ✓ → 참여 신청 ✓ ○○부 → **관리자 승인 · 기다리는 중**).
   - 큰 버튼 **[미션 수행하러 가기]** → 미션 화면, 작은 버튼 [신청 보기] → `/join`.
3. **미션 화면(새 화면)**: 지금 홈의 **아랫부분 그대로** — 오늘의 말씀(흰 말씀 카드) · 오늘 할 것(성경말씀 · 성경통독 카드) · 이번 주 나의 기록 · 다음 축하 · 계정 줄.
   - 머리말은 홈과 같고, 맨 위에 "← 처음 화면"으로 홈에 돌아간다.
   - 주소는 구현 때 정한다(제안: `/welcome/today`). 이미 있는 미션 홈(`/welcome/word-mission`)과는 다른 화면이다(사용자 답 1).
4. 바뀌지 않는 것: 임시 부서의 규칙(0064 — 기록 · 점수는 승인 때 부서로 옮김), 일반 부서 홈, 성경통독 카드 모양.

## 고침(사용자, 2026-10-30 — 시안 임시부서-홈-고친곳 "확정")
구현(feature/lobby-two-steps, 2026-10-30) 뒤 휴대폰에서 보고 바꾼 5가지.
1. **머리말**(1 · 2단계 · 미션 화면 공통): "내 부서를 찾는 동안 / 처음 오신 분"을 없애고, 로그인 전 첫 화면과 같은 **"대한예수교장로회 / 잠실새내교회 ↗"**(`https://www.saenae.org/` 새 창) + 오른쪽 오늘 날짜.
2. **문장**: 인사 아래 "먼저 내가 참여할 부서를 신청해요."(교회를 찾는 것이 아니라 부서만 신청). 단계 설명은 "목록에서 내 부서를 골라 신청해요".
3. **"내 부서 찾기" → "내 부서 참여"**: 3단계 카드의 둘째 단계 이름 · 큰 파란 버튼 · 임시 부서 계정 줄, 세 곳 모두.
4. **1단계 "먼저 미션 해 보기"**: 작은 링크 → **흰 큰 버튼**(파란 [내 부서 참여] 바로 아래, 같은 높이).
5. **맨 아래(모든 부서 홈)**: 계정 줄(내 계정 · 부서 바꾸기 또는 내 부서 참여 · 로그아웃)을 **가운데 정렬**하고 그 아래에 **"© {올해} 잠실새내 · 주일학교"**(해가 바뀌면 자동).
