# ADR 0139 — 부서 홈(`/{slug}`)에서 「우리 가족팀」 점수 카드 삭제

- 날짜: 2026-11-23
- 상태: 확정 (사용자 "가족팀 홈루트에서 삭제 안됨. 삭제해")
- 앞선 결정: ADR 0132(가족팀 홈 아래 복원), ADR 0137(첫 화면 `/` 에서 같은 카드 삭제)

## 배경

ADR 0137 에서 첫 화면(`/`)의 「우리 가족팀」 카드(`.hmx-fam`)는 뺐지만, 부서 홈(`/{slug}`)에는 그대로 남아 있었다.
사용자가 부서 홈 스크린샷(「우리 가족팀 · 7,101점 / 이새내네 가족 · 다음 가족 축하까지 899점」)을 보내며 삭제를 요청.

## 결정

부서 홈(`Pages/TenantHome.cshtml`)의 가족팀 블록에서 **`.hmx-fam` 점수 카드만** 뺀다.

- 남기는 것: 초대 배너(`.hmx-inv`)와 만들기 유도(`.hmx-make`) — 첫 화면(`/`)과 같은 구성.
- 만들기 유도 조건을 `Model.Family is null && Model.FamilyCanJoin` 으로 좁혔다.
  팀이 이미 있는 사람에게 "만들어 보세요"가 뜨면 안 되기 때문(카드 삭제로 `else if` 순서가 바뀐 데 따른 보정).
- 팀 점수 · 구성원 · 다음 축하까지는 가족팀 화면(`/{slug}/family-team`)과 순위 가족팀 탭에서 그대로 본다. 데이터 · 서비스는 손대지 않는다.
- `Mission/Home.cshtml`(옛 미션 홈)의 `.hFam` 입구는 성격이 달라(미션 홈 전용) 그대로 둔다.
- `.hmx-fam` CSS(`home.css`)는 지우지 않는다 — 다른 화면에서 재사용될 수 있고, 죽은 규칙이 해롭지 않다.

## 테스트

- `FamilyTeamTests` — `/jamsil-kids` 에 「우리 가족팀」 없음, `href="/jamsil-kids/family-team"`(☰ 메뉴)은 유지.
- `FamilyJoinTests` — 팀에 합류한 뒤에도 홈에 카드 · 만들기 유도가 없고, 가족팀 화면에서 「구성원 2명」이 보인다.
- `HomeMainTests` 의 만들기 카드 테스트(팀 없음)는 그대로 통과.

## 결과

부서 홈은 「오늘의 말씀」 → 선물 한 줄 알림 → (초대 배너 / 만들기 유도) 순서로 짧아졌고, 첫 화면(`/`)과 구성이 같아졌다.
