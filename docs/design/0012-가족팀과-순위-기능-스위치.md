# 0012. 가족팀 · 순위는 포함하되 영역별 켜기/끄기, 가족팀은 같은 영역 안에서만

- 상태: 확정 (2026-10-21)
- 원래 결정: D12
- 관련: R-80 ~ R-97, 0003

## 맥락
순위 · 가족팀은 꾸준함을 북돋지만, 부서에 따라 경쟁 분위기를 원하지 않을 수 있다.
또 현행 가족팀은 한 부서 안에서만 동작했다.

## 결정
- 순위 · 가족팀 둘 다 만든다.
- 영역 설정의 **기능 스위치(FeatureToggle)** 로 켜고 끈다. 기본값: 둘 다 켬.
- 가족팀 구성원은 **같은 영역의 참여자**만. 유년부 아이 + 초등부 아이는 한 팀이 될 수 없다.

## 결과
- 스위치가 꺼진 영역에서는 해당 화면 · API 를 막는다(화면 숨김만으로 막지 않음).
- 형제가 다른 영역이면 가족팀으로 묶이지 않는다. 대신 보호자는 영역 전환으로 각 자녀를 본다.
- 06 문서에 따라 순위 · 가족팀은 2차로 미룰 수 있다.
