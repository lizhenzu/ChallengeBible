# 0044. 홈 메인에서 프로그램을 고른다

- 상태: 확정 (2026-10-22, 사용자 요청)
- 대체 대상: 0039 결정 5 의 "둘이면 아래 탭으로 오간다"
- 관련: 0038(부서별 이름), 시안 "홈 메인", "미션 홈"

## 결정
1. 영역 주소 `/{slug}` 는 **홈 메인**이다. 로그인 후 처음 보는 화면이다.
   - 머리말: 왼쪽 부서 이름 ▼(누르면 부서 고르기), 오른쪽 날짜. 아래 얇은 선 하나.
   - 인사, 그리고 **프로그램 카드**: 도전!!!성경말씀(오늘 미션 n/4 · 남은 미션 · 올해 점수), 도전!!!성경통독(진도율 · 회차 · 이어 읽기 장).
   - 아래: 내 계정 · 비밀번호 바꾸기 · 로그아웃.
2. 영역이 프로그램을 **하나만** 켰으면 홈 메인을 건너뛰고 그 프로그램으로 바로 간다.
3. 각 프로그램 화면의 머리말은 왼쪽 **"홈으로"**, 오른쪽 날짜만 둔다. 부서 전환 · 프로그램 전환 버튼을 프로그램 화면에 두지 않는다.
4. 주소: 성경말씀 `/{slug}/word-mission`, 성경통독 `/{slug}/reading`.

## 결과
- 부서를 오가는 곳은 홈 메인 한 곳이다.
- API · 화면 계약의 영역 홈 · 미션 홈 주소를 이에 맞춘다.
