# 0063. 장 듣기 영상은 옛 Bible2 에서 옮기고, 화면 안 재생 창에서 무한 반복한다

- 상태: 데이터 · 표는 진행(2026-10-25, 사용자 "위처럼 이관"), 화면은 시안 통독-본문읽기-듣기영상 확정 뒤 구현
- 관련: R-166(장마다 듣기 · 해설 영상), 0041 · 0043(Bible2 에서 한 번 옮겨 온다), 0062(책 개요 · 개요 영상), 논리 설계 ChapterMedia

## 맥락
옛 Bible2 성경 읽기 화면에는 "🎬 미디어" 줄이 있다: 그 장의 **🎧 유튜브 듣기**(`dbo.eBibleYouTuBu`, 1,189장, 장마다 1개)와
그 책의 **🎬 개요 해설 1 · 2**(책 개요 표의 영상). 누르면 화면 위 창에서 유튜브가 재생되고 끝나면 처음부터 다시 재생된다(정지 · 닫기).
옛 표의 `TimeMM · TimeSS` 는 **영상 길이**다(옛 코드 주석: 시작 위치로 쓰면 끝에서 시작해 안 나옴 → 항상 처음부터).

## 결정
1. 논리 설계의 **`app.ChapterMedia`**(Id, BookId, Chapter, Kind[Listen · Overview], SortOrder, YoutubeVideoId, Title)에 `DurationSec`(영상 길이, 선택)을 더해 만든다. 고유 (BookId, Chapter, Kind, SortOrder). 플랫폼 참조 데이터(TenantId · RLS 없음).
2. 옮기기는 0062 와 같은 방식: 옛 DB `chaptermedia-1-export-old.sql`(읽기만) → 새 DB `migrate-chaptermedia.sql`(표) → `chaptermedia-2-import-new.sql`(붙여 넣고 실행).
   - 주소는 유튜브 영상 번호(11자)로 바꿔 넣는다(전체 주소 · youtu.be · embed · shorts · 번호만 모두). 번호를 못 찾은 줄 · 없는 장은 넣지 않고 목록으로 보여 준다.
   - 책 이름이 안 맞으면 아무것도 넣지 않는다(옛 "요한1서 · 2서 · 3서" = "요한일서 · 이서 · 삼서"). 다시 실행하면 장 듣기(Listen) 줄을 지우고 다시 넣는다.
3. 화면(시안 확정 뒤): 통독 본문 · 말씀 성경 읽기의 장 진도 아래 "듣기 · 영상" 줄 — 🎧 유튜브 듣기(그 장) + 🎬 개요 해설 1 · 2(그 책). 개요 영상은 이 줄로 옮기고 책 개요 카드 안 "관련 영상"은 뺀다.
   누르면 화면 안 재생 창(휴대폰은 아래에서 올라오는 판): 처음부터 재생, 끝나면 다시 처음부터(무한 반복), [정지] [닫기]. 영상이 없으면 줄을 숨긴다.
4. 장 해설(Kind = Overview) 영상은 지금 데이터가 없다. 표는 받을 수 있게 두고, 생기면 같은 줄에 보인다.

## 결과
- 마이그레이션 `ChapterMedia`(표 하나). 실DB 순서: 표 SQL → 옮기기 SQL → 게시.
- 실DB 에서 되돌림 트랜잭션으로 표 만들기 + 옮기기를 미리 실행해 봄(주소 모양 4가지 · 요한1서 · 없는 장 · 주소 아닌 값, 흔적 0).
