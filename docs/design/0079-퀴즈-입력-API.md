# 0079. 퀴즈 입력 API

- 상태: **확정**(2026-11-04, 사용자: "성경퀴즈를 API 호출해서 넣고 싶다. 입력은 하루씩")
- 관련: R-120 ~ R-125, 관리 콘텐츠 편집(`ContentAdminService`)

## 결정
1. 하루치 공용 퀴즈를 `PUT /api/platform/quizzes/{yyyy-MM-dd}` 로 넣는다. 같은 날을 다시 부르면 그날 퀴즈를 바꾼다(여러 번 불러도 결과가 같음).
2. 프로그램이 부르므로 쿠키 대신 헤더 `X-Api-Key`. 키는 Git 에 두지 않고 서버 설정에만 둔다(32자 이상). 키가 없으면 API 는 꺼진 것(404).
3. 저장은 화면과 같은 서비스를 쓴다. 공개된 날을 다시 넣으면 새 개정, 지난 기록은 예전 개정을 가리킨 채 그대로(R-124).
4. 만든 사람(`CreatedByAccountId`)은 설정 `ContentApi:ActorAccountId` 의 활성 플랫폼 관리자. 아니면 503.
5. 플랫폼 관리자는 화면 **플랫폼 › 퀴즈 넣기**(`/platform/quiz-input`, 시안 `qput.png`)에서 날짜를 고르고 같은 JSON 을 붙여 넣는다. 키를 브라우저에 두지 않도록 주소를 부르지 않고 같은 코드를 서버에서 부른다 — 키 설정이 없어도 되고, 만든 사람은 로그인한 관리자.
6. DB 바꿈 없음. 범위는 공용 퀴즈만 — 말씀 · 기도 · 암송 · 부서 덮어쓰기는 범위 밖.

## 서버 설정
| 이름(appsettings) | 환경 변수 | 값 |
|---|---|---|
| `ContentApi:Key` | `ContentApi__Key` | 32자 이상 임의 문자열 |
| `ContentApi:ActorAccountId` | `ContentApi__ActorAccountId` | 플랫폼 관리자 계정 번호 |

## 호출
`PUT https://{사이트}/api/platform/quizzes/2026-11-05` · `Content-Type: application/json` · `X-Api-Key: {키}`. HTTPS 로만 부른다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `question` | 글자 | 예 | 문제, 1,000자까지 |
| `background` | 글자 | | 배경, 4,000자까지. 줄바꿈(`\n`) 하나가 문단 하나 |
| `format` | `Choice` · `Text` | | 객관식 · 주관식, 기본 `Choice` |
| `choices` | 글자 배열 | 객관식 | 보기 2 ~ 4개, 300자까지 |
| `correctNumber` | 숫자 | 객관식 | 정답 보기 번호, **1부터** |
| `acceptedAnswers` | 글자 배열 | 주관식 | 맞는 답, 200자까지 |
| `explanation` | 글자 | | 해설, 4,000자까지 |
| `publish` | 참 · 거짓 | | 기본 `true`(공개), `false` 면 초안 |

```json
{
  "question": "삼손이 기둥을 붙잡고 드린 마지막 기도에서, 하나님께 구한 말은 무엇인가요?",
  "background": "눈을 잃고 옥에서 맷돌을 돌리던 삼손은 다곤 신전의 잔치 자리로 끌려 나왔습니다.",
  "format": "Choice",
  "choices": ["나를 이 옥에서 건져 주소서", "내 눈을 다시 보게 하소서", "이번만 나를 강하게 하소서", "내 원수를 용서하소서"],
  "correctNumber": 3,
  "explanation": "삼손은 이번만 강하게 해 달라고 구했습니다(삿 16:28).",
  "publish": true
}
```

## 응답
| 상태 | `code` | 뜻 |
|---|---|---|
| 200 | | `{ "date", "id", "status", "created" }` — `created` 는 그날 퀴즈를 처음 만들었는지 |
| 400 | `BadDate` · `BadJson` · `Invalid` | `Invalid` 는 `errors` 에 칸별 안내. 공개된 날을 `publish: false` 로 넣어도 여기(`errors.status`) |
| 401 | `BadKey` | 키가 없거나 틀림 |
| 404 | | 서버에 키가 설정되지 않음 |
| 503 | `NotReady` | `ContentApi:ActorAccountId` 가 없거나 활성 플랫폼 관리자가 아님 |
