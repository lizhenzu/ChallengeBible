## 3. PC 에서만 할 수 있는 일 (아직 안 함)

사용자 PC(`C:\WorkSpace\ChallengeBible`)에서:

1. `dotnet user-secrets set "ConnectionStrings:App" "<접속 문자열>" --project src/ChallengeBible.Web` — 사용자가 직접 입력. **접속 문자열 · 비밀번호를 채팅에 받지 않는다.**
2. `dotnet tool restore` → `dotnet ef database update --project src/ChallengeBible.Infrastructure --startup-project src/ChallengeBible.Web` (마이그레이션: Initial, Rls, Missions, GuardianLinks)
3. 실제 SQL Server(SmarterASP, SQL 2022)에서 RLS 격리 확인
4. SmarterASP 배포

자세한 것은 `처음-실행-순서.md`.

## 5. 알아 두면 시간 아끼는 것

- 셸 명령에 한글을 넣으면 실패할 수 있다 → 한글은 파일 편집 도구로 쓰고, 셸 명령은 영어로만.
- Razor 에서 `@Model.X일` 처럼 한글이 바로 붙으면 이름으로 읽힌다 → `@(Model.X)일`. 조사는 `Ui.IGa(...)`.
- 한글이 HTML 에서 이스케이프되지 않게 `WebEncoderOptions` 를 `UnicodeRanges.All` 로 해 두었다.
- 날짜 표기는 `"M'/'d"` (ko 문화권 구분자가 `-`).
- 점수 값은 코드에 쓰지 않고 RuleSet 에서 읽는다. DB 의 GETDATE() 금지. TenantId 없는 조회 금지.
- 콘텐츠 수정: 공개된 것은 새 개정을 만들고 이전 것은 보관, 초안은 그 자리에서 수정. 퀴즈는 초안 저장 → 보기 추가 → 상태 지정(CK_DailyQuiz_Correct).

## 6. 화면 캡처 방법

1. `CB_SCREENS_DIR=<폴더>` 환경 변수를 두고 `dotnet test --filter ScreenDump` → 화면 HTML(CSS 포함) 저장
2. `node tools/screens/appshots.js <html 폴더 절대경로> <png 폴더 절대경로>` → Edge headless 로 500px 폭 캡처(절대 경로 필수)
3. `node tools/screens/gallery.js <png 폴더> <출력.html>` → 한 장짜리 모음 페이지
