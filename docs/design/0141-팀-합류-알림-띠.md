# 0141 · 팀 합류 · 초대 알림을 「띠」 한 종류로 (2026-11-28)

## 결정
- 사용자 시안 JoinA1 ~ A12 · JoinB · TeamManage 를 따른다. 알림은 미션홈 · 팀보기 맨 위의 **띠**만 쓴다(숫자 배지 · 합류 신청 N 표시 삭제).
- 푸시 알림은 이 앱에 없다. 팀원은 앱을 열었을 때 띠로 신청을 알고, 신청자는 홈 맨 위 결과 띠로 결과를 안다.
- 규칙은 그대로: 한 사람 한 팀 · 교사 · 임원 제외 · 친구팀 학생 2명 · 구성원 누구나 수락 · 선물 받은 팀 잠김.

## 구현
- 저장: 신청 시각은 `DM2_FamilyRequest.CreatedAt` 이 이미 있다. 신청자에게 남기는 결과는 `DM2_FamilyNotice.Kind` 에 `ACCEPTED`(합류) · `REJECTED`(거절) 를 더해 쓴다 — **DB 변경 없음**(마이그레이션 없음). 취소는 취소 화면으로 바로 가므로 저장하지 않는다.
- `FamilyJoinService.BandAsync` 가 띠에 쓸 것을 모은다. `RejectAsync(id, notify)` · `TakeResultAsync` · `RelTime` 추가.
- 화면: `_JoinBand.cshtml`(partial) + `join-band.css/js`, 흐름 화면 `/{부서}/family-join/{sent|result}`(신청 확인 · 합류 · 거절 · 취소). 띠의 수락 · 거절 · 확인 · 다음에 할게요 · 신청 취소는 이 화면으로 POST 한다.
- 결정(사용자): 결과 띠는 화면을 열면 지운다 · 거절 뒤 바로 재신청 · 오래된 신청은 남김 · 시간은 상대 시간 · 대기 띠와 초대 띠는 함께.
