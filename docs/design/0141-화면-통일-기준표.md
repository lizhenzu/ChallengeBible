# 0141 화면 통일 기준표 (홈 화면 기준 · 계속 강화)

- 날짜: 2026-11-24 · 상태: **6판 — 사용자 확정(2026-11-24 "이대로 확정만 한다, 작업은 보류" · 머리줄은 5판에서 확정)**(햄버거 머리 C안은 사용자 확정, 1판 · 2판 규칙은 시안 `시안/화면통일-기준표.png` 를 보고 합의한 안)
- 시안: `docs/design/시안/화면통일-기준표.html · .png`(색 · 글자 · 폭 · 메뉴), `시안/햄버거-머리-표준안.png`(머리 3안 비교)
- **새 개발은 하지 않는다**(2026-11-24 사용자): 기능 · 문구는 그대로, 모양만 홈 루트(첫 화면)에 맞춘다. 화면마다 **시안 먼저 → 확정 → 구현 → 테스트(기능 불변) → 게시 → 폰 확인**.

## 배경
홈 · 나의 도전은 흰 바탕 + 프로그램 4색인데, 옛 화면(미션 홈 · 말씀 · 통독 · 필사 · 365축복기도 · 가족팀 · 계정 · 메뉴)은 머리말 · 색 · 폭 · 글자 크기가 제각각이다. 햄버거 메뉴도 네 곳(첫 화면 · 부서 홈 · 부서 관리 · 플랫폼)이 모두 다르다.

### ④ 머리줄(모든 화면 맨 위, 시안 `시안/머리줄-표준안.png` · `시안/머리줄-오른쪽간격.png`)
- **「도전!!! 성경말씀」 글자는 머리줄에 쓰지 않는다**(관리 · 플랫폼 · 얇은 머리말에서 반복되던 것을 뺌 — 2026-11-24 사용자). 로고는 ☰ 메뉴 머리와 홈 첫머리에만.
- **왼쪽 = A안 경로형**: ☰ + 「상위 › 현재」. **부서 이름(유년부)은 머리줄에 쓰지 않는다**(7판, 부서 이름은 ☰ 메뉴 맨 위). 부서 홈 바로 아래 화면은 「☰ 현재」만(예: ☰ 나의 도전), 미션 하위는 「성경미션 › 기도」(예전 예: 관리 › 예배 안내, 플랫폼 › 부서). 최상위는 소속 이름 하나(부서 홈 = 부서 이름). **예외: 첫 화면은 「대한예수교장로회」 + 「잠실새내교회」 두 줄을 그대로 둔다**(2026-11-24 사용자 "이단이 많으니"). 상위 이름을 누르면 한 단계 위로 간다(예전의 「‹ 홈으로」 · 「돌아가기」 · 「미션홈」을 대신). 긴 이름은 위 단계를 줄이고(…) 현재 화면 이름을 먼저 보인다.
- **오른쪽(6판, 2026-11-24 사용자 확정 · 시안 `시안/머리줄-오른쪽-부서홈버튼.png`)**:
  - **「쪽지 | 이름님」 한 덩어리 알약은 부서 홈과 첫 화면에만** 둔다(알약 안: 편지(안 읽은 점) · 가는 세로선 · 이름님. 편지 = 쪽지, 이름 = 내 계정. 손님은 사람 아이콘 하나). 누르는 칸은 머리줄 높이(56px)까지.
  - **그 밖의 화면은 알약 대신 이동 버튼 하나**(홈 아이콘 + 글자, 누르는 칸 높이 44px 이상 · 15px · 800 · **검정 글자 · 테두리 없음**, 7판). 기본값: 부서 안 하위 화면(나의 도전 · 주보 · 사진첩 · 의견 등) = 「홈으로」, 미션 하위 화면(말씀 · 퀴즈 · 기도 · 암송 · 내 점수 · 순위 · 가족팀) = 「미션홈」(띄어쓰기 없음), 플랫폼 = 「처음 화면」.
  - **부서 밖 화면(쪽지 · 계정 · 참여 신청 등)은 「홈으로」로 고정하지 않는다.** 상황에 따라 그 화면에 맞는 버튼을 쓴다(2026-11-24 사용자). **화면마다 시안에서 오른쪽 버튼을 확인하고 정한다**(「홈으로」는 시안의 기본 자리표시).
  - 로그인 전 화면은 반대 이동 링크 하나(로그인 화면 = 「가입하기」, 그 밖 = 「로그인」).
  - 쪽지 · 내 계정은 알약이 없는 화면에서 ☰ 메뉴(사람 카드 → 내 계정, 「단체쪽지」 항목)로 간다. 안 읽은 쪽지 알림을 다른 화면에서도 보이게 하는 안(☰ 아이콘 빨간 점)은 제안만 해 두고 정하지 않음.
- **머리줄에서 뺀 것의 행선지**: 날짜 → 홈 본문 위쪽 · 글자 「가- 100% 가+」 → 제목 줄(「오늘의 ○○」과 같은 줄)의 오른쪽 끝, 알약이 아니라 **모서리 반지름 10px 둥근 사각형**(8판) · 「부서 홈으로」 · 「처음 화면」 · 「로그아웃」 → ☰ 메뉴.
