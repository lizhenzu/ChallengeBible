# 0141 화면 통일 기준표 (홈 화면 기준 · 계속 강화)

- 날짜: 2026-11-24 · 상태: **3판 — 사용자 확정 진행 중**(햄버거 머리 C안은 사용자 확정, 1판 · 2판 규칙은 시안 `시안/화면통일-기준표.png` 를 보고 합의한 안)
- 시안: `docs/design/시안/화면통일-기준표.html · .png`(색 · 글자 · 폭 · 메뉴), `시안/햄버거-머리-표준안.png`(머리 3안 비교)
- **새 개발은 하지 않는다**(2026-11-24 사용자): 기능 · 문구는 그대로, 모양만 홈 루트(첫 화면)에 맞춘다. 화면마다 **시안 먼저 → 확정 → 구현 → 테스트(기능 불변) → 게시 → 폰 확인**.

## 배경
홈 · 나의 도전은 흰 바탕 + 프로그램 4색인데, 옛 화면(미션 홈 · 말씀 · 통독 · 필사 · 365기도 · 가족팀 · 계정 · 메뉴)은 머리말 · 색 · 폭 · 글자 크기가 제각각이다. 햄버거 메뉴도 네 곳(첫 화면 · 부서 홈 · 부서 관리 · 플랫폼)이 모두 다르다.

## 규칙(기준표)

### ① 색
- 글자 `#1d1d1f` · 글자2 `#56565c` · **보조 글자 `#6e6e75`**(흰 바탕 5.1 : 1, 예전 `#8e8e94` 3.3 : 1) · 선 `#e7e7ea` · 옅은 면 `#f4f4f5` · 흰 바탕.
- 프로그램 색(**면 · 막대 · 점**): 성경미션 `#1f9d55`(옅게 `#e8f6ee`) · 성경통독 `#2f6fe4`(`#eaf1fd`) · 성경필사 `#ea6a1c`(`#fdf0e6`) · 기도365 `#dc3f8a`(`#fcebf3`). 그 프로그램을 가리킬 때만 쓴다.
- **색 글자(옅은 바탕 위, 대비 4.5 이상)** — 미션 `#167a41`(4.8) · 통독 `#1f55c0`(5.9) · 필사 `#b8500d`(4.5) · 기도 `#b02a6a`(5.4). 색 면 위 흰 글자는 진한 면(위 색 글자 값)에서만(주황 면 `#ea6a1c` 위 흰 글자 3.2 는 쓰지 않음).
- 상태: 완료 = 진한 면 + 흰 글자 · 대기 = 옅은 바탕 + 색 글자 · 없음 = 회색. 미션 안의 말씀 / 퀴즈 / 기도 / 암송 = 초록 / 파랑 / 분홍 / 주황.
- **색만으로 구분하지 않는다**(색각 이상): 이름 글자를 항상 함께.

### ③ 햄버거 메뉴(네 곳 같은 뼈대)
- 패널 폭 **320px** 하나.
- **맨 위(머리) — C안 확정**: 1줄 「도전!!! 성경말씀」 로고(+ GROW IN THE WORD) + ✕(44px) — 어디서 열어도 같다. 2줄 "지금 누구인지" 카드(아바타 · 이름님 · 소속 한 줄 · 내 정보 ›). **손님**은 같은 자리에 [로그인] [가입하기] 두 버튼. 순서는 항상 **로고 → 사람 → 메뉴**. 소속 글: "유년부 · 학생" · "유년부 · 관리자" · "플랫폼 관리자".
- 그룹 라벨 12px · 800 · 보조 글자색(예전: 파랑 12px/900 · 회색 14px/700 혼재).
- 항목 높이 48px 이상 · 15px · 700 · **단색 선 아이콘 한 종류**(색 타일 쓰지 않음). 설명 한 줄(11.5px → 12px 보조색)은 관리 · 플랫폼 메뉴에서만 허용.
- 현재 위치는 옅은 회색 면(`#f4f4f5`). 하단은 옅은 버튼 두 개(왼쪽 이동 · 오른쪽 로그아웃), 「앱 설치」는 메뉴 목록 안으로.
