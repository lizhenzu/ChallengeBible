# 0051. 미션 홈은 어디서나 1단 — 넓은 화면의 2단을 쓰지 않는다

- 상태: 확정 (2026-10-23, 사용자 결정)
- 관련: 시안 `말씀-미션홈`(900px 이상 2단), 0034(서버 렌더링 화면)

## 결정
미션 홈은 휴대폰 · 데스크톱 모두 **1단**, 가운데 좁은 폭(최대 640px)으로 같은 순서로 보인다.
나의 기록 → 최근 7일 → 통계 → 오늘 미션(띠 · 카드) → 달력 순서다. 시안의 900px 이상 2단 배치만 바꾸고, 부품 모양은 시안 그대로 둔다.

## 이유
- 휴대폰과 데스크톱의 배치가 달라 헷갈린다(사용자 의견).
- 아이들은 주로 휴대폰을 쓰고, 다른 화면은 이미 1단이다.
