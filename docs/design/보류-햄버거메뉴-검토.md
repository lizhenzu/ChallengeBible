# 보류: 홈의 ☰(햄버거) 메뉴 다시 검토 (2026-11-26 사용자)

> 사용자 지시: 「홈 왼쪽 위 ☰ 는 삭제한다. 이 메뉴가 무엇인지 기록해 놓고 나중에 알려.」
> → 홈(`/{부서}`)에서만 ☰ 버튼을 뺐다. 메뉴판 부품(`Pages/Shared/_TenantDrawer.cshtml`)은 그대로 있고 다른 화면(미션 · 출석 · 쪽지 등)의 ☰ 는 그대로다.

## ☰ 가 무엇이었나(부서 메뉴판 `_TenantDrawer`, 로그인한 사람에게만)
| 묶음 | 항목 | 누구에게 |
|---|---|---|
| 맨 위 | 「도전!!! 성경말씀」 제목 · 닫기 | 모두 |
| 바로 | **홈으로** | 모두 |
| 가장 중(대리 접속 중일 때만) | 사람 바꾸기 · 복귀 | 플랫폼 관리자 |
| 행정 | **행정업무**(오늘 할 일 · 출석 · 교적부 · 인명 검색 · 생일자로 가는 영역) | 교사 · 관리자 |
| 이벤트 | **생일자** · **선물 처리** | 생일자 = 교사 · 관리자, 선물 처리 = 관리자 |
| 함께하기 | **단체쪽지** · **사진첩** · **메인화면**(예전 「유년부 소개」) · **가족팀** | 모두(메인화면 · 가족팀은 켜진 부서만) |
| 관리 | **부서 관리** | 부서 관리자 |
| 다른 곳 | **내 부서 참여**(소속 없는 사람) · **플랫폼** | 처음 오신 분 · 플랫폼 관리자 |
| 맨 아래 | 내 프로필 카드(사진 · 이름 · 부서 · 역할) → 내 계정 | 모두 |

## 홈에서 ☰ 를 빼서 생긴 일(검토할 것)
- 홈에서 위 항목들(행정업무 · 생일자 · 선물 처리 · 단체쪽지 · 사진첩 · 가족팀 · 부서 관리 · 플랫폼)로 가는 길이 사라졌다. 다른 화면의 ☰ 나 각 화면의 직접 링크로만 간다.
- 특히 **부서 관리자 · 교사**가 홈에서 「부서 관리」 · 「행정업무」로 가는 길을 확인해야 한다.
- 홈 오른쪽의 쪽지(편지) · 내 계정은 그대로 있다.
- 나중에 정할 것: ☰ 를 다시 달지, 항목을 홈 본문으로 옮길지, 아예 없앨지.
