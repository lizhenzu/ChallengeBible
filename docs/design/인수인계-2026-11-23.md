- 관리자(SuperAdmin · 부서 Admin) 계정은 지우거나 비밀번호 · 역할을 바꾸지 않는다(R-315). 비밀번호 글자를 SQL · Git 에 쓰지 않는다. 실제 교인 이름을 예시에 쓰지 않는다.
- 데스크톱 내용 폭 760px. 업무 규칙(R-번호)마다 테스트. ADR 은 `docs/design/`.
- SQL: 사이트 SQL 화면은 COMMIT/ROLLBACK/BEGIN TRAN 을 주석 안에서도 막는다. SSMS 는 맨 위 `EXEC sp_set_session_context N'PlatformScope', 1;` 필요.
- EF 마이그레이션: `DOTNET_ROLL_FORWARD=Major dotnet tool run dotnet-ef migrations add X --project src/ChallengeBible.Infrastructure --startup-project src/ChallengeBible.Infrastructure --no-build` (RLS 는 migrationBuilder.Sql 로 `ALTER SECURITY POLICY sec.TenantIsolation ADD FILTER/BLOCK PREDICATE`).
