# 0117 부서 주보(올리기 · 보기)

- 날짜: 2026-11-20 · 상태: 확정(사용자 "1 진행", 시안 `시안/주보-시안.png`)

## 배경
예배 안내 카드(ADR 0116)에 주보 버튼을 붙인다. 유년부의 블록형 주보 만들기는 따르지 않고(사용자), 교회가 만든 주보를 부서마다 올리고 본다.

## 결정
- 주보 한 건 = 날짜(부서 날짜, 기본 이번 주일) · 제목 · 내용(둘 다 비워도 됨) + 파일 여러 개.
- 파일: 사진(JPG · PNG) · PDF만(파일 앞부분으로 확인), 한 주보에 10개, 파일마다 10MB. 한 번에 여러 개 고른다.
- 올리기 · 고치기 · 지우기: 그 부서 **교사 · 관리자**. 보기: **누구나**(로그인 안 한 손님 포함).
- 부서 홈 예배 안내 카드 첫 줄 오른쪽 주황 버튼 **[📋 주보 보기 · 가장 최근 날짜]** → `/{부서}/bulletin`(최근 주보 + 지난 주보). 주보가 없으면 교사 · 관리자에게만 [📋 주보 올리기].
- 부서 격리: 표 `app.Bulletin` · `app.BulletinFile`(TenantId, RLS + 전역 필터). 파일은 `Bulletins:Dir`(없으면 `App_Data/bulletins`)`/{TenantId}/{GUID}.확장자` — wwwroot 밖이라 주소로 바로 못 열고, `/{부서}/bulletin/file/{번호}`가 그 부서 줄일 때만 연다. 다른 부서 주소로는 404.
- 소속이 없어도 GET 으로 볼 수 있는 부서 화면 표시 `IPublicTenantPage`(TenantPageFilter). 고치기는 소속 · 역할 그대로 확인.
- 바꾼 기록: AuditLog `Bulletin`.

## 결과
- 운영 DB: `tools/sql/migrate-bulletin.sql` 을 SSMS 로 실행(표 + RLS + 마이그레이션 기록).
- 운영 서버: `App_Data/bulletins` 에 쓸 수 있어야 하고, 게시할 때 App_Data 를 지우지 않아야 한다(올린 주보 파일이 거기 있다).
- 테스트: `BulletinTests`(R-338).
