# 0114 브랜드 그림은 「네잎 정돈」(아이콘 · 카톡 대표 이미지 · 로딩 화면)

- 날짜: 2026-11-18 · 상태: 결정(사용자: 시안 ⑥-1 「네잎 정돈」 1 · 모든 부서 같은 아이콘 1 · 이미지에 교회 이름 그대로 2 · 작업 시작 1)
- 바꾸는 결정: ADR 0038 · 0033 의 "홈 화면 아이콘 = 부서 대표 색 바탕에 짧은 이름 앞 2자"
- 관련: 0034(PWA) · 0113(플랫폼 이름 도전!!! 성경말씀)

## 배경
예전 아이콘은 파랑 · 초록 · 주황 · 보라 바탕에 "도전" 두 글자였고, 카톡으로 주소를 보내면 대표 이미지가 없었다.
남색 · 고급 · 자연 계열 시안은 "어르신 같다"고 해서 빼고, 어린이 · 청소년 · 청년에게 맞는 밝은 시안 중 「네잎 말씀」 분위기를 골랐다.

## 결정
1. **모양**: 흰 바탕에 하트 잎 4장 + 초록 줄기의 네잎클로버. 잎 색 = 프로그램 색
   - 초록 `#22C55E` 성경미션 · 파랑 `#3B82F6` 성경통독 · 주황 `#F97316` 성경필사 · 분홍 `#EC4899` 365 기도
   - 뜻: "네 가지 도전, 하나의 말씀!"
2. **모든 부서가 같은 아이콘**. 부서 대표 색 · 짧은 이름 글자는 아이콘에 쓰지 않는다. 바탕화면 아이콘 아래 이름(짧은 이름)만 부서마다 다르다.
   대표 색은 화면 강조색 · 휴대폰 상단 막대 색(theme_color)에 그대로 쓴다.
3. **카톡 · SNS 공유 대표 이미지**: `og.png` 1200×630 한 장. "잠실새내교회 주일학교 · 도전!!! 성경말씀 · 네 가지 도전, 하나의 말씀! · 프로그램 칩 4개 · 네잎 아이콘".
   미리보기 제목(`og:title`)은 앱 이름 뒤에 부서 이름(앱 이름에 이미 있으면 그대로), 부서 밖 화면은 기본 이름.
4. **로딩 화면**: 흰 바탕 + 네잎 아이콘 + 앱 이름. 안드로이드는 매니페스트(`background_color` 흰색 · 아이콘 · name)로 휴대폰이 그린다.
5. 파일(`tools/brand/make.js` 로 다시 만든다)
   | 파일 | 쓰는 곳 |
   |---|---|
   | `/icons/icon-192.png` · `/icons/icon-512.png` | 매니페스트(안드로이드 설치) |
   | `/icons/icon-maskable-512.png` | 매니페스트 `purpose: maskable`(둥근 · 물방울 모양 휴대폰, 가운데 80% 안전 영역) |
   | `/icons/apple-touch-icon.png` (180) | 아이폰 홈 화면 |
   | `/icons/clover.svg` | 매니페스트 SVG · 관리 화면 미리보기 |
   | `/icons/favicon.svg` · `/favicon.ico`(16 · 32 · 48) | 브라우저 탭(바탕 없이 크게) |
   | `/images/og.png` | `og:image` |
6. 예전 부서 아이콘 주소 `/{slug}/icon.svg` 는 이미 설치한 앱을 위해 `/icons/clover.svg` 로 보낸다. 대표 색별 PNG 12개는 지운다.
7. **바탕화면 아이콘 아래 이름**(짧은 이름 기본값)을 "도전성경" → **"도전!!!성경말씀"** 으로 바꾼다(2026-11-18 사용자, 0037 · 0038 의 짧은 이름 기본값을 바꿈). 부서가 짧은 이름을 따로 정했으면 그 이름. 휴대폰에 따라 뒷부분이 "…"로 잘릴 수 있다.
8. 서비스 워커 저장소 이름을 `cb-v2` 로 올려 예전 아이콘을 지운다.

## 결과
- 이미 설치한 앱의 아이콘은 휴대폰이 매니페스트를 다시 읽을 때 바뀐다(기기마다 시점이 다르다. 아이폰은 지웠다가 다시 추가해야 바뀌기도 한다).
- 카톡은 같은 주소의 미리보기를 한동안 저장해 두므로, 이미 보낸 주소는 바로 바뀌지 않을 수 있다.
- 다른 교회가 들어오면 이미지의 교회 이름 줄을 그때 다시 정한다.
