# 0100. 오늘 할 일(할 일 모아 보기)

- 상태: 확정(2026-11-16 사용자, 질문 1 ~ 18 · 시안 `시안/오늘할일-시안.png`)
- 관련: R-309 ~ R-312, 정리 엑셀(사용자 PC, `오늘할일-설계-정리.xlsx`)

## 배경
처음 쓰는 사람도 메뉴를 찾아 들어가지 않고, 들어오자마자 "오늘 내가 할 일"을 보고 그 자리에서 끝내게 한다.

## 정한 것
1. **자동 이동**: 로그인 직후(돌아갈 주소가 없을 때) 처음 가는 화면(부서 홈 · 플랫폼 홈)에서 할 일이 있으면 한 번만 `/{부서}/todo` · `/platform/todo` 로 보낸다. 화면 맨 위 [홈으로].
2. **안 보기**: 오늘(다음 날 다시) · 3일 · 5일 · 한 달 — 자동 이동만 멈춘다(`UserSetting.TodoSnoozedUntil`). 할 일은 ☰ "오늘 할 일"에서 언제든.
3. **업무 꼬리표 "선물 담당"**(`app.MemberTag`, Tag = Gift): 역할과 따로, 부서 관리자가 사람 자세히에서 켠다.
4. **선물 그룹** = 부서 관리자 + 부장 · 부감 · 서기(T1005 · T1006 · T1008) + 지도(T1004) + 선물 담당. 선물 8가지 모두 🔔 대상자 알림(생긴 순간, 계정 없으면 [링크 복사]) → 🎁 사 주세요([쿠팡에서 보기] [구매 완료]) → 🎁 전해 주세요(구매자 이름 · 날짜, [전달 완료]) → 사라짐. 그룹 누구나 처리, 처리한 사람은 선물 이력에 남는다. 3일 넘게 아무도 안 산 선물은 맨 위 빨간 테두리("n일째 아무도 안 삼"). 기한 지난 선물은 "기한 지남", 다시 열기는 부서 관리자. 전도자 미정이면 🆕 데려온 사람 정하기(처리 화면은 부서 관리자).
5. **담임**(일반 반 선생님): 📋 우리 반 출석 체크(**주일 당일만**, 한 명이라도 체크하면 사라짐) · 🎂 생일 선물 링크 보내기(우리 반 아이, 생일 30일 안 = 선물이 열린 동안, **아이가 고르면** 사라짐). 오래 안 나온 아이는 넣지 않음. 새친구반 담당은 🙋 새친구 출석(주일 당일).
6. **부서 관리자**: 위 선물 일 + ✋ 참여 신청 승인 · 🎓 진급 받기(명부 연결 · 역할 고르기가 있어 기존 화면으로 연결) + 📋 이번 주일 전체 출석(체크한 반 n / m).
7. **플랫폼 관리자**: 부서 일은 부서별로 **보기만**(사 주세요 · 밀림 · 전해 주세요 · 선물 대상 · 승인 · 진급 · 주일 출석한 반), **자기 일만 처리**(플랫폼 홈의 챙길 일: 곧 비는 공용 콘텐츠 · 관리자 없는 부서 등).
8. **누가 보나** = 부서 규칙("우리 부서만 따로", `app.TodoRule` 부서 줄) → 공통 규칙(플랫폼, TenantId null 줄) → 코드 기본값. 종류 6줄(선물 사기 · 전하기 / 선물 대상 알림 · 링크 / 생일 링크 / 데려온 사람 정하기 / 승인 · 진급 / 출석) × 묶음 5칸(관리자 · 부장 부감 서기 · 지도 · 선물 담당 · 담임). 부서: 관리 › 할 일, 공통: 플랫폼 › 오늘 할 일 아래.
9. **기존 메뉴는 그대로**: 할 일은 흩어진 일을 모아 보여 주는 입구다. 같은 데이터(선물 · 출석 · 신청)를 쓰므로 어디서 처리하든 양쪽에 반영된다.
10. 데이터: `app.MemberTag` · `app.TodoRule`(보안 조건: 부서 · 공통), `app.UserSetting.TodoSnoozedUntil`. 마이그레이션 `TodoHub`.

## 고침 — 카드는 보고 이동, 완료는 업무 화면에서(2026-11-16 사용자, 확정 시안 `시안/할일타임라인-시안.png`)
- 실제 일을 하지 않고 카드에서 완료할 수 있어서 바꾼다. 카드에는 **무슨 일 · 왜(한 줄) · 필요한 정보 · 진행 타임라인 · [업무 화면으로]**만 둔다. 카드의 [구매 완료] · [전달 완료] · [링크 복사]는 없앴다.
- 타임라인(선물 일만): 선물 대상 → (링크 보냄) → 아이가 고름 → 구매 → 전달. 단계마다 시각 · 사람. 승인 · 출석은 단계가 하나라 정보와 [가기]만.
- 선물 처리 화면 `/{부서}/todo/gift/{번호}`: 선물 그룹(관리자가 아니어도) · 선물 알림 · 우리 반 담임이 들어온다. [쿠팡에서 사기] → [구매 완료] → [전달 완료](할 일로 돌아가고 바로 사라짐), 아직 안 고른 선물은 [링크 복사](처음 만들면 "링크 보냄 · 누가"가 남음). 취소 · 되돌리기는 관리 › 선물(관리자)에서.
