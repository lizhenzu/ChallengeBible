# 0105 성경필사를 성경통독과 같은 틀로 · 복사 · 붙여넣기 막기

- 날짜: 2026-11-16 · 상태: 확정(사용자 "1", 시안 `시안/필사-통독틀-*-시안.png`)
- 바꾸는 것: ADR 0099 의 필사 화면 머리말(☰ = 부서 메뉴판, 안쪽 화면은 ← 돌아가기)

## 배경
메인에서 성경통독을 누르면 통독 전용 목차가 있는 대시보드로 가는데, 성경필사는 머리말 하나 + 1단 화면이라 두 프로그램의 이동 방식이 달랐다. 통독 쪽이 좋다(사용자).

## 결정
1. 필사 모든 화면(대시보드 · 장 고르기 · 참여자 현황 · 따라 쓰기)이 통독과 같은 틀(`.rp.b2`, reading.css · reading-b2.css)을 쓴다:
   넓은 화면 = 왼쪽 고정 목차, 좁은 화면 = ☰ 서랍. 목차: 대시보드 · 구약 쓰기 · 신약 쓰기 · 참여자 현황 / 빠른 이동: 이어 쓰기 · 창세기 1장 · 마태복음 1장 · 시편 23편 / ← 부서 홈으로. 공통 부분은 `Pages/Copy/_CopyNav.cshtml`.
2. 색은 필사 테마 `data-theme="copy"`(갈색 #7A4E2D, copy.css 토큰과 같은 값). 통독 색 테마 고르기는 필사에 두지 않는다.
3. 대시보드는 통독과 같은 2단: 왼쪽 진도 원 · 쓴 절 · 일 연속 · 일 씀 · 오늘 쓴 절 · 최근 쓴 곳 · 완필 선물 · 필사 진도 / 오른쪽 이어 쓰기 · 최근 8주(쓴 날).
4. 따라 쓰기 화면에서 **복사 · 붙여넣기를 막는다**(2026-11-16 사용자): 본문은 고르기 · 복사 · 길게 누르기 · 끌기를 막고, 쓰는 칸은 붙여넣기 · 끌어 놓기(paste · drop · beforeinput insertFromPaste)를 받지 않고 "직접 따라 써 주세요"를 보인다.

## 결과
- 예전 머리말 `_CopyTop` 은 없앴다.
- 브라우저에서 막는 것이라 개발자 도구 등으로 우회하는 것까지 막지는 못한다(서버는 글자가 본문과 같은지만 본다, R-306).
- 이어 쓰기 카드의 다음 절 미리 보기 문장(시안의 따옴표 줄)은 이번에 넣지 않았다.
- 테스트: `CopyTests`(틀 · 목차 · 붙여넣기 막기 스크립트).

## 고침 — 화면 흐름도 통독과 똑같이(2026-11-16 사용자 "글쓰기 빼고 통독과 똑같이", 확정 시안 `시안/필사-통독흐름-*-시안.png`)
- 대시보드 맨 아래 **책별 진도**(구약 39권 · 신약 27권 탭 + 책 타일) — 통독 대시보드와 같다.
- 구약 · 신약 쓰기(`/copy/books`) = 통독 "구약 읽기"와 같은 화면: 탭 → 전체 % → 책 타일 → 책을 누르면 그 줄 끝에 장 칸 판넬(다 씀 · 쓰는 중 · 아직, [닫기] · [이어 쓰기 N장 →]). 통독의 "다 읽음 표시"는 없다.
- 쓰는 화면 = 통독 본문 화면과 같은 배치: 색 띠 머리(경로 · 구약/신약 · 성경 필사 · 책 이름 + 큰 장 번호 · 절 진도 막대) → 장 번호 줄 → 번역 칸 → 따라 쓰기(그대로) → ◀ 앞 장 · 다음 장 ▶ → 대시보드 · 구약/신약 쓰기 · 부서 홈.
