# 0132 가족팀 카드 · 초대 배너 · 만들기 유도 (홈 아래)

- 날짜: 2026-11-22 · 상태: 결정(사용자 "구현해줘")
- 관련: ADR 0127(홈 교체) · 0129(메뉴 2차)

## 배경

0127에서 가족팀 카드와 초대 배너를 홈에서 빼고 메뉴로만 옮겼다. 사용자가 다시 홈 아래(나의 도전 현황 다음)에 넣고, 아무것도 없을 때는 가족팀·친구팀 만들기를 권하는 카드까지 넣어 달라고 했다.

## 결정

1. **자리** — 나의 도전 현황 카드 아래, 작은 링크 위.
2. **받은 초대가 있으면** — 초대 배너. 팀 이름 · 초대한 사람 · `N개`, [초대 확인하기] → `/{slug}/family-team`, [다음에 할래요] → `SnoozeInvites`(오늘 숨김, R-212).
3. **가족팀에 속해 있으면** — 우리 가족팀 카드. 팀 이름 · 시즌 점수 · 다음 가족 축하까지 남은 점수 · 진행 막대. 누르면 가족팀 화면.
4. **둘 다 없으면** — 점선 카드 `가족팀 · 친구팀을 만들어 보세요`. [가족팀 만들기]는 모두, [친구팀 만들기]는 **학생만**(R-221). 둘 다 가족팀 화면으로.
5. **조건** — `MissionEnabled` + 규칙 `Features.FamilyTeam`, 임시 부서(로비) 제외.
6. **메뉴** — ☰ > 함께하기 > 가족팀은 그대로 둔다.

## 구현

- `TenantHomeModel`: `FamilyTeamService` · `FamilyJoinService` 다시 주입, `Family` · `Invites` · `FamilyIsStudent` · `OnPostSnoozeInvitesAsync` 추가.
- `FamilyIsStudent`는 `UserRole.KindOf(tenant.RoleCode)`로 판단(기존 `FamilyState.IsStudent`는 기본값 false라 쓰지 않음).
- `TenantHome.cshtml`: 현황 카드 아래 세 상태. `home.css`에 `.hmx-inv` · `.hmx-fam` · `.hmx-make`.
- 테스트: `HomeMainTests`(만들기 카드, 학생/학부모), `FamilyJoinTests`(배너 · 스누즈 · 수락 뒤 카드), `FamilyTeamTests`(카드).

## 참고

- 초대 배너와 가족팀 카드는 보통 함께 뜨지 않는다(팀이 있으면 초대를 읽지 않는다).
- 0127·0129의 "가족팀 홈 제거"를 이 결정으로 되돌린다.
