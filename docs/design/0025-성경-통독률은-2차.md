# 0025. 성경 통독률은 2차로 미룬다

- 상태: 확정 (2026-10-21)
- 원래 결정: D25
- 관련: R-110 ~ R-117

## 맥락
현행에는 성경 전체 통독률(읽은 절 ÷ 전체)과 오늘 읽은 절 수 표시가 있다.
1차 범위를 줄이기 위해 무엇을 먼저 만들지 정해야 했다.

## 결정
- 1차: 오늘 말씀 범위의 본문 보기, 절 **읽음 표시** · 범위 전체 읽음 · **책갈피**(R-110 ~ R-112).
- 2차: 성경 전체 통독률, 오늘 읽은 절 수(R-114).

## 결과
- 2차를 위해 읽음 기록에는 **처음부터 날짜를 남긴다**.
- 읽음 표시는 점수와 무관하다(R-113). 말씀 점수는 말씀 미션 버튼으로만 생긴다.
- 읽음 · 책갈피 API 는 토글이 아니라 멱등으로 만든다: `PUT` 읽음, `DELETE` 읽음(X-17).
