# 0043. 통독 화면 스타일 · 글자 크기 · 영상 주소 이전

- 상태: 확정 (2026-10-22, 사용자와 합의)
- 관련: 0033(화면은 하나, 대표 색), 0036(성경 본문 적재), 0041, 0042, 시안 "통독 본문 읽기"

## 결정
1. **화면 스타일**: 통독 화면은 카드 안에 카드를 두지 않는다. 흰 바탕 한 장에 구분선으로만 나누고,
   위쪽 띠(목차 · 경로 · 글자 크기 · 밝기) → 큰 제목 → 내용 순서로 둔다(Bible2 배치, 테마는 0033).
   절 번호는 연한 동그라미, 읽음 ✓ · 북마크 ★ 는 본문 끝에 이어 붙는 둥근 버튼이다.
2. **글자 크기**: 위쪽 띠의 **[ − ] 비율 [ + ]** 버튼으로 조절한다.
   - − 는 한 번에 **5%**, + 는 한 번에 **10%**, 각각 **5번까지** → **75% ~ 150%**.
   - 가운데 비율을 누르면 **100%** 로 돌아간다. 끝에 닿은 쪽 버튼은 눌리지 않는다.
   - 본문 · 다른 번역 줄 · 개요 · 요약만 커지고, 버튼 · 제목 · ✓ · ★ 는 그대로다.
   - 고른 크기는 그 기기(브라우저 저장소)에 기억한다. 계정에 저장하지 않는다.
3. **듣기 · 해설 영상 주소**는 Bible2 의 기존 DB 에서 성경 본문과 함께 **한 번 옮겨 온다**(참조 데이터 — 0036 과 같은 원칙).
4. 짧은 이름은 성경말씀 "도전성경", 성경통독 "도전통독"으로 확정한다(0039).

## 결과
- 업무 규칙 R-167(글자 크기)을 더했다.
- 0036 적재 도구가 ChapterMedia(0041)도 함께 채운다.
