# 0082. 페이지를 옮길 때 대기 카드를 보여 주고, 문구는 갈 곳에 맞춘다

- 상태: **확정 · 구현** (2026-11-05, 사용자와 하나씩 정함)
- 확정 시안: `시안/wait-card.png` 1안(펼친 책, 흰 카드, 어두운 뒤)

## 결정(사용자)
1. **모든 화면에** 같은 카드를 쓴다. 통독에만 있던 대기 창(옛 Bible2)은 이 카드로 바꾼다.
2. **문구는 갈 곳에 맞춘다.** 큰 글자는 "잠시만 기다려 주세요"로 같고, 작은 글자만 다르다. 아이들 · 통독 화면만 나누고 관리 · 플랫폼 화면은 "이동하고 있어요" 하나로 쓴다.
3. **맨 위 진행 줄은 바로, 카드는 0.3초 뒤**에 나온다. 빠른 이동에서 카드가 깜빡이지 않게 한다.
4. **링크 이동과 폼 제출** 모두에 나온다.

## 고침(2026-11-05, 사용자): 카드가 보이도록 링크 이동을 0.6초 늦춘다
카드가 금방 사라져 결정 3을 바꾼다. 진행 줄과 카드를 **누르는 즉시** 보여 주고, **링크는 0.6초 뒤에** 옮긴다. 폼 제출은 늦추지 않는다(눌린 버튼 값을 그대로 보내야 하므로).

## 고침(2026-11-05, 사용자): 큰 읽음 버튼에도 카드를 보여 준다
화면을 옮기지 않지만 "이 페이지 읽음으로 표시"(말씀)와 "이 장 읽음으로 표시"(통독)를 누르면 저장하는 동안 카드를 보여 준다. 최소 0.6초 보이고, 문구는 "읽음으로 표시하고 있어요" · "읽음 표시를 취소하고 있어요". 절마다 있는 ✓ · ★ 에는 넣지 않는다.

## 고침(2026-11-05, 사용자): 통독에 맞춘다
- 통독 화면의 카드와 진행 줄은 사용자가 고른 통독 테마 색을 따른다.
- 통독 목록의 "다 읽음 표시"(장 번호 버튼)도 저장하는 동안 카드를 보여 준다.

## 문구
| 가는 곳 | 작은 글자 |
|---|---|
| 말씀 · 말씀 읽기 | 말씀을 펼치고 있어요 |
| 퀴즈 | 퀴즈를 준비하고 있어요 |
| 기도 | 기도 시간을 준비하고 있어요 |
| 암송 | 암송 구절을 꺼내고 있어요 |
| 미션 홈 | 오늘의 미션을 불러오고 있어요 |
| 달력 | 달력을 넘기고 있어요 |
| 점수 · 순위 | 점수를 모으고 있어요 |
| 통독 읽기 | 성경을 펼치고 있어요 |
| 그 밖의 통독 화면 | 통독 기록을 찾고 있어요 |
| 로그인 · 내 정보 | 내 정보를 확인하고 있어요 |
| POST 폼 | 저장하고 있어요(로그인 · 회원가입은 "내 정보를 확인하고 있어요") |
| 그 밖(로그아웃 · 가장 복귀 포함) | 이동하고 있어요 |

## 구현 때 정한 것
- `wwwroot/js/wait.js` 를 `_Layout` 에서 불러오고, 문구는 주소로 고른다. 화면마다 코드를 넣지 않는다.
- 나오지 않는 경우: 그 자리에서 처리하는 동작(`preventDefault`), 새 창, `download`, 같은 주소 · 해시 링크, 다른 사이트 링크, `data-nowait` 를 단 링크 · 폼.
- 이동이 일어나지 않아도 카드가 남지 않게 15초 뒤 저절로 닫는다. 뒤로 가기로 돌아오면(`pageshow`) 바로 닫는다.
- 색은 부서 대표 색(`--accent`)을 따르고 다크 모드를 지원한다.
