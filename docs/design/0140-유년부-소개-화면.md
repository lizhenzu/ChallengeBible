# 0140 유년부 소개 화면(처음 들어온 사람에게 먼저)

- 날짜: 2026-11-23 · 상태: 확정(사용자 "C안", 시안 `시안/유년부-소개-시안.png` · `시안/유년부-소개-색상3안.png`)

## 배경
홈 루트(`/`)와 부서 홈은 미션(도전!!! 성경말씀) 중심이다. 유년부가 어떤 곳인지, 예배는 언제 어디서인지, 주보 · 사진첩은 어디서 보는지 알려 주는 화면이 없고, 예배 안내 · 주보는 홈 개편(ADR 0127)으로 입구가 사라져 주소를 직접 쳐야만 열렸다.

## 결정(사용자 질문 · 답)
- **유년부 전용.** 다른 부서에는 보이지 않는다. 코드에 부서 이름을 쓰지 않고 **줄이 있는 부서만** 소개 화면이 있게 했다 — 줄(`app.TenantIntro`)은 운영 SQL 로 유년부에만 만든다. 부서 관리자가 스스로 만들 수 없고, 줄이 없으면 고치는 화면도 404.
- **언제**: 부서에 **처음 들어온 사람**에게 `/{부서}` 가 먼저 `/{부서}/welcome` 으로 보낸다.
- **누구 기준**: **계정 기준**(질문 1 → 2). 「1주일 후 다시 보기」(7일 숨김) · 「다시 보지 않기」는 `app.TenantIntroSeen`(TenantId + 계정)에 둔다. 손님은 기억할 계정이 없어 들어올 때마다 나온다(손님에게는 두 버튼을 보이지 않는다).
- **「성경말씀으로 가기」**: 이번 방문 동안은 다시 안 보내는 세션 쿠키 `cb_intro_{TenantId}` 만 남긴다(계정에는 남기지 않음 — 다른 기기에서 열면 또 나온다). 그래야 부서 홈 ↔ 다른 화면을 오가도 소개 화면이 계속 끼어들지 않는다.
- **글**: 관리자가 화면(`/{부서}/admin/intro`)에서 직접 — 제목(60자) · 소개 글(1000자) · **대표 사진 한 장**(JPG · PNG, 5MB, 파일 앞부분으로 확인) · 보이기 켬/끔(질문 2 · 3 → 2 = 사진 포함). 바꾼 기록은 AuditLog `TenantIntro`.
- **구성(시안 C안, 크림 + 주황)**: 대표 사진 → 제목 · 소개 글 → 예배 안내 띠(`WorshipService`, 크림 바탕 · 주황 [지도] = 네이버 지도 검색) → 주보 보기(`/{부서}/bulletin`, 가장 최근 날짜) · 사진첩 보기(`/{부서}/album`) → 주황 「도전!!! 성경말씀으로 가기」 → (로그인한 사람만) 「1주일 후 다시 보기」 · 「다시 보지 않기」.
- **다시 보는 길**: 건너뛴 사람도 ☰ 메뉴 「함께하기 › 유년부 소개」로 언제든. 관리자는 관리 ☰ 「소개 화면」.
- 예배 카드를 홈에 되살리는 안(B안 띠, 색 보류)은 이 화면이 대신한다. 홈은 그대로.

## 결과
- 표: `app.TenantIntro`(TenantId 가 키, 부서당 1줄) · `app.TenantIntroSeen`. 둘 다 `ITenantOwned` + RLS(`sec.TenantIsolation`) + EF 전역 필터. 마이그레이션 `20261123231718_TenantIntro`.
- 사진 파일: `Intro:Dir`(없으면 `App_Data/intro`)`/{TenantId}/{GUID}.확장자` — wwwroot 밖, `/{부서}/welcome/photo` 로만 연다(게시할 때 `App_Data` 를 지우지 않는다 — 주보와 같다).
- 누구나 보는 화면: `/Welcome/Index` · `/Welcome/Photo` 를 `AllowAnonymousToPage` + `IPublicTenantPage`. 「다시 보기」 POST 는 로그인한 사람만 기록.
- **운영 DB**: `tools/sql/migrate-intro-site.sql`(표 + RLS + 유년부 줄 하나)를 **게시 전에** 사이트 SQL 화면에서 실행. 표가 없으면 부서 홈이 오류.
- 테스트 `IntroTests`: R-368(유년부 전용) · R-369(구성) · R-370(처음/계정 기준/1주일/다시 보지 않기) · R-371(관리자만 고침 · 사진 · 다른 부서 404).
- 다른 부서에도 소개 화면을 두려면 그 부서 줄을 SQL 로 넣으면 된다(코드 변경 없음).
