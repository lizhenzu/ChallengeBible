# 0128 첫 화면(`/`)을 dodan 네이비 테마로 통일

- 날짜: 2026-11-22 · 상태: 결정(사용자 "추천") · 관련: ADR 0127
- 시안: `docs/design/시안/메인-UX-A4-네이비앱-단독시안.html`

## 배경

2026-11-22 부서 홈(`/{slug}`)을 dodan 화면으로 바꾼 뒤, 로그인 전 첫 화면(`/`)만 옛 0061 디자인(흰 바탕 · 하늘색 히어로 · 긴 소개)으로 남아 첫인상이 끊겼다. 사용자가 "첫 화면도 같은 테마로"를 추천으로 골랐다.

## 결정

1. **첫 화면 구조** — 머리말(교회 · 날짜 · 로그인) → 로고 `도전!!! 성경말씀` + 태그라인 → 네이비 로그인 블록 → 프로그램 4칸 → 오늘의 말씀 → 함께하는 현황 → 관리자 로그인 → 작은 링크(가입 · 앱 설치) → ©.
2. **색·모양** — 부서 홈과 같은 `#1e3a8a` · `#0179dc` · 회색 카드 · 얇은 선. `home.css`의 `.hmx`를 그대로 쓰고 랜딩 전용은 `first.css`(`.lp-*`)에 둔다.
3. **로그인한 사람** — 지금과 같다: 소속 1곳 → 그 부서 홈, 2곳 이상 → 부서 고르기, 0곳 → 참여 신청. 플랫폼 관리자는 `/platform`.
4. **유지** — 공용 오늘의 말씀 · 이번 주 암송 · 오늘의 기도, 모든 부서 합계(부서 수 · 사람 수 · 오늘 · 올해 읽은 장 · 최근 7일), 부서 관리자(R-364) · 대표 학생(R-367) · 플랫폼 관리자 로그인, 가입 링크.
5. **뺀 것** — 긴 소개 문단, 프로그램 탭 설명, 주간 막대 그림, 시작 2단계, 가족팀 소개, 점수·퀴즈 횟수 설명. 이 내용은 부서 홈·프로그램 화면에서 본다.
6. **검색** — 첫 화면에서는 뺐다. 부서가 정해지기 전에는 검색할 본문 범위가 없기 때문이다. 검색은 부서 홈과 통독 화면에 있다.

## 결과

- `Pages/Index.cshtml` 전면 교체, `wwwroot/css/first.css` 추가. `IndexModel`은 그대로(합계 · 관리자 버튼 · 연도).
- `LandingTests` 5개를 새 구조로 다시 씀.
- 부서 홈(0127)과 첫 화면이 같은 언어를 쓴다.

## 남은 일

- 관리자 · 플랫폼 ☰ 메뉴는 아직 예전 타일 모양이다. 필요하면 같은 깔끔판으로 통일.
- 첫 화면에서 프로그램 아이콘은 지금 로그인으로 보낸다. 로그인 전 프로그램 미리보기 화면을 만들면 링크를 바꾼다.
