# 0072. 통독 본문 큰 버튼은 "이 장 읽음으로 표시"(장 전체) — 옛 Bible2 와 같게

- 상태: **확정 · 구현 끝**(2026-10-31, 사용자 "3번 해줘" — 옛 Bible2 비교 목록 3번)
- 바꾸는 것: R-160 의 "이 페이지 모두 읽음"(보이는 절만). 0042("넘기기만으로는 읽음 아님")는 그대로
- 관련: 0071(통독 화면 옛 Bible2 배치), R-151(장 완료) · R-162

## 결정
1. 통독 본문(`/{slug}/reading/read/…`)의 큰 버튼 = **이 장 전체 읽음 표시**(R-151 장 완료 API). 다 읽은 장이면 "이 장 읽음 표시를 취소할까요?" — 누르면 그 장의 회차 읽음을 지운다.
2. 버튼 안에 **"오늘 읽은 절 N"**(부서 시간대 오늘, 회차 절 읽음 기준).
3. 절을 하나씩 눌러 장이 다 차거나 풀리면 버튼 · 맨 위 "이 장을 다 읽었어요" 띠도 바로 바뀐다. 큰 버튼을 누른 뒤에는 화면을 다시 불러온다.
4. 성경말씀 미션의 성경 읽기(`/{slug}/read`)는 그대로 "이 페이지 읽음으로 표시".

## 결과
- 새 SQL 없음. `ReadingService.TodayVersesAsync`, 본문 화면 · mission.js 수정, 테스트 추가.
