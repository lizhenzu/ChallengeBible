# 0102 완전 초기화와 시험 도구 나누기

- 날짜: 2026-11-16 · 상태: 확정(사용자 "1", 시안 `시안/완전초기화-시안.png` · `시안/가짜데이터넣기-시안.png` · `시안/상황별로그인-시안.png`)
- 바꾸는 것: 0094 정한 것 17(새해 초기화 화면) · 0095(시험 도구) · 2026-11-15 "관리자만 남기기"

## 배경
지우는 기능이 세 군데(새해 초기화 · 관리자만 남기기 · 시험 도구의 가짜 데이터 지우기)에 흩어져 있고, 새해 초기화와 관리자만 남기기는 "반을 지우나"만 달라 헷갈린다.
시험 도구 한 화면에는 가짜 데이터 · 상황별 로그인 · 케이스별 시험(보라색 상자)이 섞여 너무 복잡하다. 케이스 시나리오 대신 직접 시험하고 싶다(사용자).

## 결정
1. **완전 초기화** `/platform/reset`(플랫폼 ☰ › 도구, 플랫폼 관리자만, 확인 글자 `RESET`, 되돌릴 수 없음).
   - 지울 것을 체크 칸으로 고른다. 기본은 모두 체크, 체크를 뺀 것은 남긴다. 항목마다 지울 개수를 보인다.
   - 기록: 미션 · 퀴즈 / 출석(새친구 포함) / 선물 · 선물 이력(쓴 점수 · 초기화 시각 포함) / 시상 기록(지난 기록 포함) / 가족팀 · 친구팀 / 성경통독 / 성경필사 / 진급 · 참여 신청 / 검색 기록 · 감사 로그.
   - 사람: 계정(관리자 제외, 소속 · 업무 칩 · 설정 포함) / 명부 · 반 배정 · 보호자 연결(관리자 줄 제외).
   - 사람(계정 · 명부) 중 하나라도 지우면 기록은 체크와 상관없이 모두 지운다(화면에서 잠금). 계정만 지우고 명부를 남기면 명부 줄의 계정 연결만 끊는다.
   - **절대 안 지움**(잠금): 플랫폼 관리자 계정, 부서 관리자 계정 · 소속 · 명부 줄 · 반 배정, 부서, **반**(이름 · 학년 · 새친구반), 상품 · 설정 · 콘텐츠 · 규칙.
   - 초기화 기록: 감사 로그 `FullReset` 한 줄(지운 건수). 로그를 지워도 이 한 줄은 남는다.
   - 옛 주소 `/platform/year-reset` · `/platform/people-reset` 은 여기로 보낸다. "관리자만 남기기"(반을 지우던 기능)는 없앴다.
2. **시험 도구**는 목적별 두 화면(설정 `TestTools:Enabled` 일 때만, 메뉴도 둘).
   - `/test-tools/data` **가짜 데이터 넣기**(플랫폼 관리자만, 확인 글자 `FAKE`): 부서마다 가장 최근 학기의 반(새친구반 제외)에 학생 s01 ~ s40(반마다 고루, s38 미배정) · 담임(반마다 1명, 최대 10) · 학부모 p01 ~ p10 의 계정 · 명부 · 반 배정을 새로 만들고 생일 · 출석 · 미션 점수 · 통독 · 가족팀 · 친구팀을 더한다. 아무것도 지우지 않는다. 반이 없는 부서는 건너뛴다.
   - **가짜 데이터 지우기는 없앴다** — 완전 초기화가 지운다(`fake-delete.sql` 삭제).
   - `/test-tools/login` **상황별 로그인**(플랫폼 관리자 · 가짜 계정): 가짜 데이터로 만든 계정 버튼만. [시험 관리자 만들기]는 없앴다(부서 관리자는 지울 수 없어서).
   - `/test-tools` 옛 주소는 플랫폼 관리자 → 넣기, 가짜 계정 → 로그인으로 보낸다.
   - 케이스별 시험(보라색 상자, `CaseTestService`, 오늘을 주일로 보는 `tsun` 쿠키)은 없앴다.
3. **가장도 로그인처럼 할 일로**(R-309): 계정 찾기 › 가장, 가장 중 [사람 바꾸기](부서 홈으로 갈 때), 상황별 로그인으로 들어가도 할 일이 있으면 한 번 할 일 화면으로 간다.

## 결과
- 실제 사용자가 생긴 뒤에는 완전 초기화가 실제 데이터를 지우므로, 그때는 체크를 줄여 쓰거나 메뉴를 다시 정한다.
- 가짜 데이터 SQL 은 SQL Server 에서 직접 돌려 보지 못했다(이 환경에 SQL Server 없음). 운영에서 처음 넣을 때 결과 표를 확인한다.
- 테스트: `ResetTests`(R-314), `TestToolsTests`, `TodoTests`(가장 → 할 일).
