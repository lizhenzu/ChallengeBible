# 0016. 진급 — 같은 계정으로 새 영역에 새로 소속, 새 영역은 0점부터

- 상태: 확정 (2026-10-21) — **0066 으로 바뀜**(2026-10-25: 새 부서는 0점부터가 아니라 옮긴 점수부터)
- 원래 결정: D16 (삭제 범위는 0022)
- 관련: R-139, 0003, 0022

## 맥락
아이는 학년이 오르면 유년부에서 초등부로 옮긴다. 영역은 서로 격리되어 있으므로(0003)
기록을 들고 갈 수 없다.

## 결정
- 같은 계정으로 새 영역에 **새 소속**을 만든다.
- **이전 영역의 기록은 삭제**한다(범위는 0022). 새 영역은 **0점부터** 시작한다.

## 결과
- 시즌 중간에 진급하면 이전 영역 가족팀의 합산 점수가 줄어든다.
  그래서 진급은 **시즌 시작에 권장**한다(강제는 아님).
- 계정은 유지되므로 로그인 정보 · 프로필은 그대로다.
