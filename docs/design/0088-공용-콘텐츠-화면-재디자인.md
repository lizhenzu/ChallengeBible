# 0088. 공용 콘텐츠 화면: 휴대폰은 목록과 편집을 나눈다

- 상태: **확정 · 구현** (2026-11-07, 사용자)
- 확정 시안: `시안/platform-content.html` (`platform-content-1.png` ~ `-4.png`: 휴대폰 목록 · 말씀 편집 · 퀴즈 편집 · PC)
- 바꾸는 것: `/platform/content/{word|quiz|prayer|recite}` 의 화면 구성. 저장 · 공개 규칙(R-120 ~ R-124)은 그대로다.

## 맥락
휴대폰에서 빈 편집 칸이 맨 위에 나오고 "왼쪽에서 날짜를 고르세요"라고 안내했다. 목록은 화면 절반 높이로 잘려 안쪽에서 따로 스크롤됐고, 공개된 날에도 쓸 수 없는 체크박스가 줄마다 있었다. 긴 글을 쓰면 저장 버튼까지 내려가야 했다.

## 결정(사용자)
1. **좁은 화면(899px 이하)**: 목록과 편집을 한 화면씩 보여 준다. 날짜를 누르면 편집 화면, "‹ 목록"으로 돌아오면 그 줄 자리로 간다. 페이지 스크롤 하나만 쓴다.
2. **넓은 화면(900px 이상)**: 목록과 편집을 나란히 둔다. 편집 칸이 스크롤을 차지하므로 목록은 따로 스크롤한다.
3. 저장 · 공개 버튼은 화면 아래에 고정한다.
4. 체크박스는 초안인 날에만 두고, 고르면 "고른 초안 N개 공개" 버튼이 나타난다.
5. 전체 · 공개 · 초안 · 없음으로 거르고, 목록에 성경 범위와 오늘 표시를 더한다. 편집 화면에서 앞뒤 날짜로 바로 간다.
6. 퀴즈의 해설 칸은 아이들 화면에서 힌트로도 나오므로 "힌트 · 해설"로 부른다. 답 형식에 맞는 칸만 보여 준다.

## 구현 때 정한 것
- 위쪽 플랫폼 메뉴는 다른 플랫폼 화면과 함께 쓰므로 바꾸지 않았다.
- "오늘"과 기본 달을 UTC 가 아니라 플랫폼 시간대(Asia/Seoul)로 계산한다. 전에는 한국 시간 새벽에 전날로 잡힐 수 있었다.
- 거르기는 탭별로 `sessionStorage` 에 둔다. 읽지 못해도 전체 목록으로 동작한다.
- 스크립트가 꺼져 있으면 공개 버튼과 답 형식 칸이 모두 보여 그대로 쓸 수 있다.
- 옛 `.csplit` · `.days` · `.editor` 스타일은 이 화면에서만 쓰여 지웠다.

## 결과
- **실DB:** 데이터베이스 변경 없음. 게시만 하면 된다.
- 테스트: `ContentPageTests`(목록 자료 · 실제 페이지 + 스크립트 + CSS 를 Edge headless 에서: 화면 전환, 360px 넘침, 체크박스, 거르기, 앞뒤 날짜, 답 형식). 저장 규칙은 `ContentAdminServiceTests` 그대로. Edge 가 없는 환경에서는 화면 시험만 건너뛴다.
