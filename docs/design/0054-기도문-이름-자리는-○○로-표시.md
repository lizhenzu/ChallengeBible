# 0054. 기도문의 이름 자리는 아이 이름 대신 "○○"로 강조 표시

- 상태: 확정 (2026-10-24, 사용자 결정)
- 바꾸는 것: 0047 의 2번 "화면은 로그인한 참여자 이름으로 바꾸고 강조 표시", R-32

## 결정
1. 기도문의 `{이름}` 자리는 **"○○"** 로 보여 주고 강조 색(형광펜 표시)을 입힌다. 아이 이름을 넣지 않는다.
2. 바로 뒤에 붙은 조사 표시(예: `(이)`)도 함께 강조한다. 예: **○○(이)**가 …
3. 원본 기도문에서 온 `**` 강조 기호는 화면에 보이지 않게 지운다.
4. 저장된 기도문은 그대로 둔다(`{이름}` 표시 유지). 바꾸는 것은 화면 표시뿐이다.
5. 가져온 기도문에는 "○○(이)가 …"(다른 사람) 판과 "제가 …"(나) 판이 함께 들어 있다.
   화면은 **이름 자리가 있는 문단만** 보여 준다(○○ 판 하나). 이름 자리가 있는 문단이 하나도 없으면 모두 보여 준다.

## 이유
- 기도 미션은 "나를 위해"와 "가족·친구를 위해" 두 항목이다(0047). 같은 기도문을 다른 사람을 위해서도 드리므로, 아이 이름이 박혀 있으면 맞지 않는다(사용자 의견).
- 아이가 ○○ 자리에 기도할 사람 이름을 넣어 소리 내어 기도한다(현행 앱과 같은 모양).
