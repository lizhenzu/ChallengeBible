# 0004. 계정은 전역 1개, 영역마다 소속(Membership)

- 상태: 확정 (2026-10-21)
- 원래 결정: D4
- 관련: 01 문서 6절, 02 용어집 "계정 · 소속", X-01, X-10, X-11

## 맥락
부모는 자녀가 유년부와 초등부에 나뉘어 있을 수 있다. 영역마다 따로 가입하게 하면
같은 사람이 계정을 여러 개 가져야 한다.

## 결정
- **계정(Account)** 은 로그인 주체이며 전역이다(영역과 무관).
- 계정은 영역마다 **소속(Membership)** 을 가진다. 소속 상태: 신청 → 승인 → 정지/해제.
- 권한은 항상 **(계정, 영역, 역할)** 의 조합으로 판단한다.
  같은 계정이 유년부에선 보호자, 초등부에선 영역 관리자일 수 있다.
- 계정 이름에 따른 권한 예외("Basic"·"SuperAdmin" 아이디면 관리자)는 만들지 않는다(X-11).

## 결과
- 계정은 TenantId 가 없는 **전역 데이터**다. 전역 데이터 목록은 0007 에서 다룬다.
- 아이디(로그인 이름)는 계정의 속성일 뿐, 어떤 업무 기록의 키로도 쓰지 않는다(X-01).
- 참여자 · 보호자 · 교사 구분은 소속의 역할로 명시한다. 반 정보 유무 같은 추측은 하지 않는다(X-10).
