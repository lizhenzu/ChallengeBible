# 0031. 보호자 동의 확인 폐지 — 모든 부서, 승인만으로 미션

- 상태: 확정 (2026-10-22, 사용자 결정)
- 대체 대상: 0014(D14) 중 "동의 확인" 부분, 0027 결정 2 중 "동의 확인"
- 관련: R-136(폐지), R-137(유지), 0026

## 맥락
중등부 · 고등부까지 영역을 넓히면서 보호자 동의 확인(R-136)을 다시 검토했다.
생일을 받지 않으므로(R-137) 나이로 자동 판단할 수 없다.

## 결정
1. **모든 부서 · 모든 참여자**에 대해 보호자 동의 확인을 두지 않는다.
2. 영역 관리자가 소속을 **승인하면 바로 미션**을 할 수 있다.
3. 소속에 동의 확인 속성(일시 · 확인자)을 두지 않는다. 진급 승인(0026)에서도 동의 확인 단계가 없다.
4. 아이 개인정보 최소화(R-137: 아이디 · 비밀번호 · 이름 또는 별명만, 전화 · 생일 · 주소 없음)는 **그대로 유지**한다.

## 위험 (결정 시 사용자에게 알림)
- 개인정보보호법 제22조의2 는 만 14세 미만 아동의 개인정보 처리에 **법정대리인 동의**를 요구한다.
  이 서비스는 아이디 · 이름 · 미션 기록을 처리하므로 대상이 될 수 있고, 위반 시 과태료 대상이 될 수 있다.
- 대안으로 "막지 않고 기록만" 하는 안을 제시했으나 사용자가 폐지를 택했다.
- 서비스 공개 전에 법률 확인을 권한다. 다시 넣어야 하면 새 ADR 로 소속에 동의 기록을 추가한다
  (소속 단위가 (계정, 영역)당 1건이므로 속성 추가로 끝난다).

## 결과
- 02 용어집 "동의 확인", 03 문서 R-136 을 폐지로 표시했다.
- 미션 수행 가능 검사는 "승인된 소속 + 참여자 역할"만 본다.
