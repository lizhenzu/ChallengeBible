# 0113 미션 프로그램 이름은 "도전!!! 성경미션"

- 날짜: 2026-11-18 · 상태: 결정(사용자 "도전!!! 성경미션" 1 · 미션 네 이름은 그대로)
- 바꾸는 결정: ADR 0039(한 플랫폼 두 프로그램) · 0099(성경필사)의 프로그램 이름

## 배경
"도전!!! 성경말씀"이 플랫폼 전체 이름이면서 동시에 말씀 · 퀴즈 · 기도 · 암송 프로그램의 이름이라, 통독 · 필사 · 365 기도까지 아우르는 이름과 한 프로그램 이름이 겹쳤다.

## 결정
1. **도전!!! 성경말씀** = 플랫폼(우산) 이름. 앱 이름 기본값 · 첫 화면 · 환영 문구 · 카톡 공유 이름은 그대로.
2. 말씀 · 퀴즈 · 기도 · 암송 프로그램 = **도전!!! 성경미션**. "도전!!! 성경"까지 같고 두 글자만 붙여 성경통독 · 성경필사와 나란히.
3. 미션 네 가지 이름(말씀 · 퀴즈 · 기도 · 암송)은 그대로.
4. 바꾸는 것은 화면 글자뿐: 부서 홈 프로그램 카드 · 미션 홈 · 순위 · ☰ 메뉴 · 참여 신청 칩 · 부서 고르기 칩 · 첫 화면 프로그램 칩 · 플랫폼 부서 관리 · 플랫폼 홈 · 기본 규칙 · 부서 선물 "개인 선물" 제목.
5. DB · 주소(`/word-mission` 등) · 코드 이름(MissionEnabled 등)은 바꾸지 않는다.

```
 ├─ 도전!!! 성경통독   장 · 절 읽기 · 진도율
 ├─ 도전!!! 성경필사   따라 쓰기 · 완필

```
