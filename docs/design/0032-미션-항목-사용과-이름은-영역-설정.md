# 0032. 미션 항목의 사용 여부와 표시 이름은 영역이 정한다

- 상태: 확정 (2026-10-22, 사용자와 합의)
- 보완 대상: 0010(D10)
- 관련: R-20, R-30, R-32, 03 문서 11절, 02 용어집 "미션 항목"

## 맥락
중등부 · 고등부까지 영역을 넓힌다(영역 추가만으로 가능 — 0003). 콘텐츠는 지금처럼 공용 하나 + 영역 덮어쓰기를 쓴다(0009 그대로).
그런데 "부모님께 읽어드리기", "부모님을 위해 기도" 같은 항목은 청소년 부서에 어색할 수 있다.
지금까지는 항목 점수만 바꿀 수 있고, 항목을 끄거나 이름을 바꿀 수 없었다(친구 기도만 사용 여부 있음).

## 결정
1. 영역 관리자는 **미션 항목마다** 다음을 정한다(규칙 설정의 일부).
   - 사용 여부(켜기 / 끄기)
   - 화면에 보이는 **표시 이름**(예: "부모님께 읽어드리기" → "가족과 함께 읽기")
   - 점수(기존과 같음)
2. 미션 종류(말씀 · 기도 · 퀴즈 · 암송) 자체를 끄는 것은 여전히 범위 밖이다(0010). 그래서 **미션마다 켜진 항목이 최소 1개** 있어야 한다.
3. 항목의 코드 이름(MissionItem)은 바뀌지 않는다. 표시 이름만 바뀐다.

## 결과
- "미션 완료"는 **켜진 항목 중 하나라도** 수행한 상태다(R-32 일반화). 완주일(0023)도 이 기준을 쓴다.
- 꺼진 항목은 화면에 나오지 않고, 서버도 수행을 거절한다.
- 항목을 꺼도 **이미 쌓인 기록 · 점수는 그대로**다(R-64와 같은 원칙). 다시 켜면 이어서 쓸 수 있다.
- 기도.친구 항목의 "사용 여부"(R-30)는 이 규칙의 한 경우가 된다.
- 표시 이름 변경은 규칙 변경 이력에 남는다. 기본 표시 이름은 화면 문구 리소스에 둔다(0019).
