# 0014. 만 14세 미만 — 최소 정보 + 교회 오프라인 동의 + 관리자 "동의 확인"

- 상태: 확정 (2026-10-21)
- 원래 결정: D14
- 관련: R-136, R-137

## 맥락
참여자 대부분이 만 14세 미만이다. 개인정보 보호법상 법정대리인 동의가 필요하다.
온라인 보호자 인증 절차를 만들기는 무겁고, 교회는 이미 오프라인으로 보호자를 만난다.

## 결정
- 아이 가입 시 받는 정보는 **아이디 · 비밀번호 · 이름(또는 별명)** 뿐이다.
  전화 · 생일 · 주소 등은 받지 않는다(R-137).
- 보호자 동의서는 **교회가 오프라인으로** 받는다.
- 영역 관리자가 소속 승인 때 **"보호자 동의 확인"** 을 표시해야 미션을 저장할 수 있다.
  확인 전에는 보기만 가능하다(R-136).
- 동의 확인 **일시 · 확인자**를 기록한다.

## 결과
- 동의 확인은 소속(Membership)의 속성이다. 영역마다 따로 확인한다.
- 미션 저장 API 가 동의 확인 여부를 서버에서 검사한다.
- 생일을 받지 않으므로 시스템은 사용자의 나이를 알 수 없다.
