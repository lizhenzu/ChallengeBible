# 0107 플랫폼 SQL 실행 화면

- 날짜: 2026-11-17 · 상태: 결정(사용자 "모바일에서 SQL 실행이 어려우니 웹 화면에서", 질문 답 2 = 쓰기 허용 · 시안 확정 1)
- 화면: `/platform/sql` (플랫폼 ☰ › 도구 › SQL 실행), 확정 시안 `docs/design/시안/SQL실행-단독시안.html`

## 배경
휴대폰에서는 SSMS 같은 도구로 운영 DB 를 보기 어렵다. 점검 · 원인 찾기(예: 학생에게 할 일이 뜨는 이유)를 웹 화면에서 하고 싶다.

## 결정
1. **플랫폼 관리자만**(정책 + 서비스에서 한 번 더). 시스템 연결(PlatformScope)이라 모든 부서를 한 번에 본다.
2. **늘 트랜잭션 안에서 실행**. 기본은 **시험 실행**: 끝나면 되돌린다(쓰기 문장도 결과만 보고 바뀐 것 없음).
   **저장**은 고른 뒤 확인 글자 `SAVE` 를 써야 커밋한다. 확인 글자가 없으면 실행하지 않는다.
3. **관리자 보호(R-315)**: 실행 전에 관리자(Admin · SuperAdmin 권한) 아이디를 정하고, 그 계정 · 권한 · 부서 소속 · 명부 줄의 지문(SHA-256)을 실행 전 · 후에 비교한다. 하나라도 바뀌면(지움 · 비밀번호 · 권한 빼기 포함) 저장을 고른 때도 되돌리고 알린다.
4. 이 보호를 넘을 수 있는 `COMMIT` · `ROLLBACK` · `BEGIN TRAN` · `SAVE TRAN` · `IMPLICIT_TRANSACTIONS` 는 받지 않는다.
5. 제한: 30초, 결과 표마다 5,000줄까지 보인다. 여러 결과 표 · 영향받은 줄 · PRINT 메시지를 보여 준다.
6. **감사 로그**: 실행한 SQL(앞 900자)과 방식(시험 · 저장 · 오류)을 남기고, 화면 아래 최근 10건을 보여 준다.
7. 자주 쓰는 쿼리 칩: 부서별 소속 · 할 일이 뜨는 이유 · 가짜 계정 수 · 오늘 365 기도.

## 결과
- `SqlConsoleService` · `Pages/Platform/Sql` · `wwwroot/js/sql.js`. 업무 규칙 R-320.
- 시험(메모리 DB)에서는 SQL 을 실행하지 않고 알림만 보인다. 실제 실행은 운영 · SQL Server 에서 확인.
