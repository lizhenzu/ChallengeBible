# 0047. 기도는 "성품기도" — 기본 항목은 나 · 가족·친구 (각 1점)

- 상태: 확정 (2026-10-22, 사용자와 합의)
- 보완 대상: R-30 · R-32(기도 항목), 02 용어집 "오늘의 기도", 0032(항목은 영역이 바꿀 수 있음)
- 관련: 시안 "기도 미션"(DailyMission4/Pray 구성)

## 결정
1. **기도 항목의 플랫폼 기본값**을 Bible2 와 같게 바꾼다.
   | 항목 코드 | 기본 표시 이름 | 기본 점수 |
   |---|---|---|
   | `Prayer.Me` | 나를 위해 기도했어요 | 1 |
   | `Prayer.Others` | 가족·친구를 위해 기도했어요 | 1 |
   하루 최대 2점(R-60 그대로). 둘 중 하나만 해도 기도 미션 완료.
   기존의 `Prayer.Parent` · `Prayer.Friend` 는 쓰지 않는다(아직 서비스 전이라 옮길 기록이 없다).
   영역은 0032 에 따라 이름 · 점수 · 사용 여부를 바꿀 수 있다.
2. **오늘의 기도 = 성품기도**. 공용 콘텐츠 DailyPrayer 는 다음을 가진다.
   - **성품 이름**(예: 신뢰)과 **영문 이름**(예: Trust, 선택)
   - **근거 말씀 범위**(예: 잠언 3:5~6) — 화면에서 본문을 접어 보여 줌
   - **기도문**: 문단 여러 개. 아이 이름이 들어갈 자리를 `{이름}` 표시로 쓴다.
     화면은 로그인한 참여자 이름(별명)으로 바꾸고 **강조 표시**한다. 조사(이/가 등)는 이름 받침에 맞춰 고른다.
3. 기존 DailyPrayer 의 제목 · 시작 · 본문 · 끝 문장 구조는 위 구조로 바꾼다.

## 결과
- 03 문서 R-30 · R-32 와 11절 기본값 표, 02 용어집 "오늘의 기도"를 고쳤다.
- 논리 · 물리 설계 DailyPrayer: `TraitName`, `TraitNameEn`, 근거 범위, `Paragraphs`(JSON 문단 목록, `{이름}` 자리 표시 포함).
- 이름 자리 바꾸기는 화면 쪽 일이며, 저장된 기도문은 바꾸지 않는다.
