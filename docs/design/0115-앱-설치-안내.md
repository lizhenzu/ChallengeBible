# 0115 앱 설치 안내(/install)와 설치 앱 하나

- 날짜: 2026-11-18 · 상태: 결정(사용자: 언제 띄울지 1 · 앱 하나로 통일 1 · 시안 설치안내 1)
- 바꾸는 결정: ADR 0038 결정 5(부서마다 매니페스트) — 설치 앱은 이제 하나. 부서 앱 이름 · 짧은 이름은 화면 안 제목에만 쓰인다
- 관련: 0034(PWA) · 0114(네잎 아이콘) · R-330 ~ R-332

## 배경
처음 들어온 사람이 홈 화면(바탕화면) 아이콘으로 바로 들어오게 하고 싶다(2026-11-18 사용자). 기기마다 설치 방법이 다르다.

| 기기 | 설치됐는지 아는 법 | 설치 |
|---|---|---|
| 안드로이드 크롬 · 삼성 인터넷 · PC 크롬 · 엣지 | 설치된 앱으로 열면 확실, 브라우저에서는 `getInstalledRelatedApps` | `beforeinstallprompt` 로 버튼 한 번 |
| 아이폰 사파리 | 설치된 앱으로 열 때만(`navigator.standalone`) — 브라우저에서는 알 수 없음 | 버튼 설치 불가, 공유 → 홈 화면에 추가 안내 |
| 카톡 · 밴드 · 인스타 등 앱 안 브라우저 | — | 설치 불가 → 바깥 브라우저로 옮김(카톡 `kakaotalk://web/openExternal`, 안드로이드 크롬 `intent://`) |

## 결정
1. **설치 앱은 하나**: `/manifest.webmanifest`(id · start_url · scope = `/`, 이름 · 짧은 이름 "도전!!!성경말씀", 네잎 아이콘, 바탕 흰색). 모든 화면이 이것을 쓴다. 열면 첫 화면이 로그인 상태에 따라 내 부서 홈 · 부서 고르기 · 참여 신청으로 보낸다(0045 · 0061 그대로).
   예전 `/{slug}/manifest.webmanifest` 는 이미 설치한 앱을 위해 남겨 둔다.
2. **설치 안내로 보내기**(`install-gate.js`, `<head>` 에서 바로): 브라우저로 연 화면이면 `/install?back=지금 주소` 로 보낸다. 보내지 않는 경우(R-331):
   설치된 앱으로 연 화면 · [이미 설치했어요] · [나중에] 뒤 7일 · 같은 창에서 이미 본 뒤 · 설치가 확인된 기기 · 자동 프로그램(검색 로봇 · 시험 · 캡처 브라우저) · 플랫폼 관리 화면 · 가장 중 · 설치 안내 자신 · 저장소(localStorage)가 막힌 브라우저.
   기억은 기기 브라우저의 localStorage `cb-install`(서버 · DB 에 남기지 않음).
3. **설치 안내 화면**(`/install`, 로그인 없이, 확정 시안 설치안내): 기기를 판별해 한 덩어리만 보인다.
   안드로이드 · PC(크롬 · 엣지) [설치하기] → 휴대폰 · 브라우저 확인 창 → 완료 안내 / 아이폰 3단계 그림 안내 / 앱 안 브라우저 [크롬 · 사파리로 열기] / 그 밖 PC 브라우저 즐겨찾기 안내.
   버튼을 눌러도 설치 신호가 없으면 브라우저 메뉴로 하는 법(이미 설치됐을 수도 있음)을 보여 준다.
   다 보면 `back`(이 사이트 안 주소만, R-330)으로 돌아간다. 설치하지 않아도 모든 화면을 쓸 수 있다.
4. ☰ 메뉴에 "📲 앱 설치"(설치된 앱 안에서는 숨김). `install` 은 부서 주소로 쓸 수 없다(ReservedSlugs).

## 결과
- 아이폰은 브라우저에서 설치 여부를 알 수 없어, 설치한 사람도 [이미 설치했어요]를 한 번 눌러야 사파리에서 다시 안 뜬다.
- 부서가 정한 짧은 이름은 설치 앱 이름에 쓰이지 않는다(관리 › 이름 · 색의 "휴대폰 홈 화면" 미리보기는 따로 정리할 일).
- 화면을 처음 열 때 설치 여부 확인(안드로이드 · PC)으로 아주 잠깐 원래 화면이 보였다가 옮겨질 수 있다.

## 2026-11-24 새 시안 「PC 설치 안내」 적용 — 모달이 아닌 페이지
- 사용자가 준 모달 시안(`install-modal.html`)을 **모달 없이** `/install` 페이지에 적용했다: 연한 회색(`#F4F6F9`) 바탕 가운데에 흰 카드(폭 440px · 모서리 28px · 그림자), 폰(≤520px)에서는 카드를 화면 폭으로 펴고 그림자 · 둥근 모서리를 뺀다.
- 카드 안: 로고(76px) → 제목(「도전!!! 성경말씀」 느낌표 분홍 · 주황 · 파랑 + 「PC에 설치하세요」) → 부제 → **작업 표시줄 미리보기(PC만)** → 장점 3개(아이콘 + 설명 줄) → 검정 「PC에 설치하기」(안드로이드는 「바탕화면에 설치하기」) → 「이미 설치했어요 | 나중에 할게요」. 카드 오른쪽 위 ✕ = 「나중에 할게요」(7일).
- 설치가 끝나면 같은 카드에서 「설치가 끝났어요」 + 「지금 열기」 · 「닫기」.
- 동작(install.js · install-gate.js · R-330 ~ R-332)은 그대로. 아이폰 · 카톡 안 · 설치 미지원 브라우저 안내는 내용 그대로 같은 카드 안에 들어간다.
