# 0142 메인화면을 모든 부서에(부서마다 직접 입력)

- 날짜: 2026-11-27 · 상태: **설계 확정(구현 전)** · 사용자 질문 6개에 답해 확정(모델 Opus 로 설계)
- 이어받는 것: ADR 0140(유년부 소개 화면) — 「유년부만 특화」를 풀고 모든 부서로 넓힌다. 용어는 용어집의 **메인화면 · 홈 · 첫 화면**.

## 배경
메인화면(`/{부서}/welcome`)은 지금 유년부만 있다. 소개 줄(`app.TenantIntro`)이 있는 부서에만 열리고 관리 화면(`/{부서}/admin/intro`)도 다른 부서는 404 이다. 사용자 결정(2026-11-27): **유년부만 특화가 아니다.** 모든 부서에 메인화면이 있고, 각 부서가 자기 내용을 직접 입력한다. 기존 기능이 있으면 재활용하거나 넓힌다.

## 결정(사용자 질문 · 답)
1. **모든 부서에 메인화면.** 항상 켜 둔다(`TenantIntro.IsActive` 「보이기 켬/끔」은 없앤다). 소개 줄이 없는 부서는 처음 열 때(또는 관리 화면 첫 방문 때) 빈 줄을 자동으로 만든다. 단체사진이 없으면 「단체사진이 아직 없어요」, 제목이 없으면 부서 이름을 보여 준다.
2. **이번 주 말씀 — 부서마다 직접 입력(새 기능).** 공용 말씀(플랫폼이 모든 부서에 같이 넣는 오늘의 말씀)이 아니다. 칸은 **세 개**: 주일 날짜 · 말씀 제목 · 설교 내용. 날짜는 입력한 날이 아니라 **그 말씀을 전한 주일 날짜**를 고른다(일요일만 고를 수 있다). 부서마다 주일이 하나에 말씀이 하나(같은 주일을 다시 올리면 고친다).
3. **누가 입력하나: 부서 관리자만**(교사는 못 한다 — 소개 글과 같다). 보는 것은 누구나(손님 포함).
4. **「준비중」 규칙** — 칸을 누를 수 없고(흐리게) 「준비중」 글자를 붙인다:
   - **이번 주 주보**: 가장 최근 주보 날짜에서 **7일이 지났으면**(또는 주보가 없으면) 준비중. 기존 `Bulletin` 재활용.
   - **이번 주 말씀**: 가장 최근 말씀의 주일 날짜에서 7일이 지났으면(또는 없으면) 준비중. 새 `WeeklyWord` 사용.
   - **앨범**: **보는 사람이 볼 수 있는 사진이 0장**이면 준비중(공개 범위를 따른다 — 손님은 「누구나」 공개만 센다). 기존 `Album`(`PhotoService`) 재활용.
   - **소개**: 소개 글(본문)이 비었으면 준비중. 기존 `TenantIntro.Body` 재활용.
   - **도전!!!성경말씀 · 교사행정업무 · 챙길 선물**: 지금 그대로(의견 없음).
   - 준비중이라도 지난 것은 못 본다(누르면 들어가는 안을 택하지 않았다 — 질문 4).
5. **부모님과 함께하는 미션북 칸은 유년부에만 보이고 다른 부서는 숨긴다.** 방법은 **부서 스위치**: `Tenant` 표에 `MissionBookEnabled`(기본 끔)를 두고(`MissionEnabled` · `ReadingEnabled` · `CopyEnabled` 와 같은 방식), 마이그레이션이 유년부만 켠다. 기능이 아직 없으므로 켜져 있어도 흐리게 · 안 눌린다(지금과 같음). 부서 관리 화면에 켜기 · 끄기 스위치를 둔다.
6. **「소개」 칸(06)은 새 「부서 소개」 화면**(`/{부서}/about`)을 연다. **소개 글만** 보여 준다(예배 안내는 이 화면에 넣지 않는다). 글은 기존 `/{부서}/admin/intro` 의 소개 글을 쓴다.
7. 홈 머리줄의 메인화면(집) 동그라미는 이제 **모든 부서**에 보인다(메인화면이 항상 있으니 조건이 사라진다). 첫 방문자에게 전체 주소로 알려 주는 방식은 그대로.

## 구조(구현 때)
- 표 `app.WeeklyWord`(새): `TenantId` · `SundayDate`(date, 일요일만) · `Title`(60자) · `Body`(설교 내용, 4000자) · `CreatedUtc`/`UpdatedUtc`/`UpdatedByUserName`. 키 = (TenantId, SundayDate) 유일. `ITenantOwned` + RLS(`sec.TenantIsolation`) + EF 전역 필터(D20 이중 격리). 바꾼 기록은 AuditLog `WeeklyWord`.
- `Tenant.MissionBookEnabled`(bit, 기본 0) + 유년부만 1(마이그레이션 · 운영 SQL `tools/sql/`).
- 화면(새): `/{부서}/admin/weekly-word`(목록 + 입력 · 고치기 · 지우기, 부서 관리자만) · `/{부서}/weekly-word`(가장 최근 말씀 보기, 누구나) · `/{부서}/about`(소개 글 보기, 누구나).
- 기존 변경: `IntroService.GetAsync` 가 줄이 없으면 만들어 돌려준다 · `Admin/Intro` 의 404 · 보이기 스위치 제거 · `Welcome/Index` 가 「준비중」 판단(`WelcomeStatusService` 새, 한 곳에서 계산) · `TenantHome` 의 `MainOn` 조건 제거.
- 「준비중」 판단은 **부서 시간대 오늘**을 쓴다(저장은 UTC, 규칙: 날짜는 영역 시간대).

## 업무 규칙(03 문서에 추가)
- **R-373** 메인화면은 모든 부서에 있고 부서 관리자가 직접 입력한다(소개 글 · 대표 사진 · 이번 주 말씀). 다른 부서 것은 보이지도 고칠 수도 없다(TenantId).
- **R-374** 이번 주 말씀은 **주일 날짜 · 제목 · 설교 내용**. 부서 관리자만 입력. 주일 날짜가 일요일이 아니면 막는다. 같은 주일은 한 건.
- **R-375** 준비중: 주보 · 말씀은 가장 최근 것의 날짜에서 7일 지나면, 앨범은 볼 수 있는 사진 0장이면, 소개는 소개 글이 없으면. 준비중 칸은 누를 수 없다.
- **R-376** 미션북 칸은 `Tenant.MissionBookEnabled` 가 켜진 부서에만 보인다(처음엔 유년부만).
- **R-377** 「소개」 칸은 새 소개 화면(소개 글만)을 연다.
