# 0077. 축하 단계는 부서마다 정한다

- 상태: **확정**(2026-11-02, 사용자: "축하 단계는 부서마다 정하게 바꾸기", 정하는 사람 1안 "부서 관리자", 화면 A안 "알약 칸 고치기")
- 관련: 0060(점수 규칙은 플랫폼 하나 — 축하 단계만 이 결정으로 예외), 0028(시즌), 0076(성장 단계는 모든 부서 같음), 시안 `ms.png`

## 결정
1. 개인 축하 단계(R-100)만 부서 값으로 덮을 수 있다. 나머지 점수 규칙 · 가족 축하 단계 · 성장 단계는 플랫폼 하나 그대로.
2. 값은 부서 표 `app.Tenant.Milestones`(varchar(100), "1000,2000,3000"), null = 플랫폼 기본. 규칙 읽기(`RuleService.ForDateAsync`)가 부서 값으로 덮어서
   축하 창 · 다음 축하까지 · 목표 점수(순위 달성률, R-82)가 저절로 따른다.
3. 부서 관리자가 **관리 › 시즌 "우리 부서 축하 단계"** 칸에서 정한다(알약 + ✕ 빼기 + "단계 더하기", 막대 미리보기, 이미 넘은 아이 수, "플랫폼 기본으로").
   1 ~ 10단계, 100 ~ 1,000,000점, 같은 점수는 하나로.
4. 바꾸는 순간 새 단계 가운데 이미 넘은 것은 참여자마다 "받음"으로 기록(R-104) — 축하 창이 한꺼번에 뜨지 않는다. 바꾼 내용은 감사 기록(`TenantMilestones`).
5. 실제 DB: `tools/sql/migrate-tenant-milestones.sql` 을 게시 전에 실행.
