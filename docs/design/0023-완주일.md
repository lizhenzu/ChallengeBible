# 0023. 완주일 — 4가지 미션이 모두 있고 모두 완료한 날

- 상태: 확정 (2026-10-21)
- 원래 결정: D23
- 관련: R-72, R-122

## 맥락
콘텐츠가 없는 날(예: 퀴즈를 못 만든 날)을 완주일로 볼지 정해야 했다.

## 결정
- 완주일 = 말씀 · 기도 · 퀴즈 · 암송 **4가지 콘텐츠가 모두 있고, 4가지 모두 완료**한 날. 현행과 같다.
- 콘텐츠가 하나라도 없는 날은 완주일이 될 수 없다.
- 암송은 "그 날이 속한 주의 암송을 했는가"로 판단한다(R-72).

## 결과
- 관리자 화면(콘텐츠 달력)에서 콘텐츠가 빈 날을 미리 경고한다(R-122).
- "미션 완료"의 뜻: 말씀 = 두 항목 중 하나 이상, 기도 = 세 항목 중 하나 이상(친구만 해도 완료),
  퀴즈 = 정답, 암송 = 그 주에 완료. (퀴즈를 2번 다 틀린 날은 퀴즈 미완료 → 완주일 아님)
