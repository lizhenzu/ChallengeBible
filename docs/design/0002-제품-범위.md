# 0002. 제품 범위 — 미션 · 점수 중심, 출석 · 반 · 선물 제외

- 상태: 확정 (2026-10-21)
- 원래 결정: D2
- 관련: 01 문서 3절, 04 문서 4절, X-16

## 맥락
현행 미션 홈은 출석 · 세계관 · 묵상 · 전도 점수와 선물 금액까지 함께 계산한다(X-16).
기능 하나를 바꾸면 미션 홈이 깨지는 결합 구조다.

## 결정
포함:
- 매일 미션 4종(말씀 · 기도 · 퀴즈 / 암송은 매주), 성경 본문 읽기(절 읽음 · 책갈피 · 대조 번역)
- 점수(하루 · 시즌 · 최근 7일 · 연속 참여일), 달력
- 순위, 가족팀, 개인 축하 단계
- 콘텐츠 관리(공용 라이브러리 + 영역 덮어쓰기), 테넌시 관리

제외(별도 시스템, 필요하면 연동):
- 출석 체크, 반 · 학년 관리(참여자에 선택 **그룹 라벨**만), 선물 · 도토리,
  통합 점수(출석 + 세계관 + 묵상 + 전도 + 미션), 기존 데이터 이전

## 결과
- 이 서비스는 **자기 점수만** 계산한다.
- 범위 밖 시스템과는 04 문서 4절의 출구로만 만난다:
  - 제공: 참여자 점수 조회 API
  - 발행: `MilestoneReached`, `FamilyMilestoneReached`, (선택) `ActivityRecorded`
  - 받기(선택): 그룹 라벨 동기화
- 축하 단계 도달 시 "선물 고르기"로 보내지 않는다. 이벤트만 내고, 받는 쪽이 없으면 축하 메시지만 보인다.
