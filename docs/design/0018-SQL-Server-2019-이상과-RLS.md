# 0018. 새 DB 는 SQL Server 2019 이상, RLS 로 영역 격리

- 상태: 확정 (2026-10-21)
- 원래 결정: D18
- 관련: 0007, 0020, 0021

## 맥락
행 수준 보안(RLS)은 SQL Server 2016 부터 지원된다. 현행 DB 서버는 2014 라 RLS 를 쓸 수 없음을 확인했다.

## 결정
- 새 DB 는 **SQL Server 2019 이상**으로 만든다.
- 영역 격리는 **RLS** 로 DB 수준에서 강제한다.

## 결과
- 현행 DB 서버(2014)는 쓰지 않는다.
- RLS 정책(필터 · 차단 조건자)은 물리 설계에서 정의한다.
- 공유 호스팅에서 RLS 를 쓰려면 정책 생성 권한(DDL)이 필요하다 — 마이그레이션 계정 권한을 배포 단계에서 확인한다.
