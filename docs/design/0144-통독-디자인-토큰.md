# 0144 통독 화면 디자인 토큰 · 공통 컴포넌트 (2026-11-28)

확정 시안 보드 「디자인 기준표」를 코드로 옮긴 기록. 대상: 성경통독 메인 · 구약/신약 읽기 · 성경 읽기 본문.

## 결정
- 색 · 간격 · 모서리 값은 `wwwroot/css/reading-home.css` 맨 위 `.rhp { --rh-* }` 한 곳에만 쓴다. 값을 바꿀 때는 거기만 고친다.
- 공통 컴포넌트(헤더 · 탭 · 흰 카드 · 초록 카드 · 링 · 진행 바 · 칸 · 책 칩 · 접기 줄 · 해설 구간 · 절 행 · 주요/보조 버튼 · 알약 · 범례)는 같은 CSS 규칙을 세 화면이 나눠 쓴다. 링 · 탭은 부분 뷰(`_RhRing` · `_RhTabs`).
- 읽기 상태 색: 읽음 = 진한 초록 `#4B7A56`(흰 글자) · 현재(보던 곳) = 연두 `#A8D5A2`(글자 `#1F4A2B`) · 아직 = 연회색 `#E4EADB`(글자 `#5F7A64`). 「오늘」 동그라미만 예외 `#FFF1B8`(글자 `#6B5300`). 진한 초록은 읽음 · 주요 버튼 · 선택된 탭에만.
- 이동 버튼 이름: 「홈으로」 = 앱 홈(부서 홈), 「통독홈」 = 통독 메인(`/{slug}/reading`).
- 글꼴: 이 세 화면은 Noto Sans KR 400 / 500 / 700 만 불러온다(`ViewData["FontsLite"]`). 다른 화면은 예전 그대로(300 ~ 900 + Noto Serif KR).

## 확인 사항
- 본문 맨 아래 「대시보드」 버튼(`/{slug}/reading`)과 헤더 「통독홈」(`/{slug}/reading`)은 같은 화면이다 → 사용자에게 하나로 합칠지 확인 요청(시안 지시: 같은 화면이면 하나로).
