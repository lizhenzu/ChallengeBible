# 0137 첫 화면(/) 「우리 가족팀」 카드 삭제

- 날짜: 2026-11-23 · 상태: 결정(사용자 "홈루트에서 우리 가족팀 삭제해줘")
- 관련: ADR 0132(가족팀 카드 복원) · 0136(나의 도전 화면 신설)

## 배경

0136으로 「나의 도전 현황」 카드를 첫 화면에서 빼면서, 첫 화면(`/`)에 남은 큰 카드는
선물 대상자 · 우리 가족팀 둘이 됐다. 사용자가 그중 **우리 가족팀** 카드를 빼 달라고 했다.

## 결정

1. **첫 화면(`/`)에서 `.hmx-fam` 카드를 삭제** — 팀 점수 · 구성원 · 다음 가족 축하 진행 막대를 그리지 않는다.
2. **초대 배너(`.hmx-inv`)와 만들기 유도(`.hmx-make`)는 그대로 둔다** — 해야 할 행동(수락 · 만들기)은 남기고,
   이미 하고 있는 것(팀 점수)은 팀 화면에서 본다.
3. **부서 홈(`/{slug}`)은 그대로** — 이번 요청은 홈루트에 한정한다.
4. 값 계산도 함께 뺀다 — 첫 화면에서 쓰지 않는 `inv` 지역 변수를 지운다(팀 점수 · 진행률 계산 제거).

## 구현

- `Pages/Index.cshtml` — `else if (Model.Family is { } f)` 블록(우리 가족팀 카드) 삭제, 미사용 `inv` 변수 삭제.
- `IndexModel.Family` 는 초대 배너 판단(`Family is null` 일 때만 초대를 본다)에 계속 쓰므로 남긴다.
- 테스트: `LandingTests` · `LobbyTests` · `FamilyJoinTests` · `HomeMainTests` · `FamilyTeamTests` 72건 통과.

## 하지 않은 것

- 부서 홈의 우리 가족팀 카드는 그대로(사용자가 홈루트만 말했다).
- 가족팀 화면 · 초대 흐름 · 점수 계산은 바꾸지 않는다.
