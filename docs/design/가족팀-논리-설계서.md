# 가족팀 구성 논리 설계서

- 기준: 도전 성경말씀 main `61cb14b`의 구현 코드와 업무 규칙(R-90 ~ R-97, R-204 ~ R-213), ADR 0083 · 0084
- 목적: 다른 사이트에 같은 기능을 옮긴다. 그쪽 표 구조가 다르므로 **표 이름이 아니라 개념 · 규칙 · 동작**을 정의한다.
- 읽는 법: "반드시"는 이 기능의 핵심 규칙이고, "선택"은 사이트 사정에 따라 뺄 수 있다.

---

## 1. 기능 요약

참여자가 관리자 승인 없이 **가족팀을 직접 만들고**, 두 가지 길로 구성원을 모은다. 팀 점수는 구성원 개인 점수의 합이다.

| 길 | 시작하는 사람 | 결정하는 사람 |
|---|---|---|
| **합류 신청** | 들어오려는 사람 | 팀의 구성원 누구든 |
| **초대** | 팀의 구성원 누구든 | 초대받은 본인 |

**설계 원칙**

1. **본인 동의 없이 팀에 넣지 않는다.** 신청은 본인이 내고, 초대는 본인이 수락한다.
2. **팀 안에는 직책이 없다.** 팀장 없이 모든 구성원의 권한이 같다.
3. **점수는 사람에게 붙는다.** 팀은 합계를 보여 줄 뿐이고, 팀에서 나가도 개인 점수는 그대로다.
4. **빈 팀은 남기지 않는다.** 마지막 구성원이 빠지면 팀을 지운다.
5. **처리된 신청 · 초대는 지운다.** 거절 이력을 남기지 않으므로 다시 신청 · 초대할 수 있다.

## 2. 먼저 맞출 개념

다른 사이트에 적용하기 전에 아래 표의 오른쪽을 채운다. 이 문서의 나머지는 왼쪽 용어로 쓴다.

| 이 문서의 용어 | 뜻 | 다른 사이트에서 대응하는 것 |
|---|---|---|
| 계정 | 로그인하는 사람 | |
| 영역 | 팀이 속하는 단위(여기서는 교회 부서). 영역끼리 데이터가 분리된다 | |
| 참여자 | 한 영역에서 활동하는 사람. 계정 + 영역마다 하나 | |
| 활동 가능한 참여자 | 소속이 승인됐고 멈추지 않은 참여자 | |
| 개인 점수 | 참여자가 시즌 동안 얻은 점수의 합 | |
| 시즌 | 점수를 모으는 기간(여기서는 해마다) | |
| 오늘 | 영역 시간대의 날짜 | |
| 기능 스위치 | 가족팀 기능을 켜고 끄는 설정 | |

**영역이 하나뿐인 사이트:** 규칙 B-05와 영역 칸을 빼면 된다.

## 3. 논리 데이터 모델

### 3.1 관계

```
영역 1 ─── N 가족팀
가족팀 1 ─── N 구성원 N ─── 1 참여자     (참여자는 활성 팀 0 ~ 1개)
가족팀 1 ─── N 합류 신청 N ─── 1 참여자  (참여자는 신청 0 ~ 1개)
가족팀 1 ─── N 초대 N ─── 1 참여자       (참여자는 여러 팀의 초대를 받을 수 있음)
초대 N ─── 1 참여자(초대한 사람)
가족팀 1 ─── N 단계 도달 기록
```

### 3.2 엔터티

**가족팀**

| 속성 | 필수 | 설명 |
|---|---|---|
| 식별자 | 예 | |
| 영역 | 예 | |
| 팀 이름 | 아니요 | 최대 50자. 비우면 B-03으로 표시. 같은 이름 허용 |
| 만든 시각 | 예 | UTC |

**구성원**

| 속성 | 필수 | 설명 |
|---|---|---|
| 식별자 | 예 | |
| 영역 · 가족팀 · 참여자 | 예 | 팀과 참여자는 같은 영역이어야 한다 |
| 역할 | 예 | 3.3의 값 |
| 표시 순서 | 예 | 들어온 차례. 새 구성원은 지금 가장 큰 값 + 1 |

**합류 신청**

| 속성 | 필수 | 설명 |
|---|---|---|
| 식별자 | 예 | |
| 영역 · 가족팀 · 참여자 | 예 | 신청한 사람 |
| 역할 | 예 | 신청자가 고른 값. 수락되면 그대로 쓴다 |
| 신청 시각 | 예 | UTC |

**초대**

| 속성 | 필수 | 설명 |
|---|---|---|
| 식별자 | 예 | |
| 영역 · 가족팀 · 참여자 | 예 | 초대받은 사람 |
| 초대한 참여자 | 예 | 표시용. 권한은 팀에 있다 |
| 역할 | 예 | 초대한 사람이 고른 값. 받는 사람이 바꿀 수 있다 |
| 초대 시각 | 예 | UTC |
| 미룬 날 | 아니요 | "다음에 할래요"를 누른 날(영역 시간대의 날짜) |

**단계 도달 기록**(선택: 축하 기능을 옮길 때)

| 속성 | 필수 | 설명 |
|---|---|---|
| 영역 · 가족팀 · 시즌 · 단계 점수 | 예 | 이 네 개가 함께 식별자 |
| 도달 시각 | 예 | UTC |

**가족 단계 설정**(선택: 축하 기능을 옮길 때): 단계 점수, 이모지, 문구, 종류(보상 · 박수), 사용 여부를 설정으로 둔다. 코드에 값을 쓰지 않는다. 지금 기본값은 1,000 · 3,000 · 5,000 보상, 2,000 · 4,000 박수다.

### 3.3 역할 값

학생 · 엄마 · 아빠 · 할머니 · 할아버지 · 기타. 역할은 표시와 팀 이름 계산에만 쓰고 **권한과는 상관없다**. 같은 역할이 둘이어도 된다.

### 3.4 저장소에서 지켜야 할 제약 (반드시)

화면 검사만으로는 동시에 눌렀을 때 뚫리므로 저장소 제약으로 막는다.

| 번호 | 제약 | 지키는 규칙 |
|---|---|---|
| C-1 | 한 영역에서 참여자당 활성 구성원 자리는 하나 | B-04 |
| C-2 | 한 영역에서 참여자당 합류 신청은 하나 | B-07 |
| C-3 | 같은 팀 · 같은 사람의 초대는 하나 | B-12 |
| C-4 | 같은 팀 · 같은 사람의 구성원 줄은 하나 | |
| C-5 | 팀 · 시즌 · 단계마다 도달 기록은 하나 | B-23 |
| C-6 | 팀과 구성원 · 신청 · 초대 · 기록은 같은 영역이어야 한다 | |
| C-7 | 역할은 3.3의 값만 | |

제약에 걸리면 오류 화면 대신 "이미 처리됐어요" 종류의 안내를 낸다.

## 4. 업무 규칙

### 기본

| 번호 | 규칙 |
|---|---|
| B-01 | 기능 스위치가 꺼져 있거나 임시 영역(가입 대기용)이면 만들기 · 찾기 · 신청 · 수락 · 초대를 막는다. 스위치가 꺼지면 가족팀 화면도 열리지 않는다. 서버에서 나가기 · 이름 바꾸기처럼 이미 든 팀 안의 동작은 스위치로 막지 않는다 |
| B-02 | 모든 동작은 활동 가능한 참여자만 한다 |
| B-03 | 팀 이름이 비면 "{대표 학생 이름} 가족"으로 표시한다. 대표 학생은 역할이 학생인 첫 구성원이고, 없으면 첫 구성원이다 |
| B-04 | 한 참여자는 활성 팀 하나에만 든다. 다른 팀에 가려면 먼저 나간다 |
| B-05 | 한 사람(계정)은 한 영역의 가족팀에만 든다. 다른 영역 팀에 들어 있으면 만들기 · 신청 · 수락 · 초대 수락이 막히고, 초대 후보에도 나오지 않는다 |
| B-06 | 팀 인원, 초대 수에는 제한이 없다 |

### 합류 신청

| 번호 | 규칙 |
|---|---|
| B-07 | 역할을 골라 한 번에 한 팀에만 신청한다. 수락 전에는 취소할 수 있다 |
| B-08 | 이미 팀이 있거나 신청 중이면 팀을 만들거나 신청할 수 없다 |
| B-09 | 그 팀의 구성원 누구든 수락 · 거절한다 |
| B-10 | 수락할 때 다시 검사한다. 신청자가 그사이 자격을 잃었으면(멈춤, 다른 팀 합류, 다른 영역 팀 합류) **신청을 지우고 이유를 알린다** |

### 초대

| 번호 | 규칙 |
|---|---|
| B-11 | 구성원 누구든 같은 영역의 참여자를 이름으로 찾아 역할을 골라 초대한다 |
| B-12 | 후보에는 **팀이 없는 사람의 이름만** 보인다. 우리 팀에 이미 신청했거나 초대받은 사람, B-05에 걸리는 사람은 빠진다. 최대 20명 |
| B-13 | 수락 전에는 구성원 누구든 취소한다. 초대한 사람이 나가도 초대는 팀의 것이라 남는다 |
| B-14 | 한 사람이 여러 팀의 초대를 받을 수 있고, 합류 신청 중에도 받을 수 있다 |
| B-15 | 수락 · 거절은 초대받은 본인만 한다. 초대받은 역할을 바꿔서 수락할 수 있고, 수락하면 바로 구성원이 된다 |

### 신청 · 초대가 사라지는 때

| 번호 | 규칙 |
|---|---|
| B-16 | 어느 팀이든 들어가면(새 팀 · 신청 수락 · 초대 수락) 그 사람이 받은 초대를 **모두** 지운다 |
| B-17 | 초대를 수락하면 그 사람이 낸 합류 신청도 지운다 |

### 나가기 · 내보내기 · 빈 팀

| 번호 | 규칙 |
|---|---|
| B-18 | 구성원은 언제든 나갈 수 있고 다른 구성원을 내보낼 수 있다(자기 자신은 나가기로) |
| B-19 | 나가도 개인 점수는 그대로이고 팀 합계에서만 빠진다. 이미 넘은 단계 기록은 취소하지 않는다 |
| B-20 | **마지막 구성원이 빠지면 팀과 그 팀의 구성원 · 신청 · 초대 · 단계 기록을 한 번에 지운다.** 나가기 전에 "마지막 구성원이에요. 나가면 팀이 사라져요."로 알리고, 나간 뒤 "가족팀에서 나왔어요. 마지막 구성원이라 팀이 삭제됐어요"로 알린다 |
| B-21 | 사람이 다른 영역으로 옮겨지면 옮기기 전에 그 사람의 구성원 자리, 신청, 받거나 보낸 초대를 지운다. B-20도 그대로 적용한다 |

### 이름 · 역할

| 번호 | 규칙 |
|---|---|
| B-22 | 구성원 누구든 팀 이름을 바꾼다. 역할은 본인 것만 바꾼다 |

### 점수 · 축하 (선택)

| 번호 | 규칙 |
|---|---|
| B-23 | 팀 점수는 활동 가능한 구성원의 시즌 점수를 단순히 더한 값이다 |
| B-24 | 점수를 받은 직후 팀 합계가 새로 넘은 단계를 시즌 · 팀마다 한 번 기록하고, 가장 높은 단계로 축하 팝업을 보여 준다. 동시에 기록하면 먼저 저장한 쪽만 축하를 본다 |
| B-25 | 점수를 받은 활동이 취소되어 합계가 줄면, 합계보다 높은 단계 기록을 지운다. 다시 넘으면 또 축하한다 |
| B-26 | 개인 순위에는 구성원도 그대로 나온다. 팀 순위는 팀 점수순, 같으면 이름순이다 |

### 찾기 · 보이는 정보

| 번호 | 규칙 |
|---|---|
| B-27 | 팀 찾기는 사람 이름 · 팀 이름으로 하고 최대 20개다. 결과에는 팀 이름과 구성원 이름 · 역할만 보이고 **점수는 보이지 않는다** |
| B-28 | 영역 관리자는 팀을 보고, 팀 이름 고치기와 구성원 빼기만 한다. 만들기 · 넣기는 하지 않는다. 관리자가 마지막 구성원을 빼도 B-20을 적용한다 |

## 5. 참여자 상태

한 참여자는 항상 아래 중 하나다. **초대는 상태가 아니라 덧붙는 정보**여서 "팀 없음"과 "신청 중" 양쪽에 있을 수 있다.

| 지금 상태 | 동작 | 다음 상태 |
|---|---|---|
| 팀 없음 | 팀 만들기 | 구성원 |
| 팀 없음 | 합류 신청 | 신청 중 |
| 팀 없음 · 신청 중 | 초대 수락 | 구성원 (신청 · 받은 초대 삭제) |
| 신청 중 | 신청 취소 · 상대 거절 | 팀 없음 |
| 신청 중 | 상대 수락 | 구성원 (받은 초대 삭제) |
| 구성원 | 나가기 · 내보내짐 · 관리자가 뺌 | 팀 없음 (마지막이면 팀 삭제) |

## 6. 동작 정의

호출자는 모두 로그인한 활동 가능한 참여자다. 각 동작은 **한 트랜잭션**으로 처리한다.

| 동작 | 입력 | 조건 | 결과 |
|---|---|---|---|
| 팀 만들기 | 이름(선택), 역할 | 팀 · 신청 없음, B-05 | 팀 + 첫 구성원 생성, 받은 초대 삭제 |
| 팀 찾기 | 검색어 | 스위치 켜짐 | B-27의 결과 |
| 합류 신청 | 팀, 역할 | 팀 · 신청 없음, B-05, 구성원이 있는 팀 | 신청 생성 |
| 신청 취소 | | 내 신청 있음 | 신청 삭제 |
| 신청 수락 | 신청 | 그 팀 구성원, B-10 | 신청 삭제, 구성원 생성, 받은 초대 삭제 |
| 신청 거절 | 신청 | 그 팀 구성원 | 신청 삭제 |
| 초대 후보 찾기 | 검색어 | 내가 구성원 | B-12의 결과 |
| 초대 | 참여자, 역할 | 내가 구성원. 상대가 활동 가능, 팀 없음, 우리 팀 신청 · 초대 없음, B-05 | 초대 생성 |
| 초대 취소 | 초대 | 그 팀 구성원 | 초대 삭제 |
| 초대 수락 | 초대, 역할 | 본인, 팀 없음, B-05, 팀에 구성원 있음 | 구성원 생성, 받은 초대 · 내 신청 삭제 |
| 초대 거절 | 초대 | 본인 | 초대 삭제 |
| 다음에 할래요 | | | 받은 초대 전부의 미룬 날 = 오늘 |
| 나가기 | | 내가 구성원 | 구성원 삭제. 마지막이면 B-20 |
| 내보내기 | 구성원 | 같은 팀, 내가 아님 | 구성원 삭제 |
| 팀 이름 바꾸기 | 이름 | 내가 구성원 | 이름 변경 |
| 내 역할 바꾸기 | 역할 | 내가 구성원 | 역할 변경 |

**빈 팀 삭제 순서:** 저장소가 연쇄 삭제를 하지 않으면 구성원 → 신청 → 초대 → 단계 기록 → 팀 순서로 지운다.

**오류 종류**

| 상황 | 안내 내용 |
|---|---|
| 기능 꺼짐 | 지금 쓸 수 없음 |
| 대상 없음 | 이미 처리됐거나 없어진 팀 · 신청 · 초대 |

| 이미 팀 있음 | 팀에서 나와야 함 |
| 신청 중 | 신청을 취소해야 함 |
| 다른 영역 팀에 있음 | 한 사람은 한 영역의 팀에만 |
| 구성원 아님 | 그 팀 구성원만 할 수 있음 |
| 잘못된 역할 | 역할을 다시 고름 |
| 상대가 이미 팀 있음 · 신청함 · 초대받음 · 다른 영역 팀에 있음 | 초대할 수 없는 이유를 각각 안내 |

## 8. 화면과 알림

**푸시 알림은 없다.** 화면 안에서만 알린다.

| 위치 | 내용 |
|---|---|
| 미션 홈 맨 아래 입구 | 팀 없음: "우리 가족팀 만들기". 신청 중: 신청한 팀. 팀 있음: 이름 · 점수 · 기다리는 신청 수 |
| 영역 홈(말씀 찾기 위) | 팀이 없고 오늘 미루지 않은 초대가 있을 때 주황 배너 + "다음에 할래요" |
| 가족팀 화면 | 만들기, 찾기, 신청, 받은 초대, 우리 팀(구성원 · 신청 · 보낸 초대), 초대 찾기, 이름 · 역할 바꾸기, 나가기 |
| 영역 홈 "우리 가족팀" | 팀 점수, 구성원별 오늘 활동 · 점수, 단계 축하 |
| 순위 "가족팀" 탭 | 팀 순위, 구성원, 넘은 단계 배지 |
| 활동 완료 직후 | 단계 축하 팝업 |
| 관리 화면 | 팀 목록, 이름 고치기, 구성원 빼기 |

**"다음에 할래요":** 초대 줄마다 날짜를 적으므로 ① 어느 기기에서나 같고 ② 내일 다시 보이며 ③ 같은 날 새로 온 초대는 보인다. 숨겨도 초대는 남아 가족팀 화면에서 처리할 수 있다.

## 9. 옮길 때 판단할 점

**구현과 규칙 문서가 다른 곳:** R-91은 "한 시즌에 한 팀"이라고 쓰지만, 구현은 **동시에 한 팀**만 막는다. 시즌 중 나가서 다른 팀에 갈 수 있다. 이 문서는 구현을 따랐다. 시즌 점수가 상금과 연결된다면 그쪽 사이트에서 다시 정해야 한다.

**이 구현의 위험 (그대로 옮기면 함께 따라온다)**

| 항목 | 내용 | 대안 |
|---|---|---|
| 내보내기 | 구성원 아무나 다른 구성원을 내보낼 수 있고, 동의 절차가 없다 | 팀장 역할, 내보낸 사람 알림 |
| 이름 | 팀 이름을 통제하지 않아 부적절한 이름이 보일 수 있다 | 금칙어. 지금은 관리자가 사후에 고친다 |
| 동명이인 | 초대 후보가 이름만 보여 구분이 안 된다 | 받은 사람이 거절하면 되지만, 반 · 사진을 함께 보여 줄 수 있다 |
| 초대 수 | 제한이 없어 같은 사람에게 거절 뒤 반복해서 보낼 수 있다 | 하루 횟수 제한 |
| 이력 | 처리된 신청 · 초대를 지워 분쟁 시 추적할 수 없다 | 감사 로그만 따로 남기기 |

**옮기지 않아도 되는 것(옛 구조의 흔적)**

| 이 사이트에 있는 것 | 이유 | 새 사이트 |
|---|---|---|
| 팀 · 구성원의 "활성 여부" | 옛 관리자 "멈추기" 기능의 흔적. 지금은 나가면 줄을 지운다 | 빼도 된다. 빼면 C-1은 "참여자당 구성원 줄 하나"가 된다 |
| 멈춘 자리 되살리기 | 위와 같음 | 빼도 된다 |
| 팀 메모 | 옛 관리 기능 | 빼도 된다 |
| 관리자가 숨긴 축하 카드 기록 | 숨기는 기능은 없어졌고 예전 기록만 유지 | 빼도 된다 |
| 시상 부서 | 없어진 개념 | 옮기지 않는다 |

## 10. 완료 확인 목록

옮긴 뒤 아래가 모두 맞는지 시험한다.

**만들기 · 신청**
- [ ] 승인 없이 팀을 만들면 바로 구성원이 되고, 받은 초대가 사라진다
- [ ] 이미 팀이 있거나 신청 중이면 만들기 · 신청이 막힌다
- [ ] 두 번째 팀에 신청할 수 없고, 동시에 눌러도 신청은 하나만 생긴다
- [ ] 찾기 결과에 점수가 보이지 않는다
- [ ] 수락 직전에 자격을 잃은 신청자는 합류되지 않고 신청만 지워진다

**초대**
- [ ] 후보에 팀이 있는 사람, 우리 팀에 신청 · 초대된 사람이 나오지 않는다
- [ ] 같은 팀이 같은 사람을 두 번 초대할 수 없고, 다른 팀은 초대할 수 있다
- [ ] 초대한 역할을 바꿔서 수락할 수 있다
- [ ] 수락하면 받은 초대와 내 신청이 모두 사라진다
- [ ] 거절한 뒤 다시 초대할 수 있다
- [ ] 초대한 사람이 나가도 초대가 남고, 다른 구성원이 취소할 수 있다
- [ ] 본인이 아닌 사람은 초대를 수락 · 거절할 수 없다
- [ ] "다음에 할래요"를 누르면 오늘만 숨고, 내일과 새 초대는 보인다. 다른 기기에서도 같다

**나가기 · 빈 팀**
- [ ] 나가도 개인 점수가 그대로이고 팀 합계에서만 빠진다
- [ ] 남은 사람이 있으면 신청 · 초대 · 단계 기록이 유지된다
- [ ] 마지막 사람이 나가면 팀 · 구성원 · 신청 · 초대 · 단계 기록이 모두 사라지고, 나가기 전과 뒤에 안내가 나온다
- [ ] 팀이 삭제된 뒤 그 사람이 새 팀을 만들거나 다른 팀에 신청할 수 있다
- [ ] 다른 영역으로 옮길 때 자리 · 신청 · 초대가 지워지고 옮기기가 실패하지 않는다

**분리 · 권한**
- [ ] 다른 영역의 팀 · 신청 · 초대가 보이지 않고 처리되지 않는다
- [ ] 다른 영역 팀에 든 사람은 만들기 · 신청 · 수락이 막힌다
- [ ] 구성원이 아닌 사람은 수락 · 거절 · 초대 · 내보내기 · 이름 바꾸기를 할 수 없다
- [ ] 기능 스위치를 끄면 입구와 만들기 · 찾기 · 신청 · 초대가 막힌다

**점수 · 축하(옮긴 경우)**
- [ ] 팀 점수가 구성원 시즌 점수의 합과 같다
- [ ] 단계를 넘으면 시즌 · 팀마다 한 번만 축하한다
- [ ] 활동을 취소해 합계가 줄면 그 단계 기록이 지워지고, 다시 넘으면 또 축하한다
- [ ] 나가서 합계가 줄어도 단계 기록은 지워지지 않는다
