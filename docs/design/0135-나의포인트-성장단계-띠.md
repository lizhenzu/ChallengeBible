# 0135 나의 포인트 · 성장 단계 띠 (순위 · 연속 삭제)

- 날짜: 2026-11-23 · 상태: 결정(사용자 "A로 하고 구현 해줘")
- 관련: ADR 0133(나의 도전 현황 통합 카드) · 0076(R-190 성장 단계) · 0012(D12 순위 켜기/끄기)
- 시안: `docs/design/시안/홈-포인트강조-B-성장단계-단독시안.html` (B-1 · 띠 + 눈금 4칸)

## 배경

0133 카드의 아래 줄은 `나의 포인트 · 순위 · 연속` 세 가지를 같은 크기로 늘어놓아 포인트가 눈에 띄지 않았다.
사용자(2026-11-23): "순위 삭제, 연속 0일 삭제. 나의 포인트는 상단에 조금 크게해서 강조해 보여줘. 나의 포인트가 중요."
이어 성장 몇 단계인지도 함께 보여 달라고 했다.

## 결정

1. **포인트 띠** — 카드 머리 바로 아래, 옅은 초록 바탕(`--s1`) 둥근 띠. `나의 포인트` 이름표 + 30px 굵은 숫자 + `점`.
2. **오른쪽 배지** — `🌿 성장 3단계 · 나무`(이모지 · 번호 · 이름 모두 `RuleSet.GrowthStages` 값). 그 아래 `1,300점까지 250점`.
3. **눈금 4칸(B-1)** — 단계 수만큼 칸. 지나온 단계(지금 단계 포함)는 진한 초록, 아직은 옅은 초록. 칸 아래 단계 이름 — 지나온 단계 `past`, 지금 단계 `now`(진하게).
4. **마지막 단계** — 다 자랐으면(Done) 눈금 전부 채우고 `모든 성장 단계를 넘었어요`.
5. **삭제** — 순위 · 연속은 카드에서 완전히 뺀다(계산 · 조회도 하지 않는다). `.vb-cardfoot` 을 지운다.
   순위 화면(`/{slug}/ranking`)과 `Features.Ranking` 스위치는 그대로 둔다 — 홈 카드에서만 뺀다.
6. **손님** — 개인 숫자 없이 지금처럼 `로그인하면 내 기록이 보여요`.
7. **값의 출처** — 점수는 `HomeView.SeasonPoints`, 단계는 `PointMath.GrowthOf(... Rules.GrowthStages)`. 코드에 단계 이름 · 경계 점수를 쓰지 않는다(R-190).

## 구현

- `Services/ChallengeCardService.cs` — `GrowthStep(Name, Emoji, Reached, Now)` · `GrowthView(Stage, Count, Name, Emoji, NextUntil, ToNext, Done, Steps)` 추가.
  `ChallengeCard` 에서 `Rank` · `Streak` 를 빼고 `Growth` 를 넣는다. `RankingService` 주입 제거.
- `Pages/Shared/_ChallengeCard.cshtml` — `.vb-pts` 띠 + `.steps` 눈금 + `.names` 이름.
- `landing.css` — `.vb-pts` 계열, `.vb-cardfoot` 삭제.
- 테스트: `HomeMainTests` — 포인트 띠 있음 · `vb-cardfoot` 없음 · 손님에게 포인트 없음.

## 하지 않은 것

- 성장 단계 경계 · 이름 변경 없음(규칙 R-190 그대로).
- 순위 · 연속 값을 다른 화면으로 옮기지 않는다(순위는 순위 화면, 연속은 규칙 R-83 그대로 미션 화면).
