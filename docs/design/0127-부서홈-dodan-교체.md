# 0127 부서 홈을 dodan 화면 하나로 교체

- 날짜: 2026-11-22 · 상태: 결정(사용자 "기존꺼 다 무시하고 새 디자인으로 완전히 교체 하는 것이다")
- 참고: `docs/design/시안/메인-UX-A4-네이비앱-단독시안.html` · `메뉴-깔끔-단독시안.html` · 첨부 `dodan-seonggyeong (5).html`

## 배경

2026-11-22 오전에 부서 홈 상단만 dodan 시안(네이비 `#1e3a8a` · `#0179dc`)으로 바뀌었고, 그 아래에는 예전 카드(진행 링 · 예배/주보 · 생일 · 선물 보드 · 가족팀 · 의견 접수)가 그대로 남아 두 모양이 섞여 있었다. 사용자가 첨부 화면 하나로 **완전히 교체**하기로 정했다.

## 결정

1. **일반 부서 홈 `/{slug}` = 여섯 블록만**
   머리말(☰ · 검색 · 내 계정) → 로고(`도전!!! 성경말씀` + `하루 5분, 말씀과 함께 자라요.`) → 알약 검색 → 프로그램 4칸 → 오늘의 말씀 → 나의 도전 현황.
   맨 아래에 작은 글자 링크 둘: 학부모 `자녀 미션 보기`, `의견 보내기`.
2. **홈에서 뺀 것**
   - 진행 카드 3종(미션 링 · 통독 진도 · 필사 진도)
   - 예배 안내 + 주보 버튼
   - 생일 선물 카드(팝업은 유지)
   - `누가 선물 받나요` 보드
   - 가족팀 카드 · 초대 배너(메뉴로 이동)
   - 365 기도 상세 카드(프로그램 아이콘만)
   - 개선사항 카드(작은 링크로)
   - 새 쪽지 띠(팝업은 유지)
3. **유지한 것**
   - 생일 팝업(생일 30일 전, R-346) — 카드 없이 팝업만
   - 새 쪽지 팝업(로그인 직후 한 번, ADR 0112)
   - 비로그인 둘러보기(R-336) — 개인 숫자 대신 `로그인하면 내 기록이 보여요`
   - 임시 부서(로비) 1단계 안내 · 관리자 진입(☰)
   - `©` 줄
4. **나의 도전 현황 5칸**
   `오늘 미션 n/N` · `이번 주 참여(회)` · `전체 참여자(명)` · `나의 포인트(점)` · `순위(위)`.
   참여자가 아니면 `전체 참여자 · 오늘 참여` 2칸, 비로그인은 로그인 안내 한 칸.
5. **☰ 메뉴(깔끔판)**
   흰 바탕 · `도전!!! 성경말씀` + `GROW IN THE WORD` · ✕ · 파란 선 아이콘 · 제목만(한 줄 설명 없음).
   묶음: 프로그램(4) / 바로가기(오늘의 말씀 · 나의 기록) / 섬김 · 교사 / 생일 / 함께하기(단체쪽지 · 사진첩 · **가족팀**) / 관리 / 다른 곳.
   부서 관리 · 선물 처리에는 작은 `관리` 딱지를 붙인다.
   **2026-11-21의 "프로그램을 메뉴에서 뺀다"를 되돌린다** — 첨부 이미지에 프로그램 4개가 있으므로 메뉴에도 둔다.

## 바뀌는 예전 결정

- ADR 0116 · 0117(예배 안내 · 주보를 부서 홈에) → **홈 노출 중단**. 관리 화면(`/{slug}/admin/worship`)과 주보 화면은 남지만 홈·메뉴 입구는 없다.
- ADR 0123(생일 선물 홈 카드) → **카드 제거**, 팝업만.
- ADR 0106(365 기도 홈 카드) → **상세 카드 제거**, 프로그램 아이콘만.
- ADR 0084 · R-212(가족팀 초대 배너) → **홈 배너 제거**, ☰ > 함께하기 > 가족팀.
- R-337 · R-346의 "홈에 보인다" 부분은 이 결정으로 대체된다. 규칙의 나머지(저장·알림·기한)는 그대로다.

## 결과

- `Pages/TenantHome.cshtml` 전면 교체, `TenantHome.cshtml.cs`에서 홈 전용 조회(가족팀 · 초대 · 예배 · 주보 · 선물 보드 · 365 본문) 제거. 대신 `PrayerVisible` · `MyRank` 추가.
- `Pages/Shared/_TenantDrawer.cshtml` · `DrawerUi.Line` · `site.css`의 `.tdr2` 추가.
- `home.css`에 `.hmx` 스타일 추가.
- 홈 머리말 오른쪽 아이콘은 **내 사진**(R-200 · R-201)으로 바꿨다. 사진이 없으면 사람 아이콘.
- 옛 인사 카드의 역할 칩(R-275)은 홈에서 빠졌다. `RoleChipTests`는 화면이 없어져 은퇴했다.
- 초대 배너가 없어져 `SnoozeInvites` 화면 동작도 없앴다(서비스 `FamilyJoinService.SnoozeInvitesAsync`는 남음).
- 첨부 화면에는 교회명 · 날짜 머리말이 없어 홈에서 뺐다. 필요하면 후속으로 로고 아래 작은 날짜를 넣는다.
- `HomeMainTests`를 새 구조로 다시 씀(10개).

## 남은 일

- 예배/주보 · 선물 보드는 입구가 없어져 사실상 숨는다. 다시 쓰려면 ☰ 메뉴에 항목을 넣어야 한다.
- 옛 홈 카드 CSS(`.hj-card` · `.dz-*` 등)는 다른 화면이 일부 쓰므로 지우지 않았다.
- 랜딩(`/`)도 같은 테마(A-4)로 맞추는 일은 별도 결정.
