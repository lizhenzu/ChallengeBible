# 0036. 성경 본문은 기존 DB 에서 한 번 적재한다

- 상태: 확정 (2026-10-22, 사용자 확인)
- 관련: 0013(D13), 0019(D19), R-110 · R-111, 02 용어집 "성경 본문"(현행 `eBible`, `eBibleEN`, `eBibleHD`)

## 맥락
본문 읽기(R-110)와 번역 대조(R-111)에는 성경 본문 참조 데이터가 필요하다.
사용자가 보유한 기존 DB 에 **개역개정 · 현대인의성경 · NIV** 본문이 이미 들어 있다.

## 결정
1. 세 번역본을 기존 DB 에서 새 DB 의 `BibleTranslation` · `BibleVerse` 로 **한 번 적재**한다.
   | Code | 이름 | 순서 |
   |---|---|---|
   | `KRV` | 개역개정 | 1 (기본) |
   | `KLB` | 현대인의성경 | 2 |
   | `NIV` | NIV | 3 |
2. 이것은 업무 데이터 이전이 아니라 **플랫폼 참조 데이터 적재**다. D13(기존 데이터 이전 없음)의 예외가 아니다.
3. 적재는 플랫폼 관리 기능 "성경 참조 데이터"(`/platform/bible`)의 1회성 도구로 한다.
   기존 DB 접속 정보는 실행할 때만 넣고 Git 에 두지 않는다(X-21).
4. 책 번호는 새 DB 의 `BibleBook` 1 ~ 66 으로 맞춘다. 기존 표의 책 표기가 다르면 변환 표를 도구 안에 둔다.

## 검증
- 번역본마다 **책별 장 수 · 절 수**를 세어 서로 비교한다. 다르면(번역별 절 구분 차이) 목록으로 보고하고, 빠진 절은 비워 둔다.
- 오늘의 말씀 범위에 해당 번역의 절이 없으면 화면에서 그 절을 건너뛰고 표시한다.

## 남은 확인
- 기존 DB 의 표 이름 · 열 구조(현행 `eBible` · `eBibleHD` · `eBibleEN` 로 추정)는 적재 도구를 만들 때 확인한다.
- 개역개정 · 현대인의성경 · NIV 는 저작권이 있는 번역본이다. 공개 서비스에 쓰기 전에 사용 허락 범위를 확인한다
  (보유한 것과 서비스에 쓸 권리는 별개).
