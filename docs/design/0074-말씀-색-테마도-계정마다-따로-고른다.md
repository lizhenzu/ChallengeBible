# 0074. 성경말씀 미션 색 테마도 사용자가 고르고 계정에 따로 남긴다

- 상태: **되돌림**(2026-11-02, 사용자: "도전성경말씀에 색 테마 없었던 버전으로 rollback"). 화면 · API · CSS 는 지웠고, DB 열 `Account.MissionTheme` 과 마이그레이션은 남겨 둔다(쓰지 않음, DB 변경 없이 게시 가능).
- 처음 상태: 확정 · 구현 끝(2026-11-02, 사용자: "도전 성경말씀에 동적 테마", 저장은 "따로", 고르는 곳은 B안 "미션 홈 맨 아래 색 테마 줄")
- 관련: 0073(통독 색 테마), 시안 그림 `mt.png`(테마 4가지 + 고르는 곳 3안)

## 결정
1. 도전!!!성경말씀 화면(부서 홈 · 말씀 · 기도 · 퀴즈 · 암송 등, 통독 · 관리 화면 밖)에 색 테마 4가지: **기본(하늘)** · **종이** · **숲** · **모래**. 색 묶음은 통독(0073)과 같다.
2. 고르는 곳은 **미션 네 화면(말씀 · 기도 · 퀴즈 · 암송) 맨 아래 "색 테마" 줄**(동그라미 4개, `_MissionThemePick`). 누르면 그 자리에서 바로 바뀐다.
   (처음엔 부서 홈 맨 아래였으나 통독 테마와 헷갈려서 2026-11-02 사용자 결정으로 미션 화면 안으로 옮김, 확정 시안 B안 `mt4.png`)
3. 고른 값은 **계정**(`Account.MissionTheme`, null = 기본)에 남기고, **통독 테마와 따로**다. 저장에 실패하면 원래대로 되돌린다.
4. 기본을 고르면 아무것도 붙이지 않아 부서 대표 색(0033)이 그대로 쓰인다. 다른 테마를 고르면 대표 색보다 테마 색이 앞선다.
5. 부서 홈은 기기가 어두운 모드면 테마의 어두운 색을 쓴다. 미션 네 화면은 원래 늘 밝은 화면이라 밝은 색만 쓴다.

## 결과
- 마이그레이션 `MissionTheme`(Account 에 varchar(16) NULL 열). **실제 DB: `tools/sql/migrate-mission-theme.sql` 을 게시 전에 실행.**
- API `PUT /api/me/mission/theme { theme }`("default" · paper · forest · sand).
- 화면: `_Layout` 이 `<html data-mtheme>` 를 붙이고, `site.css` 끝의 0074 블록이 색을 바꾼다. 옛 DailyMission4 모양에 박힌 회색 글자 등은 그대로다.
