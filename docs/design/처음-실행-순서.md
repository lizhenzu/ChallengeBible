# 처음 실행 순서 (SmarterASP 새 DB · 1차)

비밀 값(접속 문자열 · 비밀번호)은 이 문서 · Git · 대화창에 쓰지 않는다.

## 1. 접속 문자열 넣기 (집 PC, 한 번)
SmarterASP 제어판 → Databases → MS SQL → `db_a64b16_challengebible` → **Connection String** 에서 값을 보고:

```powershell
cd C:\WorkSpace\ChallengeBible
dotnet user-secrets set "ConnectionStrings:App" "Data Source=<서버>;Initial Catalog=<DB>;User Id=<사용자>;Password=<비밀번호>;Encrypt=True;TrustServerCertificate=True" --project src/ChallengeBible.Web
```

## 2. 표 만들기 (집 PC)
앱이 켜질 때 자동으로 만들지 않는다(물리 설계 5절). 마이그레이션을 직접 적용한다.

```powershell
cd C:\WorkSpace\ChallengeBible
dotnet tool restore
dotnet ef database update --project src/ChallengeBible.Infrastructure --startup-project src/ChallengeBible.Infrastructure
```

접속 문자열은 1단계에서 넣은 user-secrets 에서 읽는다(명령줄에 쓰지 않음).

SQL Studio 웹 화면은 `CREATE FUNCTION` 같은 여러 묶음 실행을 막을 수 있어서, 표 만들기는 이 방법으로 한다.

## 3. 첫 플랫폼 관리자 정하기 (휴대폰 가능)
1. 사이트에서 **회원가입**으로 운영자 계정을 만든다(예: 아이디 `operator`).
2. SmarterASP SQL Studio 에서 아래 한 줄을 실행한다(아이디만 바꿔서).

```sql
UPDATE app.Account SET IsPlatformAdmin = 1 WHERE LoginId = 'operator';
```

3. 사이트에서 **로그아웃 → 다시 로그인**하면 첫 화면이 `/platform/tenants`(부서 관리)로 간다.

플랫폼 관리자 표시는 코드 · 설정 파일에 넣지 않는다. 다음 플랫폼 관리자도 같은 방법으로 정한다.

## 4. 첫 부서 만들기 (휴대폰 가능)
1. 선생님(부서 관리자)이 먼저 회원가입한다.
2. 부서 관리에서 **+ 새 부서 만들기** → 이름 · 주소 · 프로그램 · 첫 부서 관리자 아이디.
3. 생긴 **참여 코드**를 선생님께 알려 준다.

## 5. 아이 · 부모 참여
가입 → `/join` 에서 참여 코드 → 선생님이 `/{주소}/admin/members` 에서 승인.
