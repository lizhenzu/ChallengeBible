# 0131 부서 홈 검색 상자 — 입력 + 파란 검색 버튼

- 날짜: 2026-11-22 · 상태: 결정(사용자 "이와 똑같이")
- 관련: ADR 0130(머리말 편지) · 0127(부서 홈)

## 배경

부서 홈의 검색은 글자만 있는 링크 알약이었고, 오른쪽에 돋보기 아이콘이 있었다. 사용자가 첨부 이미지처럼 **왼쪽은 입력 칸, 오른쪽 끝은 파란 `검색` 버튼**인 모양을 요청했다.

## 결정

1. `form method="get"` → `/{slug}/reading/search`, 입력 이름 `q`.
2. 버튼 글자는 `검색`. 엔터와 버튼 모두 동작한다. 자바스크립트 없음.
3. 모양: 높이 50px, 연한 회색 바탕(`#F6F7F9`), 1px 테두리(`#E3E6EA`), 모서리 12px.
   오른쪽 버튼은 `#5B8DEF` 바탕 · 흰 글자 15px/800, 오른쪽 모서리만 둥글게(부모 `overflow:hidden`).
4. `ReadingEnabled`인 부서에만 보인다(통독을 끄면 검색도 없다).
5. 머리말 돋보기(0130)는 그대로 뺀 상태 — 검색 입구는 이 상자 하나다.
6. 입력 글자 크기는 16px 미만이면 iOS가 확대하므로, 모바일에서 확대가 싫으면 16px로 올린다(후속 확인).

## 영향

- `Pages/TenantHome.cshtml`의 `hmx-search`가 링크에서 폼으로 바뀐다.
- `home.css`의 `.hmx-search` 스타일 교체.
- `HomeMainTests`가 폼·`name="q"`·`검색` 버튼을 확인한다.
