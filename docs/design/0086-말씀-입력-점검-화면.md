# 0086. 말씀 입력 점검: 달력에서 날마다 빠진 항목을 본다

- 상태: **확정 · 구현** (2026-11-07, 사용자, R-216)
- 확정 시안: `시안/word-check.html` (`word-check-1.png` · `word-check-2.png`)
- 주소: `/platform/content/word/check?month=yyyy-MM&date=yyyy-MM-dd`, 플랫폼 관리자만. 공용 콘텐츠의 말씀 화면 "입력 점검"에서 들어간다.

## 맥락
공용 콘텐츠 화면과 부서 콘텐츠 달력은 말씀이 있는지 없는지와 공개 상태만 보여 준다. 말씀 안의 항목 가운데 무엇이 빠졌는지, 영상 구간이 들어갔는지는 어디서도 볼 수 없었다.

## 결정(사용자)
1. 한 달 달력의 칸마다 점 4개(성경 범위 · 제목 · 오늘 이야기 · 영상 구간)로 입력 여부를 보여 준다.
2. 영상 구간은 **말씀의 장 범위 안 구간에 시작 또는 끝 시점이 있을 때** 입력된 것으로 본다. 주소 유무는 보지 않는다. 시점 없이 기본 영상 전체를 재생하는 날은 "없음"으로 남는다.

## 구현 때 정한 것
- **받은 프롬프트와 다르게 한 곳**: 표 구조가 달라 키워드 → 제목, 줄거리 → 오늘 이야기, 요약 → 해설로 옮겼다. 같은 날짜는 개정 때문에 Id 가 가장 작은 줄이 아니라 `IsCurrent` 인 줄을 읽는다. 영상 칸은 번호(5칸)가 아니라 구간의 장(`Chapter`)으로 맞추므로 5칸 제한이 없다.
- **더한 것**: "말씀 없음" · "초안" 칩을 더했다. 완성은 네 가지가 입력되고 **공개된** 날만 센다. 초안은 아이들에게 보이지 않기 때문이다.
- **뺀 것**: "영상 구간 편집" 버튼(입력 화면이 없고 API 로만 넣는다, R-127), "보기" 버튼(플랫폼 관리자용 보기 화면이 없다). 버튼은 "말씀 수정" · "말씀 입력하기" 하나다.
- **시간대**: "오늘"은 플랫폼 시간대(`PlatformHomeService.PlatformTimeZone`, Asia/Seoul). 공용 콘텐츠라 특정 부서 시간대가 없다.
- **자료 넘기기**: 서버는 한 달치를 JSON 으로 주고 달력 · 칩 · 그날 칸은 `word-check.js` 가 그린다. 기본 직렬화라 한글과 태그 글자가 `\uXXXX` 로 들어가고, 입력한 글은 `esc` 를 거쳐 화면에 넣는다.
- 판정은 순수 함수 `WordCheck.Day` 하나다.

## 결과
- **실DB:** 데이터베이스 변경 없음(읽기만). 게시만 하면 된다.
- 테스트: `WordCheckTests`(판정 경계값 · 한 달 조회 · 권한 · 실제 페이지 + 스크립트 + CSS 를 Edge headless 에서). Edge 가 없는 환경에서는 화면 시험만 건너뛴다.
