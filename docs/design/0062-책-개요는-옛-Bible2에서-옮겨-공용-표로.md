# 0062. 책 개요는 옛 Bible2 의 간략본 · 상세본을 공용 표로 옮겨 본문 위 카드로 보인다

- 상태: 확정(2026-10-25, 사용자 "진행" · 시안 통독-본문읽기-책개요 "확정")
- 관련: R-116(책 소개를 본문 위에), 0036(성경 본문 적재), 0056(해설 카드는 기존 표를 읽기만), R-166(듣기 · 해설 영상)

## 맥락
R-116 의 책 소개 글이 우리 DB 에 없다(`app.BibleBook.Intro` 66권 모두 빈칸).
옛 Bible2(잠실키즈) 성경 읽기 화면에는 책 개요 상자가 있고, 옛 DB 의 표 두 개에서 읽는다.
- `dbo.BibleBasicInfo`(간략본): 저자 · 기록 시기 · 개요 · 기록 목적 · 영상 주소 2개
- `dbo.BibleBookOverview_Detail`(상세본): 저자 · 저자 설명 · 기록 연대(부터 · 까지 · 다른 설) · 장소 · 대상 · 시대 · 역사 배경 · 핵심어 · 내용 요약 · 영상 주소 2개
옛 DB 는 우리 접속 계정으로 볼 수 없다(같은 서버에 우리 DB 만 보임).

## 결정
1. 새 공용 표 **`app.BibleBookOverview`**(책마다 한 줄, PK = BookId, FK → BibleBook). 간략본 · 상세본 · 영상 주소 2개를 한 줄에 둔다. 성경 본문처럼 플랫폼 참조 데이터라 TenantId · RLS 가 없다(물리 설계 3-2: 플랫폼 표).
2. 옮기기는 기도문 때(0053)와 같은 방식: ① 옛 DB 에서 `tools/sql/bookoverview-1-export-old.sql`(읽기만, INSERT 문을 만들어 줌) ② 새 DB 에서 `migrate-bookoverview.sql`(표) → `bookoverview-2-import-new.sql`(붙여 넣고 실행).
   책은 이름으로 맞추고(띄어쓰기 무시), 하나라도 안 맞으면 아무것도 넣지 않고 멈춘다. 다시 실행해도 같은 결과(MERGE). 글 안 줄바꿈은 NCHAR(10) 으로 담아 복사 때 사라지지 않게.
3. 영상 주소는 상세본 것을 먼저, 없으면 간략본 것을 쓴다.
4. 예전 열 `app.BibleBook.Intro` 는 쓰지 않는다(지우지 않음).
5. 화면(시안 확정 뒤): 통독 본문 · 말씀 성경 읽기 모두 본문 위(읽기 설정 아래)에 "○○ 개요" 카드. 그 책 1장은 펼침, 다른 장은 접힘(한 줄 개요). 간략본 / 상세본 탭, 영상 주소가 있으면 "관련 영상" 버튼. 개요가 없는 책은 카드를 숨긴다.

## 결과
- 마이그레이션 `BibleBookOverview`(표 하나). 실DB 순서: 표 SQL → 옮기기 SQL → 게시.
- 실DB 에서 되돌림 트랜잭션으로 표 만들기 + 옮기기를 미리 실행해 봄(한 권 예시, 줄바꿈 · 띄어쓰기 다른 이름 맞춤 확인, 흔적 0).
- 관리 화면(개요 고치기)은 1차에 두지 않는다. 고칠 일이 생기면 SQL 로 하거나 따로 의논한다.
