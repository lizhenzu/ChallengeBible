# 0040. 성경통독 규칙 — 자유 읽기, 장 체크, 회차, 진도율만

- 상태: 확정 (2026-10-22, 사용자와 합의)
- 보완 대상: 0025(D25), 0029(성경 읽음은 계정에)
- 관련: 0039, 03 문서 R-150 ~ R-159

## 결정 (사용자 답변)
| 질문 | 답 |
|---|---|
| 읽는 방식 | **자유롭게** — 정해진 일정표 없이 각자 읽고 싶은 만큼 |
| 점수 · 순위 | **없음, 진도율만** |
| 표시 단위 | **장** (성경 전체 1,189장) |
| 다시 읽기 | **회차별로 기록** (1독, 2독, …) |

## 규칙
1. 통독 기록은 **계정**에 붙는다(0029 와 같은 원칙). 진급 · 영역을 옮겨도 이어진다.
2. 장 읽음은 켜기 `PUT` / 끄기 `DELETE` 로 멱등이다(X-17).
3. 장을 읽음으로 표시하면 그 장의 **모든 절도 성경 읽음 표시**(0029)에 기록한다 — 말씀 본문 화면과 이어진다.
   반대 방향(절을 다 표시하면 장 자동 체크)과 해제 연동은 하지 않는다.
4. **회차**: 계정마다 진행 중 회차는 하나다.
   - 1,189장을 모두 읽으면 그 회차는 **완료**(완료일 기록)되고 다음 회차가 자동으로 시작된다.
   - 본인이 원하면 다 읽지 않아도 **새 회차를 시작**할 수 있다. 이전 회차는 "미완료"로 닫히고 기록은 남는다.
5. 보여 주는 값
   - 진도율 = 현재 회차에서 읽은 장 ÷ 1,189 (소수 첫째 자리)
   - 완독 횟수 = 완료된 회차 수
   - 오늘 읽은 장 수, 연속 읽은 날(장을 하나라도 읽은 날이 끊기지 않은 날 수)
   - "오늘"은 접속한 영역의 시간대(R-01)
6. **점수 · 순위 없음.** 성경말씀 점수와도 무관하다.
7. 영역 관리자 · 교사는 **자기 영역 소속원**의 진도율 · 완독 횟수 · 마지막 읽은 날을 본다(요약만, 장 목록은 보지 않음).
   0029 의 "영역 통계로 쓰지 않음"은 성경말씀의 절 읽음 표시에 대한 것이고, 통독 진도는 개인 진도 그대로 보여 준다.
8. 관리자 강제 초기화(0029)는 통독의 모든 회차도 함께 지운다.

## 결과
- 표: `ReadingRound`(계정 · 회차 번호 · 시작 · 완료 · 닫힘), `ChapterRead`(계정 · 회차 · 책 · 장 · 읽은 시각), `BibleBook.ChapterCount`.
- 장 읽음 기록에는 읽은 시각(UTC)을 남긴다 — 오늘 읽은 장 수 · 연속 읽은 날의 근거.
- 저작권 확인(0036)은 통독에서 본문을 보여 줄 때도 같다.
