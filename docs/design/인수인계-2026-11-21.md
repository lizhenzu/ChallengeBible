## 사용자(관리자) 규칙 — 이번 방에서 굳어진 것
- **한국어, 짧게.** 질문은 **한 번에 하나, 번호 + 추천**. 길게 설명하지 않는다.
- **화면은 시안 먼저**(실제 화면을 찍은 캡처 또는 HTML 시안 → PNG) 보여 주고, 사용자가 **"진행"** 해야 구현한다.
- **main 합치기 · 게시는 사용자가 "1" 이라고 할 때만.** 작업은 기능 브랜치 `claude/...` 에서. 합친 뒤 `publish.yml` 워크플로를 `main` 으로 실행(`mcp__github__actions_run_trigger`).
- 사용자에게 할 일(게시 확인 · SQL 실행 · 확인)을 드렸으면 **"게시완료"/"정상" 답을 받을 때까지 매번 다시 묻는다.**
- **모델 추천을 작업마다 알린다**(토큰 절약): 확인 · 게시 · 작은 수정 = **Sonnet**, 새 화면 · 여러 파일 · 삭제/이관 같은 위험한 작업 = **Opus**. 사용자가 `/model` 로 바꾼다. 커밋 꼬리말의 모델 이름은 그때 시스템이 알려 주는 것을 쓴다.
- **개인정보 · 비밀을 Git 에 넣지 않는다.** 시안 · 테스트 · 문서에는 가짜 이름(김가나 등)과 가짜 전화(010-0000-1111)만. (이번 방에서 캡처의 실제 이름을 시안에 넣으려다 시스템이 막았다.)
- **SuperAdmin · 부서 관리자(Identity Admin) 계정은 지우지도 바꾸지도 않는다**(R-315). 역할 "어드민"(T1030)은 화면에서 고르거나 바꿀 수 없다.
- 화면 폭 760px 기본(휴대폰은 그대로). 입력 칸 글자 16px 이상(아이폰 확대 방지, 이미 전역 적용).
- 선택 표시(포커스)는 UI-1: 진한 3px 선 금지, 공통 `--ring` 값만.

## 알아 둘 구조(이번 방에서 확인한 것)
- 역할 = `DeptRoleUserAssoc.RoleCode`(계정, 부서별 한 줄) 또는 `Person.RoleCode`(계정 없는 명부 줄). 코드표 `UserRole.Codes`(T1001 학생 · T1002/T1003 교사 · T1004 지도 · T1005 부장 · T1006 부감 · T1008 서기 · T1009 회계 · T1010~T1019 봉사 · T1020 새친구 · T1030 어드민 · T1040 교장 · T1099 기타). 부서 관리자는 사람마다 지정하지 않고 **부서 관리자 규칙**(플랫폼) 역할 · 업무로 정해진다 → 역할을 바꾸면 `DeptAdminRuleService.SyncAsync` 가 다시 맞춘다.
- 반 배정 `ClassMember`(IsTeacher). 담임은 교사 · 임원이 맡을 수 있다(R-232), 한 사람은 한 반만.
- RLS: 일반 요청은 부서(TenantId)만, 시스템 작업은 `ISystemDb`. 사이트 SQL 콘솔은 보호된 표를 읽으면 **0행**이고, `EXEC sp_set_session_context N'PlatformScope', 1;` 를 맨 위에 두면 읽힌다(SSMS · 콘솔은 `COMMIT/ROLLBACK/BEGIN TRAN/GO` 거부).
- 운영 DB 작업은 SQL 적용 → 게시 순서. 이번 방은 새 표 없이 코드만 게시했다.

## 개발 환경 요령
> **주의: 아래는 이전 클라우드 방(리눅스 컨테이너) 기준이다.** 로컬 PC 에서 이어받으면 .NET SDK 버전 · SQL Server 위치 · 포트 · git/gh 도구가 다르다. 먼저 `dotnet --version`, `git --version`, SQL Server 접속을 확인하고, 안 맞는 곳은 `진행-상황.md`(개발 · 캡처 방법)와 그 PC 의 실제 상태를 기준으로 한다. 게시는 GitHub Actions 의 `publish.yml` 을 `main` 으로 실행하는 것이고(클라우드 방에서는 GitHub 도구로 눌렀다), 도구가 없으면 사용자에게 Actions 화면에서 실행하도록 안내한다.
- (클라우드 방) `dotnet` 은 저장소의 `global.json`(옛 SDK 고정) 때문에 안 될 수 있어 **빌드 · 시험 때만 `global.json` 을 잠깐 옮겼다가 되돌린다**: `mv global.json /tmp/g.bak; dotnet test; mv /tmp/g.bak global.json`.
- 전체 테스트 약 2분 30초(951개). 시험은 `WebApplicationFactory` + InMemoryDb, 오늘은 `FixedTime.SeoulMorning()` = 2027-01-05.
- (클라우드 방) 로컬 화면 확인: docker 의 SQL Server 컨테이너(`cbsql`) + `dotnet bin/Debug/net9.0/ChallengeBible.Web.dll`(포트 5080) + Playwright(`require('playwright')`). 가짜 데이터 계정(비밀번호 1234)으로 로그인. 플랫폼 관리자는 시험 계정 이용.
- 시안: `docs/design/시안/src/*.html` → Playwright 로 PNG(`docs/design/시안/`).
- 새 CSS/JS 는 **접두어를 따로**(st- · pl- · pd- · rb- 등) 써서 `site.css` 와 겹치지 않게.

## 남은 일(백로그 — 사용자가 물으면 이야기, 먼저 꺼내지 않기)
- **온가족 404**: 사용자가 "나중에, 내가 물어보면" 이라고 했다(먼저 말하지 않는다).
- 담임 생일 링크 이동 위치, 교육 슬라이드(새 이름 · 메뉴 반영 전), 메뉴 지도.
- "부서 · 반 이동" 화면 머리말 제목이 휴대폰에서 길면 잘리는 것(고칠지 답 못 받음).
- 소속 관리 상세(`/{slug}/admin/members/{번호}` 계정 자세히)에도 "역할 바꾸기"가 남아 있어 새 화면과 겹친다 — 사용자는 "둘 다 두기"를 추천받았고 아직 확정 답은 없다.
- 운영 사이트 확인 대기: 없음("모두 정상").
