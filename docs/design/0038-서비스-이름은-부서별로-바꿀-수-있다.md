# 0038. 서비스 이름은 부서(영역)별로 바꿀 수 있다

- 상태: 확정 (2026-10-22, 사용자 요청)
- 보완 대상: 0037
- 관련: 0008(주소로 영역 식별), 0033(영역별 대표 색), 0034(PWA)

## 맥락
0037 은 서비스 이름을 플랫폼에 하나("도전!!!성경말씀")로 두었다.
사용자는 이것을 **기본값**으로 두고, 부서마다 자기 이름(예: "유년부 말씀 챌린지")으로 바꿀 수 있기를 원했다.

## 결정
1. **기본 이름**은 플랫폼 문구 리소스 `AppName` = "도전!!!성경말씀", 짧은 이름 `AppShortName` = "도전성경"(0037).
2. 영역은 **앱 이름**과 **짧은 이름**을 따로 정할 수 있다. 비워 두면 기본 이름을 쓴다.
   - 앱 이름: 1 ~ 30자
   - 짧은 이름: 1 ~ 12자 (홈 화면 아이콘 아래 표시용). 비워 두면 기본 짧은 이름
3. 바꾸는 사람: 영역 관리자(자기 영역), 플랫폼 관리자(영역을 만들 때 · 언제든).
4. 쓰이는 곳
   | 위치 | 이름 |
   |---|---|
   | `/{slug}/…` 영역 화면(상단 · 로그인 안내 · 축하 팝업 등) | 영역 이름, 없으면 기본 |
   | `/{slug}/manifest.webmanifest` (그 영역 주소에서 설치한 앱) | 영역 이름 · 짧은 이름 |
   | `/`, `/account/…`, `/platform/…` (영역 밖 화면) | 기본 이름 |
5. PWA 매니페스트는 **영역마다** 만든다: `start_url` · `scope` = `/{slug}/`, `theme_color` = 영역 대표 색(0033), `name` · `short_name` = 위 규칙.

## 결과
- Tenant 에 `AppName`(nvarchar(30) NULL), `AppShortName`(nvarchar(12) NULL) 열을 더한다.
- 영역 이름 변경은 감사 로그와 규칙 변경 이력처럼 남긴다(누가, 언제, 이전 값 → 새 값).
- 이미 홈 화면에 설치한 앱의 이름은 휴대폰이 매니페스트를 다시 읽을 때 바뀐다(기기마다 시점이 다르다). 화면 안의 이름은 바로 바뀐다.
- 화면 템플릿은 이름을 직접 쓰지 않고 "현재 이름"(영역 값 → 기본값)을 주는 서비스 하나에서 읽는다.
