# 0073. 통독 색 테마는 사용자가 고르고 계정에 남긴다(동적 테마)

- 상태: **확정 · 구현 끝**(2026-10-31, 사용자: 처음 시안 3가지를 모두 넣어 실시간으로 고르게, 저장은 "계정")
- 관련: 0071(통독 옛 Bible2 배치), 시안 `통독-자연색테마-단독시안.html`(처음 3안)

## 결정
1. 통독 화면 전체(대시보드 · 목록 · 검색 · 북마크 · 참여자 · 회차 · 본문)에 색 테마 4가지: **기본(파랑)** · **한지 · 나무** · **숲 · 세이지** · **모래 · 하늘**.
2. 왼쪽 목차(좁은 화면은 ☰ 서랍) "색 테마"에서 고르면 **그 자리에서 바로** 바뀐다(다시 불러오지 않음).
3. 고른 테마는 **계정**(`Account.ReadingTheme`, null = 기본)에 남긴다 — 어느 기기에서나 같다. 저장에 실패하면 원래대로 되돌린다.
4. 기기가 어두운 모드면 각 테마의 어두운 색을 쓴다.
5. 성경말씀 미션 · 부서 홈 등 통독 밖 화면은 바뀌지 않는다.

## 결과
- 마이그레이션 `ReadingTheme`(Account 에 varchar(16) NULL 열). **실제 DB: `tools/sql/migrate-reading-theme.sql` 을 게시 전에 실행.**
- API `PUT /api/me/reading/theme { theme }`("default" · paper · forest · sand).
