# 0133 나의 도전 현황 통합 카드 (통독 · 필사 · 기도365 진행)

- 날짜: 2026-11-23 · 상태: 결정(사용자 "구현해줘")
- 관련: ADR 0127(홈 교체) · 0128(첫 화면) · 0106(365 기도 상세 카드 제거) · 0132(가족팀 카드)
- 시안: `docs/design/시안/홈-나의도전-통합카드-단독시안.html` (A안 · 초록 완료/대기중 글자형)

## 배경 — 왜 사라졌나

0127에서 홈을 dodan 시안 한 장으로 바꾸면서 **진행 카드 3종(미션 링 · 통독 진도 · 필사 진도)** 을 뺐고,
0106에서 365 기도 상세 카드를 뺐다. 그 뒤 현황 카드에는 `오늘 미션 / 이번 주 참여 / 전체 참여자 / 포인트 / 순위` 만 남아
"나의 성경통독률 · 필사률 · 365 기도" 를 홈에서 볼 수 없게 됐다.

## 결정

1. **한 카드** — `나의 도전 현황` 카드 하나에 오늘 미션 칸 + 프로그램 진행 줄 + 아래 줄을 모은다.
2. **오늘 미션** — 체크 표시 없이 **바탕색 + 글자색**. 완료 = 초록 바탕(`--p1`) · 흰 글자 + "완료",
   대기중 = 옅은 초록 바탕(`--s1`) · 초록 글자 + "대기중", 그날 콘텐츠 없음 = 테두리만 + "—".
3. **진행 줄** — `성경통독 %(장) · 성경필사 %(절) · 기도365 %(일)`. 프로그램 색(파랑 · 주황 · 분홍)은 점과 막대에만, 퍼센트는 검정.
4. **켜지 않은 프로그램은 줄에서 뺀다** — `ReadingEnabled` · `CopyEnabled` · `Prayer365Service.CanSee()`(학생 · 새친구 없음, R-316).
5. **시작 전** — 통독 · 필사를 시작하지 않았으면 막대 대신 `아직 시작 전 · 시작하기 ›` 한 줄.
6. **아래 줄** — 나의 포인트 · 순위 · 연속. 순위는 `Features.Ranking` 이 켜지고 내 점수가 있을 때만.
7. **자리** — 부서 홈(`/{slug}`)의 오늘의 말씀 옆, 첫 화면(`/`)은 승인된 부서가 **꼭 하나**일 때 같은 카드(아니면 기존 함께하는 현황).
8. **손님** — 로그인 안 한 사람에게는 개인 숫자 대신 `로그인하면 내 기록이 보여요`.

## 구현

- `Services/ChallengeCardService.cs` — `ChallengeChip` / `ChallengeRow` / `ChallengeCard` 레코드 + 조립.
  `HomeView`(미션 · 점수 · 연속 · 부서 숫자)는 다시 세지 않고, 없던 **필사 · 기도365 · 순위** 만 여기서 더한다.
- `Pages/ChallengeCardVm.cs` — 카드 + 부서 slug + 손님 여부 → `더보기` · 줄별 링크.
- `Pages/Shared/_ChallengeCard.cshtml` — 두 화면이 같이 쓰는 부품.
- `TenantHomeModel` · `IndexModel` — `ChallengeCardService` 주입, `Card` 계산(`MyRank` 는 카드로 흡수).
- `landing.css` — `.vb-chips` · `.vb-chip.ok/.wait/.none` · `.vb-chipsum` · `.vb-prog` · `.vb-deptnum` · `.vb-cardfoot` · `.c-reading/.c-copy/.c-prayer`.
- 테스트: `HomeMainTests`(진행 줄 · 시작 전 · 학생에게 365 줄 없음 · 교사에게 365 줄 있음), `RosterTests` · `LobbyTests` · `LandingTests` 그대로 통과.

## 하지 않은 것

- 홈에 새 카드를 더 늘리지 않는다 — 진행은 이 카드 하나로 끝.
- 필사 "오늘 몇 절" 은 카드에 넣지 않는다(필사 화면에서 확인). 줄 아래 숫자는 누적 장/절/일만.
