# 0075. 부서 홈 윗부분을 "오늘" 화면(A안)으로 바꾼다

- 상태: **0076 으로 대체**(홈 배치 · 아래 탭은 0076, 완료 창 "다음 미션" 버튼만 남음). 처음: 확정(2026-11-02, 사용자: UX 분석 → 추천 "오늘 홈" → 시안 A "진행 링 + 이어서 하기" → 넣는 곳 1안 "부서 홈 윗부분")
- 관련: 0044(부서 홈 메인), 0069(미션 홈 옛 모양), 시안 그림 `th.png`(A · B · C)

## 배경
초 · 중 · 고 학생이 앱을 열면 "오늘 무엇을 해야 하는지"가 바로 보이지 않고, 미션 하나를 끝내면 다음 미션으로 가는 길이 약했다.

## 결정
1. 로그인 후 오는 부서 홈(`/{slug}`)은 그대로 두고, **윗부분의 성경말씀 카드를 "오늘" 블록으로 바꾼다**:
   인사 + 🔥 연속일 → 큰 진행 링(완료 / 오늘 미션 수) → 큰 **"이어서 하기 · ○○"** 버튼 → 미션 4줄(완료 체크 · 상태, 줄을 누르면 그 미션).
2. 통독 카드 · 가족팀 · 이번 주 기록 · 우리 부서 칸은 그 아래에 그대로 둔다.
3. 부서 홈 맨 아래에 **탭 4개**(오늘 · 달력 · 내 점수 · 통독)를 붙인다. 성경말씀을 끈 부서는 달력 · 내 점수, 통독을 끈 부서는 통독 탭을 숨긴다. 미션 화면은 원래 있는 아래 미션 메뉴를 그대로 쓴다.
4. 미션 완료 안내 창에 **"다음: ○○ →"** 버튼을 더해 바로 다음 미션으로 간다. 오늘 미션을 다 했으면 "오늘 미션 끝! 홈으로" 버튼. 축하 창이 이어 뜰 때는 축하를 먼저 보인다.
5. 점수 값은 지금처럼 RuleSet 에서 읽고, 화면 글자만 바꾼다(업무 규칙 변화 없음).
