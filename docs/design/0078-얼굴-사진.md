# 0078. 얼굴 사진

- 상태: **확정**(2026-11-03, 사용자: 저장 2안 "사이트 폴더에 파일", 보는 사람 2안 "같은 부서 모두", 올리는 사람 2안 "본인 + 부서 관리자", 올리는 곳 3안 "홈 동그라미 + 내 계정", 시안 `ph.png`)
- 관련: 0076(부서 홈 인사 카드 동그라미), 0067(가장), R-200 ~ R-203

## 결정
1. 계정마다 사진 한 장. 기존 `app.Account.PhotoPath`(nvarchar(260))에 파일 이름(`{계정}-{시각}.jpg`)을 둔다 — DB 바꿈 없음.
2. 파일은 `wwwroot/profile`(2026-11-03 사용자: "일단 여기, 나중에 개선", 설정 `Photos:Dir` 로 바꿀 수 있음).
   `/profile/…` 주소는 앞단에서 404 로 막아(개발 환경의 정적 파일은 목록 밖 파일도 내주므로) 권한을 보는 주소로만 나간다. `profile` 은 부서 주소로 쓰지 못하게 예약.
   개발 중 올린 사진은 csproj 에서 게시 · 정적 목록에서 뺀다. 게시(Web Deploy)는 `SkipExtraFilesOnServer=true` 라 서버에만 있는 사진을 지우지 않는다 —
   "대상에서 추가 파일 제거"를 켜면 지워지므로 켜지 않는다. 백업은 DB 와 따로 이 폴더를 챙긴다.
   **나중 개선**: 사이트 루트 밖 폴더(`Photos:Dir`) 또는 DB 저장으로 옮긴다.
3. 보기: `/{slug}/photo/{계정}` — 이 부서에 승인된 사람이, 이 부서에 승인된 소속이 있는 계정의 사진만(R-201). 임시 부서는 본인만. 본인 것은 `/account/photo?handler=img`.
4. 올리기 · 바꾸기 · 지우기: 본인은 `/account/photo`(홈 동그라미 📷 · 내 계정 "내 사진"에서 들어옴), 부서 관리자는 관리 › 회원 상세. 관리자가 한 일은 감사 기록(`Photo`).
5. 크기: 사진을 고르면 **자르기 화면**(확정 시안 `crop.png`, 2026-11-03)이 열린다 — 끌어서 옮기기 · 두 손가락 · 막대 · 휠로 키우기(최대 4배) · 90° 돌리기.
   "이대로 올리기"를 누르면 동그라미 안만 320px JPEG 로 올린다(`photo.js`, 라이브러리 없음). 사진을 못 읽는 브라우저는 고른 파일 그대로. 서버는 400KB 이하 · JPEG/PNG/WebP 머리 바이트만 받는다(R-202).
6. 순위 · 가족팀 화면의 사진 표시는 이 결정 범위 밖(나중).
