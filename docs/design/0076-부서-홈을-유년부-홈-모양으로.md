# 0076. 부서 홈을 옛 유년부 홈(jamsilkids.com) 모양으로 다시 짠다

- 상태: **확정**(2026-11-02, 사용자: 그림 시안 확정 "맨 아래 © 줄 넣고 확정", 성장 단계는 "모든 부서 똑같이")
- 관련: 0044(부서 홈), 0075(오늘 블록 — 이 결정으로 대체), 시안 그림 `hk.png`, 옛 소스 YuYunBu `Views/Home/Index.cshtml`(도토리 성장일지)

## 결정
1. 부서 홈(`/{slug}`, 임시 부서 1 · 2단계 화면 제외) 순서:
   머리말(교단 · 교회 · 날짜, 부서 이름 · 관리) → 말씀 한 줄 띠(✝) → **인사 카드**(이름 · 얼굴 동그라미 · 나의 점수 성장 링 · 단계 줄 · 연속일 · 성장일지 ›)
   → 말씀 찾기(통독을 켠 부서) → **도전!!! 성경말씀 카드**(올해 점수 · 오늘 미션 링 · 오늘의 말씀 · 미션 네 칸 · 올해 참여 막대 · 오늘 참여 인원)
   → **도전!!! 성경통독 카드**(진도 링 · 이어 읽을 곳 · 읽은/남은/전체 장) → 가족팀 한 줄 → 우리 부서 두 칸 → 계정 줄 → © 줄.
2. "이어서 하기" 큰 버튼 · 아래 탭 4개(0075)는 뺀다 — 두 프로그램이 큰 카드로 있으니 겹친다. 미션 완료 창의 "다음 미션" 버튼(0075 4)은 그대로.
3. **나의 점수 성장 단계**(R-190): 씨앗 🌰 → 새싹 🌱 → 나무 🌿 → 숲 🌲, 기본 끝 점수 400 · 900 · 1,300 · 1,700.
   플랫폼 규칙(`RuleSet.GrowthStages`)에 두고 모든 부서가 같이 쓴다(축하 단계와 따로). "도토리" 말은 쓰지 않는다. 나의 점수 = 성경말씀 시즌 점수.
4. 얼굴 사진: 이번에는 이름 첫 글자 동그라미만. 사진 넣기(고르기 → 동그랗게 맞추기 → 저장)는 저장 위치 · 공개 범위 · 관리자 대신 넣기를 정한 뒤 따로 한다.
5. 색: 성경말씀 = 주황, 성경통독 = 파랑, 완료 · 성장 = 초록, 맑고 부드러운 색.
