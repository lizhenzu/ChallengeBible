# 설계 문서

- 설계 결정 기록(ADR)은 `0001-제목.md` 형식으로 이 폴더에 둔다.
- 0001 ~ 0025 는 개념 명세의 확정 결정 D1 ~ D25 를 옮긴 것이다(번호가 1:1 대응).
  바꾸려면 사용자와 먼저 합의하고, 기존 ADR 을 고치지 말고 새 ADR 로 대체한다.
- 0026 부터는 설계 과정에서 새로 정한 결정이다.
