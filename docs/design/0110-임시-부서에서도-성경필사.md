# 0110 임시 부서(가입 · 승인 전)에서도 성경필사

- 날짜: 2026-11-17 · 상태: 결정(사용자 "회원 가입 후 가입 승인 전 필사도 보여줘")
- 바꾸는 것: ADR 0099 의 "임시 부서는 404"

## 결정
1. 임시 부서 "처음 오신 분"에서도 성경필사를 한다(미션 · 통독과 같음, ADR 0064). 미션 화면(홈 아랫부분)에 필사 카드, `/welcome/copy` · 장 고르기 · 쓰기.
2. 참여자 현황은 숨긴다(404, 목차에서도 빠짐) — 모르는 사람끼리 이름 · 진도가 보이지 않게(통독과 같음).
3. 필사 기록은 계정에 붙어 있어(부서 칸 없음) 승인된 부서에서 그대로 이어진다.
4. 완필 선물은 임시 부서에서 만들지 않는다. 승인된 부서의 필사 화면을 열면 그 부서에서 생긴다.

## 결과
- `Pages/Copy/Pages.cs`(Off = 필사를 끈 부서만, 참여자 현황 · 선물은 임시 부서 제외), `_CopyNav`, 부서 홈 카드. 업무 규칙 R-323.
