# 0045. 로그인 전에는 공통 첫 화면 하나, 부서는 로그인 후에 갈라진다

- 상태: 확정 (2026-10-22, 사용자 결정)
- 보완 대상: 0008(D8 주소로 영역 식별), 0044(홈 메인)
- 관련: 시안 "로그인 전 첫 화면", "홈 메인"

## 결정
1. 로그인하지 않은 사람은 모두 기본 주소 **`/`** 의 **공통 첫 화면**을 본다(길게 스크롤하는 소개 페이지).
   - 내용: 소개 · 로그인 · 가입, 앱 미리보기, 오늘의 말씀(공용 콘텐츠), 두 프로그램 소개, 전체 참여 숫자(모든 부서 합계, 이름 없음), 시작 3단계.
   - **부서 이름은 로그인 전 어디에도 보이지 않는다.**
2. **로그인한 뒤 갈라진다.**
   | 승인된 소속 | 가는 곳 |
   |---|---|
   | 1개 | 그 부서의 홈 메인 `/{slug}` (0044) |
   | 2개 이상 | 부서 고르기 → 고른 부서 홈. 마지막으로 쓴 부서를 기억(R-135) |
   | 0개(신청 중 포함) | 참여 신청 화면 — 선생님께 받은 **부서 코드**를 넣는다. 신청 중이면 "승인을 기다리고 있어요" |
3. 부서 주소(`/{slug}/…`)는 **로그인한 뒤에만** 쓴다(0008 유지).
   로그인하지 않고 부서 주소로 오면 `/` 로그인으로 보내고, 로그인한 뒤 원래 주소로 돌려보낸다(그 부서 소속이 없으면 그 부서 참여 신청).
4. 부서 이름이 처음 보이는 곳은 로그인 후 화면이다.

## 결과
- 선생님이 부서 주소를 알려 주면 "로그인 → 그 부서"로 이어진다. 가입한 사람은 그 부서 코드가 미리 채워진 참여 신청으로 간다.
- 공통 첫 화면의 숫자는 플랫폼 전체 합계라 시스템 연결(PlatformScope)로 계산해 캐시한다.
- 화면 계약: `/` = 공통 첫 화면, `/account/tenants` = 부서 고르기, `/join` = 부서 코드로 참여 신청.
