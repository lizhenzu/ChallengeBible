# 0009. 콘텐츠 = 공용 라이브러리 + 영역별 날짜 덮어쓰기

- 상태: 확정 (2026-10-21)
- 원래 결정: D9
- 관련: R-120 ~ R-124, X-18, X-19

## 맥락
부서 담당자가 매일 콘텐츠(말씀 · 기도 · 퀴즈 · 암송)를 새로 만드는 것은 부담이 크다.
한편 부서마다 특별한 날(행사 · 절기)에는 다른 내용을 쓰고 싶어 한다.

## 결정
- 플랫폼 관리자가 **공용 콘텐츠 라이브러리**를 만든다. 모든 영역의 기본값이다.
- 영역 관리자는 특정 날짜(암송은 특정 기간)에 **영역 덮어쓰기**를 만들 수 있다.
- 어떤 날의 콘텐츠 = 덮어쓰기가 있으면 그것, 없으면 공용. **종류별로 따로** 판단한다(R-120).

## 결과
- 공용 콘텐츠는 전역 데이터(TenantId 없음), 덮어쓰기는 영역 데이터다(0007).
- 종류별 · 날짜별 최대 1건을 고유 제약으로 보장한다. 암송은 기간이 겹치지 않는다(R-121, X-18).
- 초안/공개 상태를 가지며, 공개된 것만 참여자에게 보인다(R-123).
- 수행 기록은 당시 콘텐츠 ID · 버전을 가리킨다. 콘텐츠를 바꾸거나 지워도 과거 기록 · 점수는 유지된다(R-124).
- 콘텐츠는 거대한 가로 표가 아니라 하위 표(영상 구간, 질문 등)로 정규화한다(X-19).
- 06 문서에 따라 영역 덮어쓰기는 2차로 미룰 수 있다(1차는 공용만).
