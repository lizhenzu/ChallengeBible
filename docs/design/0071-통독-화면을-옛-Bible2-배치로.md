# 0071. 통독 화면을 옛 사이트 Views/Bible2 와 같은 구조 · 배치로(색은 지금 그대로)

- 상태: **확정 · 구현 끝**(2026-10-31, 사용자 "확정, 구현 시작"). 게시 뒤 라이브 확인은 사용자가 직접
- 관련: 0040(통독), 0041, 0057(본문 읽기 · 장 번호 줄), 0062(책 개요), 0063(장 듣기)
- 참조(읽기만): 옛 사이트 저장소 lizhenzu/YuYunBu — `Views/Bible2/*` · `Views/Shared/_Bible2Layout.cshtml`

## 결정(사용자)
1. **범위 = 통독 화면 전부**: 대시보드(Index) · 목록(List) · 검색(Search) · 북마크(Bookmarks) · 참여자 현황(Participants) · 회차 기록(ResetProgress 모양) · 본문 읽기(Read).
2. **구조 · 배치는 옛 화면과 같게, 색은 지금 통독 색(흰 · 파랑)**.
3. **공통 틀**: 넓은 화면(769px 이상)은 왼쪽 고정 목차(240px), 좁은 화면은 ☰ 서랍. 위 줄 = ☰ · 화면 이름(본문 읽기는 파란 머리 안에 ☰).
   목차: 대시보드 · 구약 읽기 · 신약 읽기 · 성경 검색 · 북마크 · 참여자 현황(임시 부서는 숨김) · 회차 기록 + 빠른 이동 4칸 + 부서 홈.

## 옛 화면과 다른 점(일부러)
- 밝게 / 어둡게 스위치 없음(기기 설정을 따름). 목차의 "허브"는 "회차 기록"으로.
- 대시보드 "오늘의 말씀" 칸은 그날 성경말씀 미션의 첫 절(없으면 숨김).
- 회차 기록은 옛 "완독 처리" 모양만 빌림 — 기록은 지우지 않고 새 회차를 시작(0040).
- 참여자 카드는 사진 대신 이름 글자. 목록의 "다 읽음 표시"(R-151)는 그대로 둠.
