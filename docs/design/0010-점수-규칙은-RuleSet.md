# 0010. 점수 규칙 = 플랫폼 기본값 + 영역별 변경 (RuleSet)

- 상태: 확정 (2026-10-21)
- 원래 결정: D10
- 관련: 03 문서 11절, R-64, X-06

## 맥락
현행은 점수(+1), 인정 기간, 퀴즈 2회, 친구 기도 0점이 C# · SQL · 화면 문구에 흩어져 있다(X-06).
규칙 하나 바꾸려면 배포해야 하고, 화면 안내와 실제 계산이 어긋난다.

## 결정
- 점수 · 인정 기간 · 횟수 등의 값은 **규칙 설정(RuleSet)** 한 곳에 둔다.
- **플랫폼 기본값**(= 현행 유년부 값, 03 문서 11절)이 있고, **영역 관리자가 값을 바꿀 수 있다**.
- 미션 종류 자체를 켜고 끄는 것은 1차 범위가 아니다.

## 결과
- 코드에는 규칙 값을 쓰지 않는다. 화면 안내 문구도 RuleSet 값으로 만든다(예: "오늘/어제/그저께만 가능").
- 규칙이 바뀌어도 이미 쌓인 점수는 바뀌지 않는다. 점수 원장에 **당시 점수**를 기록한다(R-64).
- 규칙 변경 이력을 남긴다(04 문서 규칙 설정 화면).
- 06 문서에 따라 1차(MVP)는 플랫폼 기본값만 쓰고, 영역 변경 화면은 2차로 미룰 수 있다.
