# 0081. 말씀 읽기 "듣기"는 날짜별 영상 구간을 차례로 재생하고, 구간은 API 로만 넣는다

- 상태: **확정 · 구현** (2026-11-04, 사용자와 하나씩 정함, R-127)
- 관련: R-166 · 0063(장 듣기 영상 `app.ChapterMedia`), 0080(말씀 입력 API `PUT /api/platform/words/{date}`), 0079(퀴즈 입력 API · `X-Api-Key`)
- 참조(읽기만): 옛 사이트 lizhenzu/YuYunBu — `Views/DailyMission4/BibleRead.cshtml`(구간 차례 재생), `Models/Today/TodayWordToRead.cs`(URL · URL2 ~ URL5, YouTuBuStartMM/SS · YouTuBuEndMM/SS), `Models/Jumana/JuManNaSegEdit.cs`(구간 편집: 한 장에 구간 하나, 0 = 처음 · 끝)

## 맥락
옛 사이트는 장마다 유튜브 영상 1개(`eBibleYouTuBu`)를 두고, 날마다 말씀 표에 **구간 최대 5개**(영상 주소 · 시작 · 끝, 분:초)를 사람이 넣어 **오늘 구절 부분만** 차례로 재생했다. 말씀이 장을 넘으면(예: 1장 14절 ~ 2장 1절) 1구간 = 1장 영상의 14절 시작 ~ 끝, 2구간 = 2장 영상의 처음 ~ 1절 끝으로 이어 재생했다.
새 사이트는 장 영상(`app.ChapterMedia`, 1,189장)만 있고 "🎧 듣기"는 **장 전체**를 반복 재생한다. 날짜별 구간이 없다.

## 결정(사용자)
1. **표를 새로 만들어 옛 사이트처럼 재생한다**: 날짜별 영상 구간 표(가칭 `app.DailyWordClip` — 날짜, 순서, 장, 유튜브 영상(비우면 그 장의 `ChapterMedia` 기본 영상), 시작, 끝). 공용 콘텐츠(TenantId 없음, 0080 과 같은 범위).
2. **입력은 API 로만**: `PUT /api/platform/words/{yyyy-MM-dd}/clips` — 그날 구간 목록을 **통째로 바꾼다**(빈 목록 = 지움). 인증 · 오류 모양은 0079 · 0080 과 같다(`X-Api-Key`, 키가 없으면 없는 주소처럼). 옛 데이터도 옛 사이트에서 이 API 로 밀어 넣는다(SQL 로 옮기지 않음). 관리 화면 입력은 만들지 않는다.
3. **구간 하나** = `chapter`(장) · `youtube`(주소나 영상 번호, 비우면 그 장의 기본 영상) · `start` · `end`. 시간은 **"분:초" 글자**(예: `"12:34"`), 비우면 "처음부터" · "끝까지".
4. **검사하지 않는다**: 장이 그날 말씀 범위 안인지 · 차례인지 보지 않고, 보낸 차례 그대로 저장 · 재생한다. 그날 말씀(`DailyWord`)이 없어도 날짜로 저장된다. (형식 검사 — 시간 글자 모양, 장 번호 범위, 유튜브 주소 모양 — 는 한다.)
5. **화면**: 말씀 읽기(`/{slug}/read`, 말씀 미션에서 온 날)의 **"🎧 듣기"** 가 그날 구간이 있으면 **오늘 구절 구간만 차례로** 재생한다(구간 끝에 닿으면 다음 구간 영상의 시작으로, 마지막 뒤에는 처음부터 반복 — 옛 사이트와 같음). 구간이 없는 날은 지금처럼 장 전체. 버튼 모양은 그대로라 시안은 없다.

## 결과
- 마이그레이션 + **실DB SQL** `tools/sql/migrate-wordclips.sql`(사용자가 SQL Studio 에서 실행 → 게시).
- API 사용 가이드(옛 사이트용)를 0079 · 0080 가이드 옆에 둔다.
- 테스트: API(키 · 날짜 · 형식 · 통째 바꾸기 · 빈 목록 지움), 화면(구간 있는 날 · 없는 날의 듣기 데이터).

## 구현 때 정한 것
- 본문은 `{ "clips": [...] }`. `clips` 칸이 빠지면 오류(실수로 그날 목록을 지우지 않게), 응답은 `{ date, count }`.
- 형식 검사에 더한 것: 구간 50개까지, 끝은 시작보다 뒤. `"0:00"` 은 옛 데이터처럼 처음 · 끝으로 읽는다.
- 재생은 유튜브 플레이어 API(구간이 있는 날 "듣기"를 누를 때만 부른다). `loadVideoById` 직후 오는 "끝남" 이벤트는 구간 끝이 아니므로, 그 구간이 재생된 뒤의 "끝남"만 믿는다.
- 그 장에 듣기 영상이 없어도 구간에 영상이 있으면 듣기 버튼이 생긴다.

## 고침(2026-11-04, 사용자): 듣기 버튼에 구간을 보여 준다
결정 5의 "버튼 모양은 그대로"를 바꾼다. 확정 시안 `시안/말씀듣기-clips-단독시안.html` ㄱ안.
- `/read` 도구 줄은 [보기] [듣기] 반반. 듣기를 펼치면 "유튜브 듣기"가 한 줄 전체, 해설은 아래 반반.
- 유튜브 듣기 버튼: 구간마다 한 줄(`3장 1:05 ~ 7:40`, 비었으면 처음 · 끝까지, 둘 다 비었으면 전체). 구간이 없는 말씀 날은 `3장 전체 · 8:12`.
- 통독 본문은 그대로(이 배치는 `.rnv-pan` 안에서만).
