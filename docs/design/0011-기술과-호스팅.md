# 0011. 기술 · 호스팅 — ASP.NET Core + PWA, SQL Server, SmarterASP 새 사이트

- 상태: 확정 (2026-10-21)
- 원래 결정: D11
- 관련: 0018, 0021, X-14, X-21, X-22

## 맥락
운영자가 이미 SmarterASP(site4now)를 쓰고 있고 .NET 에 익숙하다.
아이들은 주로 휴대폰으로 접속한다.

## 결정
- ASP.NET Core (.NET 9) 웹 앱 + **PWA**(휴대폰 우선 375px, 설치 가능)
- EF Core, SQL Server(2019 이상, 0018)
- 호스팅: SmarterASP(site4now) **새 사이트 + 새 DB**. 현행 사이트 · DB 와 섞지 않는다.

## 결과
- 서비스 계층은 하나로, 전부 async + DI 로 만든다(X-14).
- 비밀 값(접속 문자열 · 비밀번호)은 Git 에 두지 않는다(X-21).
- DB 스키마는 마이그레이션으로만 바꾼다. 앱 시작 시 자동 생성하지 않는다(X-22).
- 공유 호스팅은 앱 풀 재활용 · 상시 백그라운드 작업에 제약이 있을 수 있다.
  점수 집계처럼 정확해야 하는 일은 백그라운드 작업에 기대지 않는 방향으로 설계한다(논리 · 물리 설계에서 확정).
