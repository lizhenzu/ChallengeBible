# 0070. 미션 완료를 취소할 수 있게(말씀 · 기도 · 암송, 오늘만)

- 상태: **확정**(2026-10-31, 사용자와 하나씩 정함 · 시안 미션완료취소 ① "확인 창" 확정)
- 관련: R-21 · R-31 · R-51 · R-101(이 결정으로 바뀜), 새 규칙 R-24, 0034(미션 버튼 JSON API), X-17(멱등 API)

## 맥락
잘못 누른 "완료"를 되돌릴 방법이 없었다(R-21 · R-31 "한 번 켠 항목은 꺼지지 않는다"). 사용자가 모든 미션(일반 부서 · 임시 부서)에서 완료를 눌렀다가 다시 취소할 수 있기를 원했다.

## 결정(사용자)
1. **대상**: 말씀 · 기도 · 암송. **퀴즈는 빼기**(정답으로 받는 점수이고 시도 횟수가 있어서).
2. **기간**: **오늘만**. 암송은 주 1회라 **이번 주 암송만**. 지난 날짜 · 지난 주는 취소할 수 없다(지난 점수 · 순위가 바뀌지 않게).
3. **축하도 취소**: 취소로 시즌 점수가 줄면, 그 점수 아래로 내려간 개인 축하 단계(MilestoneReached)와 가족 축하 단계(FamilyMilestoneReached) 도달 기록을 지운다. 다시 넘으면 축하가 또 뜬다.
4. **화면(시안 ①)**: 완료된 버튼을 한 번 더 누르면 확인 창 "완료를 취소할까요? 항목 · -N점 · 그 점수로 받은 축하도 함께 없어져요" [그대로 두기] [취소하기]. 버튼 아래 작은 안내 "잘못 눌렀으면 완료 버튼을 한 번 더 눌러 취소해요 (오늘만)".
5. **적용**: 모든 부서(임시 부서 포함). 미션 화면 4곳 중 퀴즈를 뺀 3곳.

## 결과
- API `POST /api/{slug}/missions/undo` `{ date, item }` — 멱등(이미 취소된 것을 또 보내도 0점 · 성공, X-17 의 취지). 퀴즈 항목은 거절.
- 취소는 수행 기록(Activity)과 원장(PointLedger) 줄을 **실제로 지운다**(논리 설계 1-4 의 "실제 삭제"에 추가). 점수는 원장 합이라 저절로 빠진다(R-63).
- 감사 로그는 남기지 않는다(아이의 미션 기록 일이라 관리 기록에 섞지 않음).
- 새 표 · 열 없음 → **실제 DB SQL 없음**.
