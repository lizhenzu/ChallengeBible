# 0059. 참여 신청은 목록에서 부서를 고른다 — 플랫폼이 켠 부서만

- 상태: 확정 (2026-10-24, 사용자 결정 "A안", 시안 부서참여신청-v2 확정)
- 보완 대상: 0048(참여 코드는 주소와 따로), 0045
- 관련: 0027, R-130

## 맥락
테스트하던 사용자가 "참여 부서 코드를 넣는 것은 어렵다, 참여 가능한 부서를 보여 주고 고르게 해 달라"고 했다.
모든 부서를 보이면 가입한 누구나 모든 교회 · 부서 이름을 보고 아무 데나 신청할 수 있게 된다(멀티테넌트).

## 결정
1. 부서(Tenant)에 **`JoinListed`(참여 목록에 보이기)** 를 둔다. 기본은 꺼짐이고, 플랫폼 관리자가 부서 관리에서 켜고 끈다.
2. 참여 신청 화면은 ① **목록에서 부서 고르기**(켠 · 운영 중 부서만, 이름으로 거르기) ② 역할 고르기 ③ 신청 순서다.
3. 참여 코드는 그대로 둔다. 목록 아래 "목록에 내 부서가 없나요? 부서 코드로 찾기"(접힘)로 쓴다. 부서 주소로 들어오면 그 부서가 골라진 채로 열린다.
4. 목록에 없는 부서는 **그 부서의 코드가 함께 와야** 신청된다. 부서 Id 만 바꿔 숨긴 부서에 신청하지 못하게.
5. 이미 소속 · 신청한 부서는 목록에 흐리게 "이미 소속" · "승인 기다리는 중"으로 보이고 고를 수 없다(0027).
6. 정지된 부서는 목록에도 코드로도 보이지 않는다(0048 결정 5).

## 결과
- 마이그레이션 `JoinListed`(Tenant 열 하나, 기본 0). 실DB 적용 뒤에는 모든 부서가 숨김이라, 보일 부서를 플랫폼 화면에서 켜야 한다.
- 코드 찾기 횟수 제한(0048 결정 6)은 그대로다. 목록 고르기는 횟수 제한이 없다.
