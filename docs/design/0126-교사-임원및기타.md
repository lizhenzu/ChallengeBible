# 0126 — 교사 · 임원 및 기타(R-362)

- 상태: 확정(2026-11-21 사용자 "교사와 교사 외로 나누기 · 교사 외는 '임원 및 기타' · 확정한다. 진행"), 시안 `docs/design/시안/역할-담임-시안2.png`
- 배경: 유년부 이관 뒤 부장이 2명으로 보였는데, 임원 · 담임을 한눈에 보고 고칠 곳이 없었다(소속 관리 · 반 화면에 흩어짐).
- 결정
  1. 한 화면에 모두 담지 않고 둘로 나눈다: **교사**(반별 담임 · 부담임 · 반 없는 교사) · **임원 및 기타**(임원 직책 칸 · 봉사 · 기타 · 새친구).
  2. 임원 중 부장 · 부감 · 서기 · 회계 · 교장은 "한 명 자리"로 보고 두 명 이상이면 경고, 비면 점선 칸. 지도는 여러 명.
  3. 바꾸기는 바닥 창(높이 고정, 목록만 스크롤) + 한 번 더 묻기. 서버가 규칙을 다시 확인한다.
  4. 어드민 역할(부서 관리자 계정)은 바꾸지 않고, 어드민으로 바꾸지도 못한다(R-315). 관리자가 되는 역할은 부서 관리자 규칙을 따른다.
  5. 소속 관리(사람 정보 · 계정)와 반 화면(반 만들기 · 학생 배정)은 그대로 두고 두 화면으로 링크를 잇는다.
