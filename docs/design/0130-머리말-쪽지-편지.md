# 0130 부서 홈 머리말 — 검색 아이콘을 쪽지 편지로

- 날짜: 2026-11-22 · 상태: 결정(사용자)
- 관련: ADR 0112(쪽지) · 0127(부서 홈)

## 배경

부서 홈 머리말 오른쪽에는 `말씀 검색`(돋보기)과 내 계정(사진)이 있었다. 사용자가 돋보기를 빼고 **쪽지 편지**로 바꿔, 받은 쪽지함으로 가고 안 읽은 수를 숫자로 보여 달라고 했다.

## 결정

1. **머리말 돋보기 제거** — 검색은 로고 아래 `성경에서 단어 검색` 알약이 그대로 맡는다.
2. **편지 아이콘 추가** — 기존 `_MailBadge`(ADR 0112)를 되살린다. 누르면 `/messages`(기본 받은 쪽지 탭)로 간다.
3. **숫자** — 안 읽은 쪽지 **전체** 수. 0이면 숫자 없음, 99개를 넘으면 `99+`. 로그인한 사람에게만 보인다.
4. **순서** — 편지 → 내 계정(사진). 둘 다 40px, 배경 투명.
5. **팝업은 그대로** — 로그인 직후 한 번 뜨는 쪽지 팝업(ADR 0112)은 건드리지 않는다.

## 참고

- 예전 홈에는 이 편지 배지가 있었지만 ADR 0127에서 홈을 새로 만들며 빠졌다. 이번에 새로 만드는 것이 아니라 **되살리는 것**이다.
- 배지 숫자는 "새로 온 쪽지"가 아니라 "안 읽은 쪽지"다. 쪽지를 열면 줄어든다.
- 검색 기능은 사라지지 않는다. 알약 검색이 같은 `/reading/search`로 간다.
