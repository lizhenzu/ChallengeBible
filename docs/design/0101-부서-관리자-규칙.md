# 0101 부서 관리자 규칙(직분 → 부서 관리자)

- 날짜: 2026-11-16 · 상태: 확정(사용자 "1", 시안 `시안/관리자규칙-*.png`)

## 배경
부장이라도 관리자 권한이 따로 없으면 ☰ 에 "관리"가 보이지 않는다. 사람마다 관리자 권한을 주는 대신, 직분으로 정하고 싶다(사용자).

## 결정
- 플랫폼 ☰ › 부서 › **부서 관리자 규칙**(`/platform/admin-rule`). 공통 규칙 하나만, 플랫폼 관리자만 바꾼다(부서별 따로 없음).
- 고를 수 있는 직분: 교장 · 지도 · 부장 · 부감 · 서기 · 회계. 기본값 부장 · 부감 · 서기.
- 체크한 직분인 사람은 모든 부서에서 바로 부서 관리자(Identity Admin)가 된다. 직분이 바뀌거나(관리 › 사람 · 부서 옮김 · 승인) 새로 들어오면 그 사람만 다시 맞춘다.
- 규칙으로 준 관리자에게 업무 꼬리표 `AutoAdmin` 을 붙인다. 체크를 풀거나 직분이 바뀌면 이 꼬리표가 있는 사람만 관리자에서 뺀다. 따로 정한 관리자 · 계정은 건드리지 않는다(CLAUDE.md).
- 규칙으로 관리자인 사람은 관리 › 사람에서 관리자를 뺄 수 없다(직분이나 규칙을 바꾼다). 관리 › 사람에서 관리자로 지정하면 "따로 정한 관리자"가 된다.
- 저장 값은 새 표를 만들지 않고 공통 할 일 규칙 표(TodoRule, TenantId NULL)의 Kind = `deptadmin` 한 줄(직분 코드 csv)에 둔다 — 마이그레이션 없음.
- 플랫폼 관리자 · 처음 오신 분(임시 부서) 소속은 규칙에서 뺀다.

## 결과
- 배포 직후에는 아무도 바뀌지 않는다. 화면에서 [저장 · 바로 적용]을 한 번 눌러야 지금 있는 부장 · 부감 · 서기가 관리자가 된다.
