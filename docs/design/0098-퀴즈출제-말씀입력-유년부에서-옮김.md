# 0098. 퀴즈 출제 · 말씀 입력 — 유년부 화면 옮기기

- 상태: 확정 (2026-11-15, 사용자 질문 1 ~ 4 · 시안 "확정")
- 원본(읽기 전용): `lizhenzu/YuYunBu` — `/Question`(퀴즈 출제) · `/JuManNa/IndexGroupByYYYYMM`(말씀 정리)와 이어지는 화면
- 확정 시안: `docs/design/시안/퀴즈출제-말씀입력-시안.png`, 구현 캡처 `퀴즈출제-말씀입력-구현.png`

## 결정
1. **플랫폼 관리자 · 모든 부서 공용 말씀 · 퀴즈**(질문 1 → 1).
2. 옛 화면(공용 콘텐츠 · 퀴즈 넣기)은 그대로 두고 메뉴에 더한다(질문 2 → 추천).
3. 옮길 것: 두 첫 화면 + 이어지는 입력 화면 — 퀴즈: 이 날 입력 · 수정 · 삭제 · 미리 보기 · 구절 복사 · AI 프롬프트 복사, 말씀: 한 달 입력 · 영상 구간 편집 · 수정 · 보기. **옮기지 않음**: 플랫폼으로 보내기(말씀 · 영상 구간 · 퀴즈 보내기), 템플릿, 문제 은행(질문 3 → 1).
4. 챌린지에는 이미 유년부 달력을 본뜬 "입력 점검"(R-216 · R-217)이 있어 **그 화면에 빠진 기능만 더하고 이름을 "퀴즈 출제" · "말씀 입력"으로**(질문 4 → 1). 테마는 챌린지(사용자 "가능한 챌린지 테마에 맞춰").
5. AI 프롬프트: 플랫폼 화면에서 고친다(새 표 `app.QuizAiPrompt`, 질문 1 → 1). 기본 문구는 **유년부 그대로**(사용자 "이것은 사람이 해야 해, 있는 그대로") — 그래서 기본 문구가 만드는 답은 유년부 표 SQL 형식이다(필요하면 사람이 문구를 고친다).
6. 퀴즈 삭제 = 그날 공용 퀴즈의 지금 개정을 내림(보관). 아이 기록이 개정을 가리켜 지우지 않는다.
7. 한 달 입력 = 제목 · 성경 · 장절만, 바꾼 날만 저장. 공개된 날은 새 개정으로 공개(R-124), 새 날 · 초안은 초안(이야기 비움). 이야기 · 해설 · 영상 구간은 그대로.
8. 영상 구간 = 그날 범위의 장마다 장 듣기 영상(ChapterMedia Listen)으로 시작 · 끝을 정해 바로 저장, 그날 목록을 범위의 모든 장으로 통째로 바꾼다(R-127). 모두 기본이면 목록을 비운다.
