# 0008. 영역은 주소 경로 `/{영역코드}/...` 로 식별

- 상태: 확정 (2026-10-21)
- 원래 결정: D8
- 관련: R-130, R-135, X-20

## 맥락
영역을 정하는 방법에는 하위 도메인(`jsn-kids.example.com`), 경로, 로그인 후 선택(세션) 등이 있다.
공유 호스팅에서 하위 도메인 · 와일드카드 인증서는 다루기 어렵고,
현행처럼 세션에 의존하면 재시작 시 값이 사라진다(X-20).

## 결정
- 모든 영역 화면은 `/{영역코드}/...` 아래에 둔다. 예: `/jsn-kids/today`
- 영역코드(TenantSlug)는 영역마다 고유한 짧은 영문 코드다.

## 결과
- 요청마다 주소에서 영역을 정해 **요청 범위의 테넌트 컨텍스트**를 만든다.
  세션에 영역을 저장해 권한 판단에 쓰지 않는다.
- 로그인한 계정이 그 영역에 **승인된 소속**이 없으면 소속 신청 화면으로 보낸다(R-130).
- "마지막으로 쓴 영역 기억"(R-135)은 첫 화면 이동 편의일 뿐 권한 판단에 쓰지 않는다.
- 로그인 · 가입 · 내 계정 · 플랫폼 관리 화면은 영역 경로 밖(전역)에 둔다.
- 영역코드는 링크 · 북마크 · PWA 시작 주소에 박히므로, 바꾸기 어려운 값으로 다룬다.
