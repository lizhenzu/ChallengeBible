# 0037. 서비스 이름은 "도전!!!성경말씀" (임시) — 이름은 한 곳에만 둔다

- 상태: 확정 (2026-10-22, 사용자 결정 · 나중에 바뀔 수 있음)
- 관련: 0019(D19, 문구 리소스 분리), 0033

## 맥락
서비스 이름을 정해야 했다. 후보(말씀등불 · 말씀걸음 · 말씀나무 · 오늘말씀 · 도전 성경말씀)를 검토했고,
사용자가 일단 **"도전!!!성경말씀"** 으로 하고 나중에 바꿀 수 있다고 했다.

## 결정
1. 화면에 보이는 서비스 이름은 **도전!!!성경말씀** 이다(표기 그대로, 띄어쓰기 없음).
2. 이름은 **화면 문구 리소스 한 곳**(`AppName`)과 PWA 매니페스트(`name`, `short_name`)에만 둔다.
   화면 · 메일 · 알림 문구는 이 값을 읽어 쓴다. 코드 · 화면 템플릿에 이름을 직접 쓰지 않는다.
3. 코드 이름(솔루션 · 네임스페이스 · 저장소)은 **ChallengeBible** 을 그대로 쓴다. 서비스 이름이 바뀌어도 코드 이름은 바꾸지 않는다.
4. 홈 화면 아이콘 아래처럼 짧은 이름이 필요한 곳(`short_name`)은 **도전성경** 으로 둔다(휴대폰 아이콘 이름은 보통 12자 안팎에서 잘림).

## 결과
- 이름을 바꿀 때는 리소스 값과 매니페스트만 고치면 된다(배포 1회).
- 같은 이름의 앱 · 상표가 있는지는 확인하지 않았다. 공개 전에 앱 스토어 · KIPRIS 에서 확인한다.
- 개념 명세 · 설계 문서의 "도전 성경말씀"은 프로젝트를 부르는 말로 남겨 둔다(문서 전체를 고치지 않음).
