# 0116 부서 예배 안내(시간 · 장소 · 주소 · 주보)는 DB 에 두고 언제든 바꾼다

- 날짜: 2026-11-18 · 상태: 결정(사용자: "부서별 예배 위치와 시간은 변경될 수 있다. DB 에 넣고 수시로 바꾸게 설계" · 화면 시안은 보류)
- 관련: R-337 · 시안 `예배안내`(부서 홈 말씀 찾기 바로 위 카드, 개발 보류)

## 배경
주일학교 부서마다 예배 시간 · 장소가 있다(교회 주보 "주일학교" 표). 장소 · 시간은 바뀔 수 있어 코드나 고정 문구가 아니라 DB 에 둔다.

## 결정
1. 표 `app.WorshipSchedule`(부서 표 — RLS + 전역 필터, D20). 부서마다 여러 줄(예: 1부 · 2부)이 될 수 있다.
   | 열 | 뜻 |
   |---|---|
   | TenantId, Id | 부서 · 줄 번호 |
   | SortOrder | 보이는 순서 |
   | Title | "1부 예배"처럼 이름이 필요할 때만(없으면 "○○부 예배") |
   | DayOfWeek | 0 = 주일 … 6 = 토요일 |
   | StartTime | 시작 시각(time(0)) — 부서 시간대의 벽시계 시각, UTC 로 바꾸지 않는다 |
   | Place | 장소(예: 비전센터 믿음홀(3F)) |
   | Address | 주소(예: 서울특별시 송파구 석촌호수로 102) — 비우면 안 보임 |
   | BulletinUrl · BulletinDate | 주보 링크 · 날짜 — 비우면 주보 버튼 안 보임 |
   | IsActive | 지우지 않고 잠시 숨기기 |
   | UpdatedUtc · UpdatedByUserName | 마지막으로 고친 때 · 사람 |
2. 고치는 사람: 부서 관리자(자기 부서). 고칠 때마다 AuditLog `WorshipSchedule`(지금 부서 TenantId, "이전 → 새 값").
   값 검사: 요일 0 ~ 6, 시간 `10:00`, 장소 1 ~ 100자, 주소 200자, 주보 링크는 http(s) 주소 500자, 주보 날짜 `yyyy-MM-dd`.
3. 처리기: `WorshipService`(목록 · 고치기 · 새로 넣기 · 지우기). 화면(부서 홈 카드 · 관리 화면)은 다음 단계 — 시안 확정 뒤.
4. 처음 값: 주보 "주일학교" 표의 7개 부서(영아부 ~ 고등부, 모두 주일 오전 10시) — `tools/sql/seed-worship.sql`. 청년부 · 장년부는 비움(카드 안 보임).
5. 주보(2026-11-18 사용자): [주보 보기]는 유년부 사이트처럼 **주보 업로드 페이지**로 간다. 주보 올리기 · 보기 설계는 유년부 사이트를 참고해 따로 정한다(그때 BulletinUrl 은 이 페이지 주소로 대신하거나 지운다).

## 실운영 적용
1. SSMS: `tools/sql/migrate-worship.sql`(표 + RLS, 여러 번 실행해도 한 번만)
2. 사이트 SQL 화면: `tools/sql/seed-worship.sql`(시험 실행 → 저장)
