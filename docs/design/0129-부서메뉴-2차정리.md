# 0129 부서 메뉴 2차 정리 — 프로그램·바로가기 제거

- 날짜: 2026-11-22 · 상태: 결정(사용자 "지울것은 아래이다")
- 관련: ADR 0127 · 0128

## 배경

0127에서 ☰ 메뉴를 깔끔판으로 바꾸며 프로그램 4개와 바로가기 2개를 넣었다. 화면을 보니 부서 홈의 프로그램 아이콘·말씀 카드·현황과 겹쳤고, 그룹 라벨이 크게 보였으며, 로그아웃 버튼이 브라우저 기본 테두리·배경 때문에 깨져 보였다.

## 결정

1. **☰에서 아래를 모두 뺀다**
   `프로그램`(도전!!!성경미션 · 성경통독 · 성경필사 · 자녀를 위한 기도365)과 `바로가기`(오늘의 말씀 · 나의 기록).
   - 프로그램은 부서 홈의 4칸 아이콘으로 간다.
   - 오늘의 말씀은 홈의 말씀 카드, 나의 기록은 현황 카드의 [더보기]로 간다.
2. **그룹 라벨 크기** — 메뉴 글자 15px보다 **1pt 작은 14px**, 굵기 700, 회색(`#9aa0aa`). (처음 16px로 올렸다가 2026-11-22 사용자 확인으로 14px)
3. **로그아웃** — `<button>` 기본 테두리·배경을 없애고 파란 글자만. 바닥은 `앱 설치 · 내 계정 · 로그아웃` 한 줄, 로그아웃은 오른쪽 끝(`margin-left:auto`), 줄바꿈 금지.
4. 남은 메뉴: 홈 / 섬김 · 교사 / 생일 / 함께하기 / 관리 / 다른 곳. 역할에 따라 보이는 묶음이 다르다.

## 영향

- 학생: 홈 · 생일 · 함께하기.
- 교사 · 관리자: 홈 · 섬김 · 교사 · 생일 · 함께하기 · 관리.
- 2026-11-21 "프로그램을 메뉴에서 빼고 홈 카드로" 결정과 같은 방향으로 돌아간다(0127에서 복원했던 것을 다시 정리).
- 테스트: 프로그램/바로가기 그룹을 확인하던 `HomeMainTests` · `CopyTests` · `Prayer365Tests` · `LobbyTests`를 새 구조로 바꿈.
