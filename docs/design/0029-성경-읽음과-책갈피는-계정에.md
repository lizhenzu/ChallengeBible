# 0029. 성경 읽음 표시와 책갈피는 계정에 붙인다 — 진급해도 유지

- 상태: 확정 (2026-10-22, 사용자와 합의)
- 예외 대상: CLAUDE.md "모든 업무 데이터는 TenantId 를 가진다", 0022(D22) 진급 시 완전 삭제
- 관련: R-112, R-113, R-114, 0025(D25)

## 맥락
절 읽음 표시와 책갈피(R-112)를 영역 데이터로 두면 진급할 때(0022) 함께 지워진다.
아이 입장에서 성경 읽기는 부서와 무관한 개인 기록이고, 2차 성경 통독률(0025)도 학년이 바뀌어도 이어져야 의미가 있다.

## 결정
1. 절 읽음 표시와 책갈피는 **영역이 아니라 계정**에 붙인다(TenantId 없음).
2. **진급해도 지우지 않는다.** 학년(영역)이 바뀌어도 그대로 이어진다.
3. 지우는 경우는 다음뿐이다.
   - 본인이 절 · 범위 단위로 해제(R-112, 멱등 API — X-17)
   - **관리자의 강제 삭제**(전체 초기화): 플랫폼 관리자, 또는 그 계정이 지금 소속된 영역의 영역 관리자
   - 계정 삭제
4. 강제 삭제는 감사 로그에 남긴다(누가, 언제, 어느 계정).

## 결과
- 이 데이터는 계정 범위 데이터다. RLS 의 테넌트 조건이 아니라 **"로그인 계정 = 소유 계정"** 조건으로 막는다.
  앱 전역 필터도 계정 조건으로 둔다(이중 격리 원칙은 유지, 기준만 계정).
- 영역 관리자는 자기 영역 참여자 상세에서 **초기화만** 할 수 있고, 읽음 내용을 영역 화면의 통계로 쓰지 않는다
  (다른 영역에서 읽은 기록이 섞여 있으므로).
- 읽음 표시는 점수와 무관하다(R-113). 진급 삭제 범위(0022)에서 이 데이터는 빠진다.
- 읽음 기록에는 처음부터 읽은 날짜(UTC)를 남긴다(R-114).
