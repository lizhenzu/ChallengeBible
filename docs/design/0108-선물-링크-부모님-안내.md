# 0108 선물 링크 — 담임이 보내는 부모님 안내글과 부모님 화면

- 날짜: 2026-11-17 · 상태: 결정(사용자 "부모가 할 일을 명확히 알 수 있도록", 시안 확정 1 · 모든 선물 링크에 적용)
- 확정 시안: `docs/design/시안/생일링크-부모안내-시안.html`

## 배경
관리자가 아닌 담임(예: 조진찬 선생님)에게 "생일 선물 링크" 할 일이 뜨는데 [선물 처리로 이동]이 관리자 전용이라 갈 곳이 없었다.
링크 주소만 보내면 부모님이 무엇을 해야 하는지 알기 어렵다.

## 결정
1. **할 일 카드에서 바로 보낸다**: 생일 링크(담임 · 우리 반 아이) · 선물 대상 알림(볼 수 있는 사람)에 [부모님께 보내기](휴대폰 공유 창 → 카톡 · 문자, 안 되면 복사) · [안내글 복사] · 보낼 글 미리 보기. 관리자는 [선물 처리로 이동]도 그대로.
2. 링크는 처음 누를 때 만든다(이력 "링크 보냄" → 타임라인). 내 할 일 카드에 없는 선물은 받을 수 없다(404).
3. **안내글**: [부서] · 아이 이름 · 왜(생일 날짜 · 새친구 · 전도 · 완독 · 완필) · 할 일(아이와 함께 선물 하나) · 로그인 없이 · 기한 · (계정 연결된 아이면) 아이 계정으로도 고를 수 있음 · 선생님이 주일에 전해 줌 · 링크.
4. **계정이 연결된 아이**는 카드에 "아이 계정에서 직접 고를 수 있어요"를 먼저 알리고, 혼자 고르기 어려우면 안내글을 보낸다. 누가 고르든 같은 선물 하나.
5. **부모님 화면(모든 선물 링크)**: 위에 부서 · 종류와 "OOO 어린이 ○○ 선물이에요", 할 일 3단계(선물 보기 → 하나 누르기 → 끝), 고르는 기한, 누르면 확인 창, 고른 뒤 "다 됐어요 · 부모님이 더 하실 일은 없어요".
6. 관리 › 선물 처리 링크 팝업에도 [안내글 복사] · 미리 보기.
7. 이름 뒤 "님"은 이름이 이미 "님"으로 끝나면 붙이지 않는다("조진찬 선생님님" 고침).

## 결과
- `BirthdayGiftService.ShareAsync` · `ShareText`, `TodoService.ShareAsync`, 할 일 `?handler=Share`(JSON), `wwwroot/js/todo-share.js`, `_BirthdayPick` 링크 화면, `Ui.Nim`. 업무 규칙 R-321.
