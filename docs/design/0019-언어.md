# 0019. 언어 — 화면 · 콘텐츠는 한국어, 본문은 여러 번역 대조, 문구는 리소스 분리

- 상태: 확정 (2026-10-21)
- 원래 결정: D19
- 관련: R-111, 04 문서 3절

## 맥락
사용자는 한국 교회 주일학교다. 현행은 개역개정 · 현대인의성경 · 영어 본문을 대조해 볼 수 있다.

## 결정
- 화면 · 콘텐츠는 **한국어**로 만든다.
- 성경 본문은 **여러 번역 대조**를 지원하고, 영역 기능 스위치로 켜고 끈다(기본 켬).
- 화면 문구는 나중에 다국어를 넣을 수 있게 **리소스로 분리만** 한다(번역은 하지 않음).

## 결과
- 성경 본문은 (번역본, 책, 장, 절)로 식별하는 전역 참조 데이터다.
- 콘텐츠(말씀 · 기도 · 퀴즈 · 암송)에는 언어 열을 두지 않는다(1차 기준).
- 암송 화면은 한국어로만 보여 준다(03 문서 3-4 참고).
