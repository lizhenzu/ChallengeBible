# 0021. DB 버전은 타협하지 않는다 — 2019 이상 (SmarterASP 확인 완료)

- 상태: 확정 (2026-10-21)
- 원래 결정: D21
- 관련: 0011, 0018

## 맥락
RLS(0018)는 격리의 핵심 장치다. 호스팅 사정으로 낮은 버전을 쓰면 이중 격리(0020)가 무너진다.

## 결정
- SmarterASP 에서 2019 이상을 못 쓰면 **요금제를 올리거나 호스팅을 바꿔서라도** 2019 이상을 쓴다.
- **확인 완료(2026-10-21)**: SmarterASP 제어판에서 SQL Server 2019 이상 사용 가능.

## 결과
- 착수 전 확인할 것 없음. 설계는 SQL Server 2019 기능(RLS, `SESSION_CONTEXT` 등)을 전제로 한다.
- 새 DB 생성은 06 문서 3절 "0. DB 준비" 단계에서 한다.
