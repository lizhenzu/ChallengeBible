# 0089. 성경통독 글자 크기: 지금의 85% 를 새 100% 로

- 상태: **확정 · 구현** (2026-11-07, 사용자, R-218)
- 확정 시안: `시안/reading-font-read.png` · `reading-font-home.png` (왼쪽 지금, 오른쪽 바뀐 뒤)

## 결정(사용자)
1. 성경통독 글자가 전체적으로 크다. 가− 로 맞춘 85% 크기를 기본으로 삼고, 그 크기가 100% 로 보이게 한다.
2. 범위는 통독 화면의 **모든 글자**(본문 · 해설 · 제목 · 버튼 · 안내).

## 구현 때 정한 것
- **크기 변수 하나**: 글자 크기를 `calc(Npx * var(--rs, 1))` 로 바꾸고, 통독 화면에서만 읽는 `reading.css` 에 `:root { --rs: .85; }` 를 둔다. 값을 바꾸면 전체 비율이 바뀐다. 말씀 미션은 이 파일을 읽지 않아 그대로 1 이다.
- **글자만 줄인다**: `zoom` 은 버튼까지 작아져 쓰지 않았다. 버튼 · 칸 크기는 그대로다.
- **가장 작은 글자**: 11px 아래로 내려가지 않는다. 원래 11px 이하인 글자는 그대로 둔다.
- **`site.css` 도 고침**: 통독과 말씀 미션이 함께 쓰는 `.brd` · `.rdv` · `.rnv` · `.bov` · `.ytm` · `.bmd` · `.fs` 규칙에도 변수를 넣었다. 말씀 미션에서는 1 이라 크기가 같다.
- **기억**: 통독은 `cb.fs.rd`, 말씀 미션은 그대로 `cb.fs`. 통독 값이 없으면 `cb.fs` 에서 옮긴다. 100% 는 새 100%, 다른 값은 보이는 크기가 가장 비슷한 단계(예: 85% → 100%).
- **그대로 둔 것**: 책 개요의 펼침 화살표(▾)는 글자가 아니라 아이콘이라 줄이지 않았다.

## 결과
- **실DB:** 데이터베이스 변경 없음. 게시만 하면 된다.
- 테스트: `ReadingFontTests`(실제 페이지 + 스크립트 + CSS 를 Edge headless 에서: 모든 글자가 줄었는지 · 버튼 크기 · 저장 옮기기 · 말씀 미션 그대로). 통독 11개 화면은 ScreenDump 로 한 번 더 검사했다. Edge 가 없는 환경에서는 화면 시험만 건너뛴다.
